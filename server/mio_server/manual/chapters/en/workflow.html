CHAPTER 03 / THE MIO HANDBOOK

Workflows & profiles

Import first shows recognized bindings, ambiguous inputs and required nodes or models. Save explicitly after review. Output mappings select nodes; parameter mappings select stored values. Diagnose the selected branch against its actual graph; custom plugin validation still belongs to ComfyUI.

Import ComfyUI API format with class_type and inputs, not the visual editor's nodes/links document. Copy built-in workflows before editing. Set real installed checkpoint filenames in the graph; check required custom nodes.

Search parameter targets by node ID, title or input name. Add custom parameters and multiple targets when needed; Edit JSON switches between parameters and the node graph. Check workflow dependencies, then generate one test image. Choose a workflow directly when assembling; images per scene and optional dimensions belong to the task and remember recent values by workflow. Empty dimensions preserve workflow values. Advanced plans can add post-processing workflows; feeding a previous image requires an [mio:init] input.

Explicit hybrid jobs validate and freeze their local refinement graphs, parameters and instance selection before submission. Editing or deleting the profile while the cloud request runs does not replace that frozen follow-up. Pure cloud candidates can be adopted directly; further refinement can be requested explicitly through the professional API.

When to use an advanced render plan

For everyday generation, select a local workflow or a cloud service in the new task. To draw a draft and then refine it at a higher resolution, add two stages in Workflows & APIs → Advanced render plans. Use a draft workflow first and an upscaling workflow second. Mark the second workflow’s image input with [mio:init] and set its stage image input to the previous output. Save the plan, then select it in the new task.

Send the prompt to the right input

If a trial image ignores your prompt, open the workflow’s mappings. Under Positive prompt, search for the text encoder and select the input that stores the prompt, then try generating another image. Standard inputs can be mapped directly. If a custom node stores its controls in a special format, such as several LoRAs packed into one input, install an adapter that supports that format.

LoRA slots and layered overrides

Say your workflow enables a character LoRA and a watercolor LoRA by default. To make just one scene line art, turn watercolor off in that scene’s LoRA settings and leave the character on. Other scenes and the saved workflow keep their settings.

Workflow details and preflight expose each controllable LoRA with its name, source, default switch, weight range and active adapter. Workflow-owned pinned LoRAs stay enabled by default. A task can disable, restore or retune one by stable key, and appended LoRAs use the same shape. These changes belong to the frozen task snapshot; the imported JSON is never rewritten.

Overrides resolve as workflow defaults, then task values, then panel.overrides for the current scene. Retries and workflow trials use the same frozen rule. Staged workflows inspect their own slots, so a similarly named slot in another stage is not written by accident.

Custom nodes can register a workflow_slot_adapter with inspect and write methods. The adapter only writes declared inputs and returns a stable identity. Disabling it leaves standard slots available and reports why an adapter-owned slot cannot be controlled.

Custom-node compatibility

Mio submits a ComfyUI API graph. Custom nodes that execute through the backend API can remain in that graph without a dedicated Mio button. Install their packages, models and dependencies on the executing instance. If automatic detection is incomplete, target a field with [mio:prompt=field_name] or a JSON Pointer mapping; one value can feed multiple inputs. Bindings and overrides cannot replace a node link or its node ID / output index. Target the upstream input that stores the actual text or number instead.

Browser-only scripts, virtual frontend nodes and custom submission protocols may need explicit adaptation. Check that the API export contains the required values. ParameterControlPanel supports production jobs after explicitly capturing and saving config.state through the workflow API. Mio records original values before writing, reserves that endpoint, saves results before restoring state, and keeps recovery records after interruptions. Use one canonical address per ComfyUI service and avoid external clients changing its parameters while it runs. Other browser-state plugins still need their own adapters. A custom image output can be tagged [mio:output], but image retrieval still needs standard images in /history; video, audio and custom result formats are not automatically supported.

Import validates the document, compilation applies bindings, and diagnostics check node availability and some model requirements. Only a real run on that instance verifies execution and image results; offline samples do not execute every plugin.
