CHAPTER 01 / THE MIO HANDBOOK

Start here

This is the Mio 4.x handbook: FastAPI + React, port 8788.

Follow the four-step introduction

A new workspace offers four Quick start cards: connect an image service, try one image, read the sample, then write your own first scene. Each card shows its status and next action. Skip it when needed and reopen it from Help → Quick start. Reading the sample does not verify your configured service; test images and normal generation still require an explicit action.

Start Mio

A release needs Python 3.11+. Run the root start.bat or ./start.sh. Source checkouts also need Node.js 20+: run npm ci --prefix web and npm --prefix web run build. Use start.bat --check or ./start.sh --check to diagnose startup. Open http://127.0.0.1:8788.

  1. Connect a serviceFor local rendering, start ComfyUI separately and configure an instance (usually 127.0.0.1:8188). For cloud rendering, add a cloud channel.
  2. Connect an image serviceFor local rendering, import an API-format workflow, check its dependencies and generate one test image. For cloud rendering, configure its address, key and model in Cloud APIs.
  3. Write one panelUse Storyboards, for example {character}, standing by a window, {style}. Write dialogue separately.
  4. Define variablesUse Presets to define character and style. Wait for saving to finish.
  5. Create a generation taskIn Generation tasks, select a storyboard, optional presets and a local workflow or cloud service. Set images per scene and optional dimensions, review the final prompts, then start generation or choose Generate later. Cloud calls may cost money.
  6. Adopt and exportThe first candidate is adopted only if there is no adopted image. Reruns add candidates: adopt a replacement on the board before expecting the reader to change.

For another work, reuse a storyboard and character presets, check the substituted prompt preview and assemble a new album. Creating, editing and assembling do not automatically call a script-writing model.

You can read existing images, edit templates and assemble offline; generation needs a working ComfyUI or cloud service.

Enable an optional professional workspace

Six official workspaces are independent sandbox extensions and start disabled. Choose one under Extensions → Installed; import its folder or ZIP if it is not listed. Inspect its origin, permissions and content digest before explicitly enabling it. Open it from a specific episode's Extensions menu. Installing, enabling or opening a panel does not submit generation or review jobs.

Workspace First steps
Panel Retouch Load candidates and a render profile. Draw a mask, set outpainting or enter an edit instruction, then submit. Compare the result and explicitly confirm adoption.
QA Review Select candidates or the whole episode and explicitly run a visual-model review. Locate issues and filter results before adopting individually or confirming a batch. Scores do not change adoption automatically.
Finalize Studio Load adopted drafts, choose a profile with valid final stages, select frames and submit. Check adoption first: a final replaces its source only if that draft remains adopted. Compare results or restore the original draft.
Variant Workshop Preview combinations and counts before creating versions and explicitly generating candidates. Filter, compare and adopt images for the chosen version before export.
Script Assistant Explicitly generate a proposal, select its operations and apply them. Applying creates a work checkpoint first. Review pacing suggestions separately; stale proposals need a fresh check.
Motion Studio Load adopted images, choose camera moves, duration and cut / fade / slide transitions, then save. Preview playback and available browser voices before exporting offline HTML.

Rendering and model review need the appropriate image, text or vision service configured beforehand. Disable an extension to remove its entry and reject further panel requests; existing work remains. Submitted jobs may continue, so stop them explicitly before disabling. Changed package contents require another digest review and enable action.

For extension trouble, start Mio with the environment variable MIO_SAFE_MODE=1. Safe mode skips every extension and rejects manual enabling. Remove the variable and restart after troubleshooting, then enable only the extensions you trust.
