CHAPTER 05 / THE MIO HANDBOOK

Jobs & uncertain results

The top bar and workshop open the same Generation tasks page for starting, pausing, retrying and selecting images. Execution records are available from task details. Created tasks freeze their parameters and workflow documents; changing recent preferences does not alter them. Generation fills scenes with no adopted image. Reruns create candidates without silently overwriting your selection.

If ComfyUI accepts a job but history or image download is interrupted, its result stays uncertain. With a known prompt ID, reconciliation retrieves it without resubmitting. A lost submission response without an ID still needs manual verification. Cancellation discards results that have not entered the save stage; if saving has already begun, that save finishes before cancellation returns.

Pause affects scheduling, not necessarily a request already accepted upstream. Cancellation is not a refund. For uncertain results, check provider records before resolving or explicitly resubmitting: repeated paid calls can create duplicate charges. Inspect job details for actual failures.
