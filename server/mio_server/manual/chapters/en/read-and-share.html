CHAPTER 06 / THE MIO HANDBOOK

Read, letter & export

Three collectible offline editions

  • Monograph (default): Warm cotton paper, mat-board frames and two-column artwork labels.
  • Nocturne: An obsidian stage, dark frames and centered festival-style subtitles.
  • Folio: Cotton-paper spreads on a linen desk, a shaded book spine and a single-page layout on phones.

All three editions show the complete exported frame without adding a crop. They change offline presentation only; they do not edit the album or generate images. Fit and Seamless remain available as basic reading layouts.

Offline reader controls

A single HTML file carries its runtime and panel images without external requests. Use the arrow keys or Space to turn pages, Home/End to jump to the beginning or end, G for the thumbnail drawer, F for fullscreen, and Esc to close the drawer or lightbox. Mobile readers can swipe horizontally. Click an image to zoom and move between panels; closing the lightbox restores focus.

The floating controls switch single or spread view, immersive captions and ambient light. Thumbnails, progress and the current palette synchronize with the embedded reader room. Reduced-motion preferences shorten page and ambient transitions automatically.

Open an album from the gallery. The reader shows adopted images. In its toolbar, the layout picker changes the presentation template (not the images); the strip canvas arranges panels, gutters, bubbles and sound effects; export opens the export drawer.

Use Export in the album's context or “⋯” menu. Choose a file format, adjust its options, then use the fixed Export button. HTML offers layouts; PDF and image ZIP use panel images; platform slices and long images use the canvas. Layout customization, import and extra settings expand when needed. Multiple albums can share one HTML, PDF or image ZIP (up to 50 episodes); editable projects and creation kits download separately for each album.

Strip, gallery and spread views use the same album; there is no need to create separate works. Reader templates and export formats are separate choices. An HTML template does not become a freely arranged print page; see the current PDF behavior below.

Without a saved layout, the reader shows complete original images with captions underneath, without adding crops or bubbles. Saved layouts retain framing and lettering; continuous reading preserves the full canvas, whitespace and text across panels. By default, only matching text already fully embedded in the same panel is omitted from external captions. Remaining captions appear below each image, or after a saved continuous canvas. Panel views and HTML templates cut text at panel boundaries and use their own spacing. Changing framing, adopted takes or series variables refreshes the preview.

Long album menus scroll to their final action. Moving one or more albums to the trash takes effect directly and can be undone or restored from the trash. Permanent deletion still asks for confirmation.

Deleting a panel also removes its canvas box, crop and lettering, and clears bridges pointing to it. Other panels, independent text and existing whitespace stay in place; adjust spacing manually when needed. Candidate artwork and historical snapshots are retained.

Select an image on the strip canvas to adjust zoom and horizontal/vertical framing, or reset to automatic centre crop. Undo/redo retains the last 100 edits (Ctrl / Cmd + Z, Ctrl / Cmd + Shift + Z, or Ctrl + Y); text fields keep their native editing shortcuts. Undo remains available after saving, but history ends when you leave the canvas. Long images and platform slices preserve saved framing and whitespace. Changes to script aspect ratios only move existing boxes after an explicit layout action.

Pacing suggestions offer compact-strip, lyrical-whitespace and cinematic-wide presets; review before applying. Select a text layer, then use its selection list to choose several layers for alignment, style synchronization or speech/thought-bubble avoidance. A bubble with no safe position stays in place; automatic placement does not resolve every obstruction. These changes remain canvas drafts until saved.

Saving checks the episode revision. If another window saved first, a conflict prevents the old canvas from overwriting it. Keep the local draft and inspect the new version before deciding how to merge. Edits made while a save is in flight remain unsaved and are not erased by the earlier response. Exports use the same saved crops, layers and whitespace, while HTML template spacing, panel-by-panel PDF and long-strip slices retain the differences below.

Output Meaning
HTML album Selected HTML template with individual panel images and template spacing; an offline reader, not an editable project backup.
Image ZIP Panel images, a simple reader and a manifest, without the selected HTML or spread layout. Separate captions appear in its reader.
Album PDF One panel per page, without the selected HTML or spread layout; images are encoded, not a byte-perfect original archive. The captions option does not typeset separate captions into the PDF.
Platform slices / long image The adopted, composited strip, with platform sizing and a real slice preview.

HTML albums and portable ZIP/PDF default to composited panel crops. Disabling in-image lettering (lettered:false in the API) uses original adopted images and also skips saved framing. Strip PDF exports through the API instead paginate the full strip.

Image processing options

Auto starts with lossless metadata cleaning and may compress large inline HTML. Publish encodes WebP up to 2560px on the long side. Archive preserves original bytes only when not compositing lettering; it may retain private workflow metadata. Hiding prompts is a display option, not complete privacy scrubbing.
