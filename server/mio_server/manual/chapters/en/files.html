CHAPTER 09 / THE MIO HANDBOOK

Files & formats

Data is organized as series, episodes, panels, takes and assets, stored in the data folder's database and assets/; there are no JSON files to edit by hand. Storyboard JSON, preset JSON, album templates (imported from the reader's layout picker), image ZIP and project bundles each have their own purpose. Reusable workflows and render profiles live in Workflows & APIs.

Creation kits package selected storyboards, presets, character and style details, workflows and referenced assets. Choose Creation kit ZIP in the workshop export picker, or Export → Creation kit in the album menu and select its storyboards and presets. Import first shows a preview; explicitly bind each profile to services or choose Import now, configure later. Select the kit as the storyboard source in the assembly wizard to reuse it without replacing the workshop.

When creating a task, select a workflow, cloud service or advanced plan directly. Workshop and kit sources both allow a choice for this task without changing source material; explicit panel plans still take priority. Presets supply variables only. Define an exclusions variable yourself and use {exclusions} in a scene's negative prompt. Presets do not append prompts or create a default negative variable.

Choose a kit in the storyboard or preset workshop's source selector to edit it, or open its editor from the assembly wizard. Switching sources saves current edits first and stays put if saving fails. Kit presets can also create a one-panel standby preview album; generation starts only when explicitly requested. Kit edits affect future assembly, while existing albums keep their snapshots.

Select panels to copy or move them between episodes in the same work. Organize actions duplicate or reorder episodes and find, preview and rename variables. Transfers preserve takes, framing and the source canvas's whitespace. Locked content and bubbles crossing the selection boundary require explicit choices. Variable operations preserve escaped double braces and candidate history.
