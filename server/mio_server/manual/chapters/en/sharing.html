CHAPTER 07 / THE MIO HANDBOOK

Sharing editable work

Reader HTML, image ZIP and PDF are reader-facing outputs. .mio.zip is an editable series bundle, not an image ZIP or full server backup.

Export a bundle from an album's "⋯" menu → Export → Editable project, or select several albums in the gallery and use the same format. Import it in Settings → Data & backup → Import .mio.zip. Scripts use the token-protected API: GET /api/v2/series/{id}/bundle and POST /api/v2/bundles (raw ZIP body). Recheck profiles, instance settings and keys after import.

Automation and optional extensions

External programs use token-protected /api/v2: see the API reference and OpenAPI schema. Read the workshop with GET /api/v2/workshop, inspect substitutions with POST /api/v2/workshop/assemble/preview, then assemble with POST /api/v2/workshop/assemble. Supply idempotency_key to avoid duplicate albums when retrying a request. Assembly only creates a snapshot; submit generation separately. Grant read, write, render and admin scopes according to the operations needed.

Create the first token locally; subsequent token and extension management is available through the admin-scoped open API. Extension routes also have v2 versions with declared scopes, and enabled extensions can wrap or replace core operations.

Give a token only the access it needs

In Settings, create an API token with only the scopes the program uses. An album directory only needs read. Add write to edit storyboards or render to start generation. Reserve admin for programs that manage tokens or extensions. The token is shown once; keep it somewhere private and pass it only to the program that needs it.

Notify another program when a task finishes

To have an automation send a notification when generation finishes, enter the receiving URL it provides in Settings → Webhooks and subscribe to job.completed. Send a test notification and check the delivery history. The receiver uses the secret shown at creation to verify X-Mio-Signature.

Troubleshoot extensions in safe mode

If Mio cannot start after you install an extension, stop the running service and temporarily set MIO_SAFE_MODE=1 before starting Mio. In Windows PowerShell, run $env:MIO_SAFE_MODE='1' and then .\start.bat. On macOS or Linux, run MIO_SAFE_MODE=1 ./start.sh. Mio skips extensions for that run. After troubleshooting and disabling the affected extension, unset the variable and restart normally.

Install six optional professional tools

The source repository includes six official independent packages under extensions/. Import a folder or ZIP in Extension market / Installed, review its digest, enable it, then open a specific episode and choose a tool from the Extensions menu beside Board / Script. These tools add no fixed main-navigation entries. Installing, enabling or opening a panel does not generate images. Read the episode, select the targets and explicitly submit. Image services, VLMs and text models may charge for calls.

  • panel-retouch: brush or rectangle masks, an eraser, outpainting and instruction editing. Results are new candidates; the adopted original remains. Disabled edit stages cannot run. Focus the canvas and use arrows to move 1 pixel, or Shift+arrows to move 10 pixels. Space or Enter starts/finishes a stroke; Esc cancels the current stroke. Tab leaves the canvas and finishes the stroke as one undo step.
  • qa-review: select candidates for assessment, then inspect character consistency, composition, dialogue fit and issues for each panel. Composition and image quality are still assessed without dialogue or reference images. Dialogue fit uses the scene's actual speaker, dialogue type and text to check whether the image's emotion, action and setting support the dialogue. It does not require captions or speech bubbles in the image. Dialogue is assessed even without characters or reference images; identity checks cover only characters with a reference image. The card shows the model's 1–5 score, comment and valid vote count. With dialogue, this score contributes 20% of the overall score and must reach 3 to pass. Without dialogue, dialogue fit is marked as not assessed and does not reduce the other scores. Refusals, missing or invalid results, no majority of valid votes and older reports are marked as unknown; a panel with dialogue cannot pass with an unknown result. Review the image, then explicitly adopt or reject candidates. The panel never automatically adopts or rejects images.
  • finalize-studio: select adopted drafts and a multi-stage profile, confirm and submit. A successful final replaces its original only while that original remains adopted; the original is retained.
  • variant-workshop: independently combine character, outfit, scene and style. Ordinary storyboards default to “Storyboard preset variables”; “Structured work bible” is the other source. Unselected axes inherit their current values. Preview up to 24 combinations and save a checked subset; saving does not generate images. Before generating, select versions, scenes and candidates per scene, then confirm the task and image totals. Compare, adopt and export versions separately; generation never adopts automatically.
  • script-assistant: review script and pacing proposals individually, then apply only checked changes. Applying creates a work checkpoint. Stale proposals require a fresh review and cannot overwrite a newer script.
  • motion-studio: save camera movement and duration, then export an offline player. It does not generate images or change adoption.

Original images use temporary media managed by the host and released on replacement or close. Once a file is ready, click the host's download button outside the panel to save it. Panels receive no token and cannot connect directly to the network. Disabling or changing a package revokes subsequent panel requests; re-enable it and reopen the tool from the menu without restarting the host. Already submitted core jobs remain in the queue and require explicit cancellation. Uninstalling does not delete candidates, QA records, variants or camera settings saved in the work.

After a panel request times out at 29 seconds, the host ends that connection and frees its request slot. This does not roll back a server-side write. Check the work or job result before manually retrying; the panel does not automatically resubmit the request.

Replaceable adapters and scripts

Extensions stay decoupled from core files. A cloud image extension registers a cloud_adapter with its title, capabilities, parameter schema and reference-image, negative prompt and seed support. A workflow extension registers a workflow_slot_adapter for slot inspection and writes. Channel-specific settings live in extra_options; ordinary values are frozen with the task and secret-like fields stay out of public snapshots. Enabled adapters appear in discovery and control responses; disabling one makes new requests use core behavior or report the missing adapter. The repository's examples/extensions/offline-cloud-adapter is a network-free minimal example.

standard-image-channels implements explicit Images, Chat image, NovelAI-style and asynchronous polling protocols. comfy-complex-adapters covers multi-slot LoRAs, staged sampling, reference inputs and specific outputs. Try tags or manual mappings first for ordinary API nodes. Reference packages do not install ComfyUI plugins or guarantee arbitrary node compatibility. Adapters never automatically repeat a generation submission; an accepted remote task may continue after local cancellation, which is not a refund.

The source tool clients/python/markdown_album.py turns UTF-8 Markdown into a storyboard, selects presets, submits generation, polls and exports default Monograph HTML and PDF. Automatic adoption requires --adopt-first. Without it, generation stops for manual selection; resume with the same command after adopting images. Keep the token in MIO_TOKEN, outside command arguments and resume files. The neighboring AUTOMATION.md also covers Webhook subscriptions and signature debugging.
