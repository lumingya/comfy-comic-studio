CHAPTER 07 / THE MIO HANDBOOK

Sharing editable work

Reader HTML, image ZIP and PDF are reader-facing outputs. .mio.zip is an editable series bundle, not an image ZIP or full server backup.

Export a bundle from an album's "⋯" menu → Export → Editable project, or select several albums in the gallery and use the same format. Import it in Settings → Data & backup → Import .mio.zip. Scripts use the token-protected API: GET /api/v2/series/{id}/bundle and POST /api/v2/bundles (raw ZIP body). Recheck profiles, instance settings and keys after import.

Automation and optional extensions

External programs use token-protected /api/v2: see the API reference and OpenAPI schema. Read the workshop with GET /api/v2/workshop, inspect substitutions with POST /api/v2/workshop/assemble/preview, then assemble with POST /api/v2/workshop/assemble. Supply idempotency_key to avoid duplicate albums when retrying a request. Assembly only creates a snapshot; submit generation separately. Grant read, write, render and admin scopes according to the operations needed.

Create the first token locally; subsequent token and extension management is available through the admin-scoped open API. Extension routes also have v2 versions with declared scopes, and enabled extensions can wrap or replace core operations.

Install six optional professional tools

The source repository includes six independent packages under examples/extensions/. Import a folder or ZIP in Extension market / Installed, review its digest, enable it, then open a specific episode and choose a tool from the Extensions menu beside Board / Script. These tools add no fixed main-navigation entries. Installing, enabling or opening a panel does not generate images. Read the episode, select the targets and explicitly submit. Image services, VLMs and text models may charge for calls.

  • panel-retouch: rectangle or polygon masks, outpainting and instruction editing. Results are new candidates; the adopted original remains. Disabled edit stages cannot run.
  • qa-review: select candidates for assessment, then inspect per-panel scores and issues. It never automatically adopts or rejects images.
  • finalize-studio: select adopted drafts and a multi-stage profile, confirm and submit. A successful final replaces its original only while that original remains adopted; the original is retained.
  • variant-workshop: derive versions from Bible styles and character appearances, then generate, compare, adopt and export each version separately. Generation never adopts automatically.
  • script-review: review per-panel and sentence-level diffs, then apply only checked operations. Revision conflicts require a fresh review and cannot overwrite a newer script.
  • motion-studio: save camera movement and duration, then export an offline player. It does not generate images or change adoption.

Original images use temporary media managed by the host and released on replacement or close. Once a file is ready, click the host's download button outside the panel to save it. Panels receive no token and cannot connect directly to the network. Disabling or changing a package revokes subsequent panel requests; re-enable it and reopen the tool from the menu without restarting the host. Already submitted core jobs remain in the queue and require explicit cancellation. Uninstalling does not delete candidates, QA records, variants or camera settings saved in the work.

Replaceable adapters and scripts

Extensions stay decoupled from core files. A cloud image extension registers a cloud_adapter with its title, capabilities, parameter schema and reference-image, negative prompt and seed support. A workflow extension registers a workflow_slot_adapter for slot inspection and writes. Channel-specific settings live in extra_options; ordinary values are frozen with the task and secret-like fields stay out of public snapshots. Enabled adapters appear in discovery and control responses; disabling one makes new requests use core behavior or report the missing adapter. The repository's examples/extensions/offline-cloud-adapter is a network-free minimal example.

standard-image-channels implements explicit Images, Chat image, NovelAI-style and asynchronous polling protocols. comfy-complex-adapters covers multi-slot LoRAs, staged sampling, reference inputs and specific outputs. Try tags or manual mappings first for ordinary API nodes. Reference packages do not install ComfyUI plugins or guarantee arbitrary node compatibility. Adapters never automatically repeat a generation submission; an accepted remote task may continue after local cancellation, which is not a refund.

The source tool clients/python/markdown_album.py turns UTF-8 Markdown into a storyboard, selects presets, submits generation, polls and exports default Monograph HTML and PDF. Automatic adoption requires --adopt-first. Without it, generation stops for manual selection; resume with the same command after adopting images. Keep the token in MIO_TOKEN, outside command arguments and resume files. The neighboring AUTOMATION.md also covers Webhook subscriptions and signature debugging.
