CHAPTER 07 / THE MIO HANDBOOK

Sharing editable work

Reader HTML, image ZIP and PDF are reader-facing outputs. .mio.zip is an editable series bundle, not an image ZIP or full server backup.

Export a bundle from an album's "⋯" menu → Export → Editable project, or select several albums in the gallery and use the same format. Import it in Settings → Data & backup → Import .mio.zip. Scripts use the token-protected API: GET /api/v2/series/{id}/bundle and POST /api/v2/bundles (raw ZIP body). Recheck profiles, instance settings and keys after import.

Automation and optional extensions

External programs use token-protected /api/v2: see the API reference and OpenAPI schema. Read the workshop with GET /api/v2/workshop, inspect substitutions with POST /api/v2/workshop/assemble/preview, then assemble with POST /api/v2/workshop/assemble. Supply idempotency_key to avoid duplicate albums when retrying a request. Assembly only creates a snapshot; submit generation separately. Grant read, write, render and admin scopes according to the operations needed.

Editing, QA, finalization, variants, the script assistant and motion export have backend APIs, without default buttons in the main interface. The repository's examples/extensions/qa-review demonstrates optional QA: installation and activation do not submit work, an explicit command does, and images are never adopted automatically. Disabled or changed extensions reject new calls immediately; reactivation requires a restart to mount new routes. Create the first token locally; subsequent token and extension management is available through the admin-scoped open API. Extension routes also have v2 versions with declared scopes, and enabled extensions can wrap or replace core operations.

Extensions stay decoupled from core files. A cloud image extension registers a cloud_adapter with its title, capabilities, parameter schema and reference-image, negative prompt and seed support. A workflow extension registers a workflow_slot_adapter for slot inspection and writes. Channel-specific settings live in extra_options; ordinary values are frozen with the task and secret-like fields stay out of public snapshots. Enabled adapters appear in discovery and control responses; disabling one makes new requests use core behavior or report the missing adapter. The repository's examples/extensions/offline-cloud-adapter is a network-free minimal example.
