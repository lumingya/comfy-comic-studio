CHAPTER 07 / THE MIO HANDBOOK

分享与可编辑作品包

给读者用 HTML、图片 ZIP 或 PDF；给另一个 Mio 工作区继续编辑，用 .mio.zip 作品包。两种 ZIP 不是同一种格式，不要把图片包当成项目导入。

导出作品包：画册的「⋯」菜单 →「导出」→「可编辑源文件」，或在画册集多选后点「导出」并选择相同格式。导入：「设置 → 数据与备份 → 导入 .mio.zip」。脚本调用用带令牌的 /api/v2：导出 GET /api/v2/series/{id}/bundle，导入 POST /api/v2/bundles（请求体是 ZIP 原始字节）。

作品包主要搬运作品内容和相关资产，并非完整服务器备份；实例连接、API 密钥、出图配置和扩展仍应单独核对。分享前检查角色参考图、提示词和图像元数据。

外部程序与可选扩展

自动化使用带令牌的 /api/v2，接口清单见 API 文档 与 OpenAPI。读取工坊用 GET /api/v2/workshop，替换预览用 POST /api/v2/workshop/assemble/preview，装配用 POST /api/v2/workshop/assemble。装配可传 idempotency_key 防止网络重试重复创建；只创建快照，生成需另行提交。按操作授予 read、write、render 或 admin 权限。

首个令牌在本机创建，后续令牌与扩展管理可通过带 admin 权限的开放 API 完成。 扩展自定义路由也有 v2 版本，权限由扩展明确声明；核心操作可由已启用扩展包装或替换。

给令牌选择最少够用的权限

在设置的「API 访问令牌」区域创建令牌时，只给程序够用的权限。例如，只显示画册目录的程序选「读取」（read）；需要修改分镜时加「写入」（write），发起生成时加「出图」（render）。管理令牌或扩展的程序才需要「管理」（admin）。令牌只显示一次，把它交给使用它的程序并妥善保存。

让外部程序收到完成通知

比如希望自动化工具在生成任务结束时发通知，在设置的 Webhook 区域填入该工具提供的接收地址，订阅 job.completed。用「测试」发送一条测试通知，再到投递记录查看是否收到。接收端使用创建时显示的密钥校验 X-Mio-Signature。

用安全模式排查扩展

安装扩展后如果工作室启动不了，先停止当前服务，再临时设置环境变量 MIO_SAFE_MODE=1，重开 Mio。Windows PowerShell 中先执行 $env:MIO_SAFE_MODE='1'，再执行 .\start.bat；macOS / Linux 可运行 MIO_SAFE_MODE=1 ./start.sh。这次启动会跳过所有扩展。排查完并停用有问题的扩展后，去掉环境变量，再正常启动。

按需安装六个专业工具

六个官方独立包在源码的 extensions/ 中，可在「扩展市场 / 已安装」导入目录或 ZIP，审阅摘要后启用，再从具体话「挑图 / 分镜」旁的「扩展」菜单选择工具。 它们不新增主导航；安装、启用和打开面板都不会出图。 先点击读取，再选择对象并明确提交。图像服务、VLM 与文本模型可能计费。

  • panel-retouch 单格精修：画笔/矩形蒙版、橡皮擦、外扩与指令编辑；结果新增候选，原采用图保留。停用的编辑阶段不能运行。 画布聚焦后，用方向键移动 1 像素，Shift+方向键移动 10 像素；Space 或 Enter 开始/结束笔画，Esc 取消当前笔画。Tab 离开画布时结束当前笔画，可一次撤销。
  • qa-review 候选评审：勾选候选后评审，逐幕查看评分与问题；不自动采用或淘汰。
  • finalize-studio 成品精修：选择已采用草稿与多阶段配置，确认后执行；成功成品接替仍采用的原草稿，原图继续保留。
  • variant-workshop 变体工坊：角色、服装、场景、画风是四个独立轴。普通分镜默认从「分镜预设变量」读取，也可切换到「结构化设定集」；未选轴沿用原值。先预览最多 24 个组合，勾选要保存的子集；保存不会出图。生成前再选择版本、分幕与每幕候选数，核对任务和图片总量；分别对比、采用和导出，生成不自动采用。
  • script-assistant 剧本助手：逐项审阅剧本与节奏提案，勾选后才应用；应用前建立作品检查点，过期提案须重新审阅，不覆盖新稿。
  • motion-studio 动态漫：设置镜头运动和时长，保存后导出离线播放器；不生成图片或修改采用图。

需要原图时，面板使用宿主管理的临时图片；换图和关闭时自动释放。文件准备好后，还需点击面板外的宿主下载按钮保存。 面板不会收到令牌，也不能自行联网。停用或文件变动立即撤销后续面板请求；重新启用后从菜单重新打开工具，无需重启宿主。 已提交任务仍由队列管理，需要停止时明确取消；卸载不删除已保存到作品中的候选、评审、变体或镜头。

面板请求 29 秒超时后，宿主会中断本次连接并释放请求名额，但这不代表后端写入已撤销。先核对作品或任务是否已有结果，再手动重试；面板不会自动重复提交。

可替换的适配器与脚本

二次开发不需要修改核心：云端出图扩展通过 cloud_adapter 注册标题、能力、参数 schema 与参考图/负面词/种子支持；工作流扩展通过 workflow_slot_adapter 声明槽位识别和写入。渠道专属参数保存在 extra_options，普通配置随任务冻结，密钥类字段不会进入公开快照。启用后它们会出现在适配器发现接口和工作流控制面，停用后新请求立即回到核心能力或报告缺少适配器。仓库中的 examples/extensions/offline-cloud-adapter 是可离线测试的最小示例。

standard-image-channels 提供 Images、Chat 图像、NovelAI 风格与异步轮询的明确协议； comfy-complex-adapters 提供多槽 LoRA、分阶段采样、参考图和特殊输出适配。 普通 API 节点仍先用标签或手动映射，参考包不会自动安装 ComfyUI 插件，也不保证任意节点兼容。 云端生成请求不会在适配器内自动重复提交；已发出的远端任务可能继续运行，取消不代表退款。

源码中的 clients/python/markdown_album.py 可从 UTF-8 Markdown 建分镜、选预设、 提交生成、轮询并导出默认 Monograph HTML 和 PDF；自动采用必须明确传 --adopt-first。 省略时生成后等待人工挑图，再用原命令续跑。令牌放在 MIO_TOKEN 环境变量， 不放命令行或续跑文件；Webhook 订阅与签名调试见同目录的 AUTOMATION.md。
