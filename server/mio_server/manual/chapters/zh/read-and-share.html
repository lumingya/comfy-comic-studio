CHAPTER 06 / THE MIO HANDBOOK

阅读、排版与导出

三套典藏离线画册

  • 典藏画集 · Monograph（默认）：暖白棉纸、卡纸画框与双栏作品铭牌。
  • 暗房放映 · Nocturne：黑曜石舞台、深灰画框与居中字幕。
  • 精装对页 · Folio：亚麻展桌、棉纸双页与书脊光影，手机上自动改为单页。

三套模板均完整展示导出的画面，不额外裁切；只改变离线阅读呈现，不会修改原画册或生成新图片。 原图适配与无缝长卷仍作为基础阅读版式保留。

离线阅读器控制

单文件 HTML 自带阅读运行时与每张图，不依赖外链。阅读时可用方向键或空格翻幕，Home/End 跳到首尾，G 打开缩略目录，F 请求全屏，Esc 关闭目录或灯箱。移动端支持左右滑动；点击画面可放大并用左右按钮切换，退出后焦点恢复到原画面。

控制栏可以切换单页/双页、沉浸无字模式和氛围光。缩略图、进度与当前幕颜色会同步到内嵌阅读室；系统开启减少动态效果时自动降低翻页与环境光过渡。

删除分镜会同步移除对应画格、裁切与文字，解除指向它的跨格引用。其他格、独立文字及原有留白不自动压缩；需要收拢版面时再手动调整。候选素材和历史快照保留。

选中画布中的图片后，可用放大、水平取景、垂直取景调整构图，或恢复自动居中裁切。撤销 / 重做支持最近 100 步修改（Ctrl / ⌘ + Z，Ctrl / ⌘ + Shift + Z 或 Ctrl + Y）；输入框内保留文字编辑快捷键。保存后仍可撤销，离开画布后不保留此历史。长图与平台切片使用保存的构图和留白，修改分镜比例后需要明确重新排版才会改变格的位置。

「自动节奏」可选择紧凑条漫、抒情留白或电影宽银幕，先审阅再应用。选中文字后可从选择列表多选， 进行对齐、同步样式或对所选对白/心声运行气泡避让；没有安全位置的气泡保留原位，不保证自动修好所有遮挡。 这些调整仍是画布草稿，需要保存。

保存会核对当前话的修订号。另一窗口先保存导致冲突时，不会把旧画布覆盖上去；先保留本页草稿， 核对新版本后再决定如何合并。保存请求发出后继续编辑的内容仍标为未保存，不会被较早返回的保存结果抹掉。 各导出继续使用同一份已保存的裁切、图层和留白，但 HTML 模板间距、逐格 PDF 与长条切片仍有下述区别。

从 画册集 打开画册。阅读室以已采用图片为准。顶栏的「版式」切换展示模板，只改变阅读外观，不会生成图片；「排版」打开条漫画布，调整分格、留白、气泡与拟声字；「导出」打开导出抽屉。

画册的右键或「⋯」菜单统一从「导出」进入。先选择导出格式，再调整相关选项，最后点底部「导出」。HTML 可以选择版式；PDF 和图片 ZIP 使用逐格图片；平台切片与长图使用画布。自定义版式、导入和更多设置按需展开。多选画册可合并导出 HTML、PDF 或图片 ZIP（最多 50 话），源文件与创作套装则每本单独下载。

不需要为条漫、画册或双页阅读分别创建作品：它们使用同一份画册内容。阅读模板与导出格式分别选择；HTML 模板不会自动转成可自由分格的印刷页面，PDF 的当前行为见下表。

没有保存排版时，阅读器显示完整原图与图下旁白，不自动裁切或添加气泡。保存过排版后，单页与双页使用保存的取景和嵌字；连续阅读保留完整画布、留白与跨格文字。默认只去掉已经完整嵌入同格的重复正文，其余旁白继续显示；连续画布的未嵌正文列在画布后。单格阅读及 HTML 模板会在格界截断格外文字，间距由模板决定。修改裁切、采用图或作品变量后，预览会更新。

画册菜单可以直接滚动到末项。单册或批量「移入回收站」后可撤销，也可到回收站恢复；永久删除仍需要确认。

输出 用途与区别
单文件 HTML 画册 当前 HTML 模板、样式与逐格图片打包在网页内，可离线阅读。模板间距代替原条漫画布间距，不是可编辑工作区备份。
图片 ZIP 逐格图片文件、简单阅读页与清单，不使用当前 HTML 或双页模板。独立台词可显示在简单阅读页。
图片画册 PDF 每格一页，不继承 HTML 或双页模板，也不等于整条条漫切页。PDF 会编码图像，不是原图字节归档；“显示台词”不会把独立台词排进 PDF。
平台切片 / 长图 基于采用图和条漫画布合成；切片按平台宽度、高度限制拆分。先检查真实切片预览。

HTML 画册与图片 ZIP / PDF 默认使用合成后的逐格图片；关闭图片内排字（API lettered:false）会使用原始采用图，同时跳过保存的裁切。通过 API 导出的条漫 PDF 则沿完整条漫画布切页。

图片处理选项

  • 自动：优先无损清洗；单文件 HTML 的内嵌图像超出预算时改为轻量发布。
  • 无损清洗：对支持的原始 PNG / JPEG / WebP 去除提示词、工作流或 EXIF 等相关容器元数据，不重新生成画面。
  • 轻量发布：重新编码 WebP，长边不超过 2560px，适合分享。
  • 无损归档：没有排字裁切时保留原图字节及可能的工作流元数据，只建议本地存档。有排字的图片是重新合成的 PNG，不再是原始文件。

显示 / 隐藏台词和提示词是呈现选项，不是全面隐私清理。发给别人之前检查导出内容；原图、提示词和嵌入的工作流可能包含私人信息。
