CHAPTER 04 / THE MIO HANDBOOK

分镜、预设与变量

分镜是可复用模板，预设保存变量。提示词和台词都可以使用 {变量名}；例如自行创建「负向词」变量，再在分镜的负向提示词中填写 {负向词}。只有显式引用的内容才会展开，预设不自动追加正负提示词，也不默认创建负向词变量。

列表标题太长时，可拖动分镜列表和详情区之间的细分割线；实例、工作流、出图配置与云端渠道页也支持。分割线获得键盘焦点后，用左右方向键调整，Home / End 移到宽度边界，双击恢复默认。宽度按页面保存在当前浏览器；窄窗口会优先保留两侧可用空间。预设工坊保持单列编辑。

规则 实际行为
优先级 内建变量 → 作品变量 → 每格的 $变量名 覆盖。后者优先。
多个预设 按向导显示的选择顺序合并，可调整先后；同名变量以后面的预设为准。预览显示实际生效的来源。
嵌套与字面花括号 值可以引用其他变量；用 {{name}} 输出字面 {name}。提示词中未知变量保留原文，阅读台词中的未知普通变量留空，不会自动猜值。
装配快照 已装配画册保存分镜、预设、变量和画布设置。之后修改工坊模板，不会追改已装配的画册；要应用新模板，重新装配。
预设类型 预设工坊里的变量都是文本变量。

装配的最后一步按分幕预览正负提示词和阅读台词。缺失变量可定位到对应幕与字段，并填写仅供本次作品使用的值。优先级从高到低为：逐格 $变量、本次补值、所选预设（后者优先）、工坊变量、内置变量。空字符串是有效值，可用于主动留空；循环引用与过深引用会提示核对。提示词中的未知变量保留原文，方便使用工作流通配符；阅读台词中的未知普通变量会留空。预览不访问图像服务，扩展仍可在生成时追加处理。

分镜工坊编辑标题、正负提示词、台词与参数。装配后，在「生成任务」里打开画册的逐幕编辑，可以设置镜头、出场角色、参考图、控制图、每幕出图覆盖，并查看历史。自动保存失败时先查看错误，不要立刻切换页面。装配请求失败后可在同一向导重试；未改请求时会复用原装配结果，不重复建画册。
