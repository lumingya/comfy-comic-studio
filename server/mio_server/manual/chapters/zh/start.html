CHAPTER 01 / THE MIO HANDBOOK

快速开始

适用于 Mio 4.x：FastAPI 后端 + React 界面，默认端口 8788。

先跟着四步引导走一遍

首次打开工作区会显示快速开始：连接图像服务、试出第一张图、翻阅示例画册，再写自己的第一幕。四张卡片会显示当前状态和下一步入口，可以跳过，之后从「帮助 → 快速开始」重新打开。查看示例不代表本机服务已验证；测试图片和正式生成都需要你明确操作。

启动与检查

发布包需要 Python 3.11+。解压后双击根目录 start.bat（Windows），或运行 ./start.sh（macOS / Linux）。首次启动会创建虚拟环境并安装依赖。源码版另需 Node.js 20+： 

npm ci --prefix web
npm --prefix web run build
# Windows
start.bat --check
start.bat
# macOS / Linux
./start.sh --check
./start.sh

浏览器打开 http://127.0.0.1:8788。开发界面用 npm --prefix web run dev；Vite 会把 API、WebSocket 和本手册转发到 8788。Mio 不会代你启动 ComfyUI。

  1. 连接图像服务在 工作流与 API 配置 → ComfyUI 实例 填写地址并测试。默认 http://127.0.0.1:8188。只用云端出图的话，见下一节。
  2. 准备图像服务本地出图：在工作流导入 API 格式工作流，检查依赖后「试生成一张」。云端出图：在云端 API配置地址、密钥与模型。第一次只做一幕、一张图。
  3. 写一幕分镜进入 创作工坊 → 分镜工坊，新建分镜并添加一幕。正向提示词可写 {character}, standing by a window, {style}。台词单独填写，不需要把文字绘入图片。
  4. 填预设进入 预设工坊，定义 character（如 a young adult traveler, blue jacket）与 style（如 anime, soft lighting）。等待保存完成再装配。
  5. 创建生成任务进入生成任务，选择分镜、可选预设、本地工作流或云端服务，设置每幕张数与尺寸。在最后一步检查最终提示词和台词，点击「开始生成」；只想保存任务时选择「稍后生成」。
  6. 检查结果并导出队列会自动采用每幕的首个候选（不替换已有采用图）。从 画册集 打开画册；如果重跑后画面不变，去出图板采用新图。失败原因看 任务详情。

重复创作时可以直接选用已有分镜与角色预设：替换预设变量、检查提示词预览，再装配成新的画册。创建、编辑与装配都不会自动调用写剧本模型。

查看已有图片、编辑分镜和装配可以离线进行；真正出图需要可用的 ComfyUI 或云端服务，云端可能计费。

按需启用六个官方专业工作台

六个工作台是独立、默认停用的沙箱扩展，不是日常创作的前置步骤。在「扩展 → 已安装」选择工作台；未列出时可导入对应文件夹或 ZIP。先核对来源、权限与内容摘要，再明确启用。从具体话的「扩展」菜单打开面板；安装、启用和打开都不提交生成或质检任务。

工作台 第一次怎么用
单格精修 读取候选与出图配置，绘制蒙版、设置外扩或填写编辑指令后再提交。完成后对照原图，明确确认「采用此候选」。
质检与挑图 选择候选或整话，明确提交视觉模型评审。按问题定位分幕、筛选结果，再逐格采用或明确批量采用；评分不会自行替你换图。
成品精修 读取已采用草稿，选择含有效成品阶段的出图配置，勾选画格后提交。先核对采用行为：草稿仍被采用时，完成的成品会接替它；可对比并恢复原草稿。
变体工坊 先预览画风、外观等组合与数量，再创建版本并明确生成。筛选和比较候选，采用指定版本的画面后导出。
剧本助手 明确生成提案，逐项勾选后应用；应用前会建立作品检查点。节奏建议也先审阅再应用，过期提案需重新核对。
动态漫工作台 读取已有采用图，选择镜头、时长和 cut / fade / slide 转场，保存后试听、试播，再导出离线 HTML。配音试听依浏览器可用语音。

需要生成或评审的操作依赖已配置的图像或文本、视觉服务；面板不会替你配置服务。停用会立即撤除入口并拒绝后续面板请求，作品保留；已提交的任务可能继续，需在停用前明确停止。扩展包内容改变后须重新审阅摘要并启用。

扩展异常时，可设置环境变量 MIO_SAFE_MODE=1 后启动 Mio；安全模式跳过所有扩展，也拒绝手动启用。排查后移除此环境变量并重启，再按需启用可信扩展。
