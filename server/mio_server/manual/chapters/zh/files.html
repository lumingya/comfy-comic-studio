CHAPTER 09 / THE MIO HANDBOOK

文件与格式

「创作套装」把所选分镜、预设、角色、画风、工作流与引用素材放在一起。工坊的导出格式可选「创作套装 ZIP」；画册菜单选「导出」，再选「创作套装」并勾选需要的分镜与预设。导入菜单里选择「导入创作套装」，先查看内容，再为每份出图配置明确选择服务或「先导入，稍后配置」。装配第一步的「分镜来源」可反复选择套装，不会改写原工坊。

新建任务时可直接选择本地工作流、云端服务或高级方案。工坊与套装都支持本次选择，不改变来源资料；单独设置过方案的分幕仍优先使用自己的方案。

要修改套装，在分镜工坊或预设工坊的「来源」里选择它，或从装配向导进入套装编辑。切换来源前会保存当前编辑；保存失败时留在原来源。套装的预设也能独立试绘：先创建一格待生成画册，再明确开始生成。编辑套装只影响之后装配的作品，不追改已装配画册。

多选分幕后可复制或移动到同作品的其他话；「整理」菜单可复制整话、上下调整顺序或查找与整理变量。跨话整理会保留候选图、裁切和原话留白；锁定内容及跨边界气泡需明确选择处理方式。变量修改先预览差异，只处理完整变量引用，双大括号转义与历史候选不改。

Mio 以作品、分集、分格、候选和资产为核心，数据都在数据目录的数据库与 assets/ 里，不需要手动编辑 JSON 文件。

分镜工坊的 JSON 导入 / 导出用于分镜模板；预设工坊的导入 / 导出用于文本预设；画册模板在阅读室「导出」中的版式选择区导入；作品备份请参考上一节。可复用工作流和高级出图方案在“工作流与 API 配置”中管理。
