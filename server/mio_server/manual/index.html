01 · 快速开始

适用于 Mio 4.x：FastAPI 后端 + React 界面，默认端口 8788。

启动与检查

发布包需要 Python 3.11+。解压后双击根目录 start.bat（Windows），或运行 ./start.sh（macOS / Linux）。首次启动会创建虚拟环境并安装依赖。源码版另需 Node.js 20+：

npm ci --prefix web
npm --prefix web run build
# Windows
start.bat --check
start.bat
# macOS / Linux
./start.sh --check
./start.sh

浏览器打开 http://127.0.0.1:8788。开发界面用 npm --prefix web run dev；Vite 会把 API、WebSocket 和本手册转发到 8788。Mio 不会代你启动 ComfyUI。

  1. 连接图像服务在 工作流与 API 配置 → ComfyUI 实例 填写地址并测试。默认 http://127.0.0.1:8188。只用云端出图的话，见下一节。
  2. 确定真正要运行的出图配置本地出图：导入可用的 API 格式工作流，在 出图配置 的基础出图工作流里选择它。云端出图：添加渠道后，在出图配置中「新建云端配置」并选择渠道，无需导入工作流。导入工作流或添加渠道不会自动切换出图配置。第一次只做一幕、一个候选。
  3. 写一幕分镜进入 创作工坊 → 分镜工坊，新建分镜并添加一幕。正向提示词可写 {character}, standing by a window, {style}。台词单独填写，不需要把文字绘入图片。
  4. 填预设进入 预设工坊，定义 character（如 a young adult traveler, blue jacket）与 style（如 anime, soft lighting）。等待保存完成再装配。
  5. 检查、装配，再开始生成进入 装配与队列，选择分镜、预设和出图配置，在最后一步查看各幕替换后的提示词与台词，再命名并添加待命任务。装配只创建快照，不请求模型；任务卡上的“开始生成”才会调用图像服务。
  6. 检查结果并导出队列会自动采用每幕的首个候选（不替换已有采用图）。从 画册集 打开画册；如果重跑后画面不变，去出图板采用新图。失败原因看 任务详情。

重复创作时可以直接选用已有分镜与角色预设：替换预设变量、检查提示词预览，再装配成新的画册。创建、编辑与装配都不会自动调用写剧本模型。

查看已有图片、编辑分镜和装配可以离线进行；真正出图需要可用的 ComfyUI 或云端服务，云端可能计费。

02 · 图像服务与密钥

服务配置位置与必要条件容易混淆的地方
本地 ComfyUI实例中保存地址；先在 ComfyUI 自己的页面跑通工作流。实例在线 ≠ 工作流的节点和模型都已安装。
OpenAI Images / NovelAI云端出图中保存类型、服务地址、模型与 API Key。渠道保存后，还要在出图配置里把出图方式切到「云端出图」并选择渠道。
聊天接口出图在云端出图里新建 chat_image 渠道，填写地址与密钥。未指定渠道且没有默认渠道时，使用「设置 → 模型与连接」中的连接与图像模型；普通聊天接口不一定会返回图片。

出图配置的出图方式二选一：本地 ComfyUI 运行基础出图工作流；云端出图 把请求发给所选渠道，不会自动运行配置中保留的本地阶段。需要分别出图时，建两份出图配置，分批提交。通过 API 明确启用的「云端 + 本地精修」会显示为混合路线，只有这种路线会在云端完成后接着运行本地工作流。

装配显示所选配置的路线与渠道；每格覆盖的配置优先于画册默认配置。顶栏「出图配置」直接打开配置页；首页和打开的开箱检查按工坊默认配置检查，逐格编辑区检查当前格。云端「已配置」仅说明已选连接，不代表服务在线或额度充足；查看页面不会发起付费试图。渠道留空时先使用默认渠道，两者都留空才使用模型连接。

云端参数如何生效

逐格设置的画幅、负向与参考图随任务保存。渠道里的负向作为附加约束，渠道尺寸只在没有分镜画幅时作为默认值。提交后修改模板或渠道生成选项，不会追改任务；删除渠道或改变渠道类型会使旧任务明确失败。

OpenAI Images 使用逐格尺寸，负向写入提示语，不发送种子；聊天接口的尺寸与负向都是提示约束，不保证输出精确像素，也不发送种子。NovelAI 使用独立负向和固定种子，尺寸按 64 对齐，超范围种子转为 32 位并留下记录。参考图的实际效果取决于服务，NovelAI 的 vibe 条件不等同于锁定人物身份。

放大候选后展开「云端生成参数」，可对照请求值、实际提交值、输出图片尺寸与参考图来源。不支持种子的渠道不会显示一个虚假的生效种子。自动参考图优先选择出场角色，再用剩余位置补充场景与所选风格，默认最多四张；手动参考图按原顺序全部发送，关闭参考图时不发送图片。自定义聊天模型也会收到全部选定图片，数量超出服务限制时会明确报错。

不要把 API Key 写进提示词、截图、工作流说明或公开的分享包。页面返回的密钥是掩码，原样保存会保留已有密钥。

云端适配器有离线请求 / 响应测试，但并不代表所有真实服务商或代理都已实测。先用中性题材、一个候选试跑，并确认你的服务商支持所选接口。

03 · 工作流与出图配置

导入后先查看预检，再明确保存。预检列出已识别绑定、歧义和需要的节点 / 模型；详情默认折叠。输出映射选择输出节点，普通参数映射选择真正保存值的输入。诊断时可选择分支，检查实际选中的图；插件自身的校验仍以 ComfyUI 为准。

工作流是 ComfyUI 节点图；出图配置决定运行哪些工作流、候选数、阶段和实例。装配选择的是出图配置，不是工作流文件本身。

  1. 在 ComfyUI 导出 API 格式 JSON（节点含 class_type 和 inputs），再导入 Mio。带 nodes/links 的可视化编辑器 JSON 不能直接作为 API 工作流。
  2. 内置工作流只作起点：先复制，再修改。把 CheckpointLoaderSimple 等节点里的模型名换成你安装的真实文件名；可在 JSON 编辑器中调整节点图与配置。
  3. 通过节点标题标签（如 [mio:prompt]、[mio:seed]）或配置中的 JSON Pointer 映射连接正负提示词、种子、宽高。使用工作流的编译预览和诊断检查映射与缺失节点。
  4. 在出图配置的基础出图工作流里选择这份工作流，保存；装配时明确选择此配置。有多个阶段时，后一阶段要接上一步的图片，工作流里必须有 [mio:init] 输入，并把「阶段图像输入」设为「接上一步输出」。未启用的阶段不会执行。

原始提示词模式保留你写的文本；自动编译模式才会组合设定集、景别、风格等结构化字段。更改工作流不会自动刷新已经提交到任务引擎的请求快照；需要明确重新提交任务。

显式混合任务会在提交前检查并固定本地精修工作流、参数与实例选择；云端运行期间修改或删除配置，不会替换该任务已固定的后续工作流。纯云端生成的候选可直接采用；进一步精修仍可主动通过专业 API 调用。

自定义节点与插件的兼容范围

Mio 提交的是 ComfyUI API 节点图。自定义节点只要能在 ComfyUI 后端通过 API 执行，就可保留在图中；不需要等待 Mio 为每个插件增加专用按钮。节点包、模型和依赖仍需在实际执行的 ComfyUI 实例上安装。

  • 自动识别不完整时，可用节点标题 [mio:prompt=字段名] 指定字段，或用 JSON Pointer 映射到节点输入。一个值可写到多个输入；高级 JSON 编辑保留。绑定与参数覆盖不能覆盖节点连线或其中的节点编号 / 输出序号；需要修改值时，映射到上游节点实际保存文本或数值的输入。
  • 依赖 ComfyUI 网页脚本的控件、前端虚拟节点或特殊提交协议，不能仅凭导入成功证明可用。先确认 API 导出中已包含实际执行所需的值，再检查编译预览。ParameterControlPanel 已支持正式任务，须先通过工作流 API 捕获并保存 config.state；Mio 在写入前保存原值，独占该服务，结果落盘后恢复参数，中断后保留恢复记录。同一个 ComfyUI 使用唯一地址登记，执行期间避免其他客户端修改参数；其他前端状态插件仍需单独适配。
  • 自定义图片输出节点可标记 [mio:output]；最终取图仍要求服务在 /history 中返回标准 images。只返回视频、音频或自定义结果结构的节点不等于可直接作为漫画图片输出。
  • 导入成功证明格式可读；编译成功证明绑定能应用；诊断检查节点与部分模型条件。最终是否能生成预期图片，仍需在对应实例试跑。离线样本测试不等于执行了所有插件。

04 · 分镜、预设与变量

分镜是可复用模板，预设是变量表。提示词和台词都可以使用 {变量名}。例如台词 {character_display_name}：我们到了。 会在阅读 / 导出时使用装配后画册的变量值。

列表标题太长时，可拖动分镜列表和详情区之间的细分割线；实例、工作流、出图配置与云端渠道页也支持。分割线获得键盘焦点后，用左右方向键调整，Home / End 移到宽度边界，双击恢复默认。宽度按页面保存在当前浏览器；窄窗口会优先保留两侧可用空间。预设工坊保持单列编辑。

规则实际行为
优先级内建变量 → 作品变量 → 每格的 $变量名 覆盖。后者优先。
多个预设按向导显示的选择顺序合并，可调整先后；同名变量以后面的预设为准。预览显示实际生效的来源。
嵌套与字面花括号值可以引用其他变量；用 {{name}} 输出字面 {name}。提示词中未知变量保留原文，阅读台词中的未知普通变量留空，不会自动猜值。
装配快照已装配画册保存分镜、预设、变量和画布设置。之后修改工坊模板，不会追改已装配的画册；要应用新模板，重新装配。
预设类型预设工坊里的变量都是文本变量。

装配的最后一步按分幕预览正负提示词和阅读台词。缺失变量可定位到对应幕与字段，并填写仅供本次作品使用的值。优先级从高到低为：逐格 $变量、本次补值、所选预设（后者优先）、工坊变量、内置变量。空字符串是有效值，可用于主动留空；循环引用与过深引用会提示核对。提示词中的未知变量保留原文，方便使用工作流通配符；阅读台词中的未知普通变量会留空。预览不访问图像服务，扩展仍可在生成时追加处理。

分镜工坊编辑标题、正负提示词、台词与参数。装配后，在「装配与队列」里打开画册的逐格编辑，可以设置镜头、出场角色、参考图、控制图、每格出图覆盖，并查看历史。自动保存失败时先查看错误，不要立刻切换页面。装配请求失败后可在同一向导重试；未改请求时会复用原装配结果，不重复建画册。

05 · 队列、候选与失败恢复

“装配与队列”展示待生成画册；“任务”页展示引擎中的具体执行批次。装配成功不代表图像已经生成，任务完成也不代表所有候选都被采用。

  • 开始生成：只补齐没有采用图的分幕。首次生成自动采用首个候选。
  • 单幕重跑 / 从此幕开始：可能为已有图片的分幕添加候选，不自动覆盖你已经采用的图片。在出图板比较并采用新图，再查看画册。
  • 暂停 / 继续：控制队列调度，不承诺撤回服务端已经收到的请求。取消也不代表云端退款。
  • 失败：查看任务详情中的具体错误、出图配置、模型与工作流；修复后再重试未完成项。
  • 不确定（uncertain）：请求可能已送达服务商。先核对上游记录，再选择认领结果、标记失败或明确确认重发；不要反复点击以免重复计费。
  • 断线与停止：ComfyUI 接单后的历史读取或图片下载中断会保留为待核对；已知任务编号时可重取结果，不会自动重新出图。提交响应丢失、没有任务编号时仍需人工核对。停止先于结果保存生效时丢弃迟到结果；结果已经进入保存阶段时先完成本次保存，再返回停止。

删除画册前应先停止它的活动任务。“清理已完成”把画册移出待生成队列，不是删除图片。任何永久删除都应先备份。

06 · 阅读、排版与导出

删除分镜会同步移除对应画格、裁切与文字，解除指向它的跨格引用。其他格、独立文字及原有留白不自动压缩；需要收拢版面时再手动调整。候选素材和历史快照保留。

选中画布中的图片后，可用放大、水平取景、垂直取景调整构图，或恢复自动居中裁切。撤销 / 重做支持最近 100 步修改（Ctrl / ⌘ + Z，Ctrl / ⌘ + Shift + Z 或 Ctrl + Y）；输入框内保留文字编辑快捷键。保存后仍可撤销，离开画布后不保留此历史。长图与平台切片使用保存的构图和留白，修改分镜比例后需要明确重新排版才会改变格的位置。

从 画册集 打开画册。阅读室以已采用图片为准。顶栏的「版式」切换展示模板，只改变阅读外观，不会生成图片；「排版」打开条漫画布，调整分格、留白、气泡与拟声字；「导出」打开导出抽屉。

不需要为条漫、画册或双页阅读分别创建作品：它们使用同一份画册内容。阅读模板与导出格式分别选择；HTML 模板不会自动转成可自由分格的印刷页面，PDF 的当前行为见下表。

原生单页、画廊与双页显示保存了裁切和嵌字的采用图；连续阅读显示完整条漫画布，保留手动留白和跨格文字。单格阅读及 HTML 画册模板按格裁图，格外文字会在边界截断，间距由阅读模板决定。修改裁切、采用图或作品变量后，阅读预览会更新。

输出用途与区别
单文件 HTML 画册当前 HTML 模板、样式与逐格图片打包在网页内，可离线阅读。模板间距代替原条漫画布间距，不是可编辑工作区备份。
图片 ZIP逐格图片文件、简单阅读页与清单，不使用当前 HTML 或双页模板。独立台词可显示在简单阅读页。
图片画册 PDF每格一页，不继承 HTML 或双页模板，也不等于整条条漫切页。PDF 会编码图像，不是原图字节归档；“显示台词”不会把独立台词排进 PDF。
平台切片 / 长图基于采用图和条漫画布合成；切片按平台宽度、高度限制拆分。先检查真实切片预览。

HTML 画册与图片 ZIP / PDF 默认使用合成后的逐格图片；关闭图片内排字（API lettered:false）会使用原始采用图，同时跳过保存的裁切。通过 API 导出的条漫 PDF 则沿完整条漫画布切页。

图片处理选项

  • 自动：优先无损清洗；单文件 HTML 的内嵌图像超出预算时改为轻量发布。
  • 无损清洗：对支持的原始 PNG / JPEG / WebP 去除提示词、工作流或 EXIF 等相关容器元数据，不重新生成画面。
  • 轻量发布：重新编码 WebP，长边不超过 2560px，适合分享。
  • 无损归档：没有排字裁切时保留原图字节及可能的工作流元数据，只建议本地存档。有排字的图片是重新合成的 PNG，不再是原始文件。

显示 / 隐藏台词和提示词是呈现选项，不是全面隐私清理。发给别人之前检查导出内容；原图、提示词和嵌入的工作流可能包含私人信息。

07 · 分享与可编辑作品包

给读者用 HTML、图片 ZIP 或 PDF；给另一个 Mio 工作区继续编辑，用 .mio.zip 作品包。两种 ZIP 不是同一种格式，不要把图片包当成项目导入。

导出作品包：画册的「⋯」菜单 →「分享画册源文件…」，或在画册集多选后点「导出」。导入：「设置 → 数据与备份 → 导入 .mio.zip」。脚本调用用带令牌的 /api/v2：导出 GET /api/v2/series/{id}/bundle，导入 POST /api/v2/bundles（请求体是 ZIP 原始字节）。

作品包主要搬运作品内容和相关资产，并非完整服务器备份；实例连接、API 密钥、出图配置和扩展仍应单独核对。分享前检查角色参考图、提示词和图像元数据。

外部程序与可选扩展

自动化使用带令牌的 /api/v2，接口清单见 API 文档 与 OpenAPI。读取工坊用 GET /api/v2/workshop，替换预览用 POST /api/v2/workshop/assemble/preview，装配用 POST /api/v2/workshop/assemble。装配可传 idempotency_key 防止网络重试重复创建；只创建快照，生成需另行提交。按操作授予 read、write、render 或 admin 权限。

修图、质检、成品档、批量变体、剧本助手与动态漫已有后端接口，不是默认主界面的按钮。仓库 examples/extensions/qa-review 提供可选质检扩展示例，安装启用后仍需通过命令明确提交，且不会自动采用图片。停用或文件变动后，旧扩展路由立即拒绝新调用；重新启用后须重启以挂载新路由。首个令牌在本机创建，后续令牌与扩展管理可通过带 admin 权限的开放 API 完成。扩展自定义路由也有 v2 版本，权限由扩展明确声明；核心操作可由已启用扩展包装或替换。

08 · 数据目录与备份

整理作品前，可从作品或分镜的「创作存档」入口保存命名快照。恢复先显示差异，明确恢复时会自动保护当前内容；过时预览、缺失素材、活动或待核对任务会阻止恢复。检查点保存作品数据，不复制图片文件或全局服务配置；已经永久删除的作品不能靠检查点重建。

用根启动器启动时，数据默认在 server/data/runtime/v3，包含 mio.sqlite3、jobs.sqlite3 与 assets/。自定义 --data 或 MIO_V3_DATA 时，以实际路径为准；手动从其他工作目录启动时，相对路径也会改变。

  1. 先等待活动任务结束，停止 Mio（不要仅关闭浏览器标签页）。
  2. 完整复制实际数据目录。不要只复制数据库而漏掉图像。
  3. 恢复前先保留当前数据副本；在停止服务的状态下恢复。

根目录的 data/ 是随包示例：首次启动时把示例画册、分镜与预设载入数据目录，之后对 data/ 的修改不会再同步过来。删除的作品先进入「设置 → 数据与备份」里的回收站，可在保留期内恢复。

不要为了重置界面而删除数据库。需要从头开始时，先备份数据目录，再换一个空的 --data 目录启动。

09 · 文件与格式

「创作套装」把所选分镜、预设、角色、画风、工作流与引用素材放在一起。工坊的导出格式可选「创作套装 ZIP」，画册菜单也可导出；导入菜单里选择「导入创作套装」，先查看内容，再为每份出图配置明确选择服务或「先导入，稍后配置」。装配第一步的「分镜来源」可反复选择套装，不会改写原工坊。

多选分幕后可复制或移动到同作品的其他话；「整理」菜单可复制整话、上下调整顺序或查找与整理变量。跨话整理会保留候选图、裁切和原话留白；锁定内容及跨边界气泡需明确选择处理方式。变量修改先预览差异，只处理完整变量引用，双大括号转义与历史候选不改。

Mio 以作品、分集、分格、候选和资产为核心，数据都在数据目录的数据库与 assets/ 里，不需要手动编辑 JSON 文件。

分镜工坊的 JSON 导入 / 导出用于分镜模板；预设工坊的导入 / 导出用于文本预设；画册模板在阅读室的「版式」里导入；作品备份请参考上一节。可复用的工作流和出图配置在“工作流与 API 配置”中管理。

10 · 局域网访问

默认仅允许本机访问。确有需要时，可用 start.bat --host 0.0.0.0 或 ./start.sh --host 0.0.0.0，在同一可信局域网的设备上打开电脑的 http://局域网IP:8788，并按需配置防火墙。

不要在手机上填 127.0.0.1：那是手机自身。Mio 中的 ComfyUI 地址则由运行后端的电脑访问，本机 ComfyUI 仍可用 127.0.0.1:8188。

本地 /api 没有登录认证，主机 / 来源检查不等于账号保护。不要直接暴露到公网或不可信网络。使用自定义主机名时才配置 MIO_ALLOWED_HOSTS；外部自动化接口使用作用域令牌保护的 /api/v2。

11 · 常见问题

按钮点了，看不到变化？

先区分“保存模板”“装配快照”“开始请求”“生成候选”“采用图片”五步。检查保存错误和任务详情；已装配的画册看不到模板的新改动是快照行为，重跑后画册不变通常是新图还没有被采用。

ComfyUI 已连接，但出图失败

在线检查只证明服务可访问。检查所选出图配置是否用了正确工作流，Checkpoint / LoRA 文件名是否存在，自定义节点是否安装，必填映射与后续阶段的 init 是否齐全。先在 ComfyUI 自己的界面跑一张。

云端渠道已填，却仍在等 ComfyUI

检查装配选择的配置、当前格的配置覆盖，以及是否通过 API 启用了「云端 + 本地精修」。仅添加渠道不会改变已有的本地配置；纯云端配置不会自动调用本地阶段。

替换后缺少角色名或台词内容

在装配预览检查对应幕的变量来源与空值；提示词中的未知变量保留原文，阅读台词中的未知普通变量留空。修改工坊预设不会追改已装配画册。确认修改的是当前画册变量或重新装配。

下载 PDF / ZIP 或平台切片没有内容

先确认有已采用图片，而不仅是候选。平台导出需要可合成的条漫；图片画册 PDF 与平台长图不是同一种输出。

更新代码后行为没变

Python 服务通常需要重启。源码前端需要重新构建（根启动器也会检查界面是否需要重建）。先结束任务再重启，不要强制终止正在出图的请求。

教程在开发界面打不开

确认后端 8788 正在运行，并重启改过代理配置的 Vite。手册随 server 一起打包，离线可用。
