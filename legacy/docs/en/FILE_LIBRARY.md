# Files and saving

The workspace uses the `data/` directory, or the path set by `MIO_DATA_DIR`.

Albums, storyboards, presets, workflows and layouts have their own files. Edits save automatically; the status bar shows the result.

Stop the service before copying the complete workspace for backup. Restart and reload after organizing files manually.
