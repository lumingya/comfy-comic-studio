# Content and sharing

Use the import and export buttons in each library to manage albums, storyboards, presets and layouts.

From an album menu, export a native ZIP for editable content, HTML for offline reading, or image ZIP / PDF for archiving. Select whether to include source storyboards and presets. Importers choose which resources to install.
