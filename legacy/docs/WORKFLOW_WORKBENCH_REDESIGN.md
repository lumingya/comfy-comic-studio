# 工作流配置页 · 视觉重构说明

涉及文件：`js/workflow-workbench.js`、`js/workflow-workbench.css`、`js/engine.js`（一行：挂接页头）、`index.html`（缓存戳）、`.eslintrc.json`（两个全局名）。
数据契约（bindings v1、映射包格式、所有 `data-act` 动作名与 `#id` 钩子）均未改变。

## 与其他页面对齐
- 新增和「分镜工坊 / 设置」一致的编辑式页头：眉题 → 大标题 → 一句说明 + 右侧三枚 metric（工作流数 / 映射启用 / 待检查）。
- 整页只用一种强调色；琥珀色只出现在「待检查」相关元素上。
- 启用列改为项目通用 `.switch` 开关，替换原生 checkbox。
- 全部圆角、间距、字号统一到 8 / 12px 与 10.5 / 11 / 12.5px 的节奏。

## 结构
- 左栏工作流库：标题 + 计数、主 CTA、搜索、卡片列表、底部工具与保护说明（贴底）。少于 2 份工作流时不显示「选择」按钮。
- 工作台头部：可编辑标题、元信息、映射包导入/导出成组、复制/编辑蓝图。
- 健康条：无问题时为静态状态（不可点），有问题时可展开列表并跳转。
- 表格：状态图标 / 映射与写入位置（含节点标题）/ 取值来源 / 时机 / 开关；输出节点作为独立「输出」分节。
- 检查器：契约句子 → 校验状态 → 名称 → 01 写入位置 → 02 取值来源 → 03 实时取值预览 → 高级选项；检查器体内部独立滚动，试跑按钮始终可见。

## 补齐的边界情况
- 蓝图为空时的整页空态（引导导入 / 编辑 JSON）。
- 映射为空 / 搜索无结果 / 筛选无结果三种不同空态，并各自给出下一步动作。
- 输出节点：显示自动探测结果；指定节点不存在或蓝图无 SaveImage 时以琥珀色提示。
- 分镜参数来源改为下拉选择（width/height/steps/cfg/denoise/seed），避免手输错字。
- 变量 / 固定值 / 分镜参数为空时表格显示「未填写」而非空白。
- 契约句子按来源类型措辞不同（固定值 / 不写入 / 仅覆盖时）。
- 键盘：↑↓ 在映射行间移动，Enter/空格选择；Esc 退出批量选择模式。
- 导入面板：过滤非 JSON 文件与 >10 MB 文件并逐行提示；拖放区支持键盘触发。
- 响应式：1360 / 1250 / 1100 / 1020 / 700 五档；窄屏工作流库折叠为下拉。
- 浅色主题、`prefers-reduced-motion`、`data-viewport=locked` 均已覆盖。
