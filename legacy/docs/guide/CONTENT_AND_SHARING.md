# 内容与分享

## 内容库

工作室包含画册、分镜、预设、工作流和展示模板。通过各自页面的导入、导出按钮管理。

## 分享画册

在画册菜单选择导出：

- **原生 ZIP**：保留图片、编辑图层和相关素材。
- **HTML**：适合离线阅读。
- **图片 ZIP / PDF**：适合归档与打印。

导出时可选择附带分镜与预设，接收方在导入窗口选择要安装的内容。

## 管理资源

分镜和预设可以重命名、复制、删除或导出。模板用于阅读与排版；预设用于角色、画风和场景变量。
