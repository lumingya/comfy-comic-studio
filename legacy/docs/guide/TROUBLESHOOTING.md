# 常见问题与错误码

出错时，Mio 会用一句话说明原因，并在旁边给出修复按钮。生成任务失败时，任务卡上还会显示一个 **错误码**（例如 `MIO-CONN-001`）和「查看排错」链接，直接跳到本页对应的条目。

## 先做这三件事

1. **读任务卡上的那句话**。它通常已经说明了原因，例如“连接被拒绝”“服务拒绝了密钥”。
2. **点修复按钮**。连接问题点「测试连接」或「图像服务设置」；工作流问题点「打开工作流」。
3. **需要求助时**，点顶栏「?」→ **「复制诊断信息」**，连同任务卡的「技术详情」（弹窗里有「复制全部」）一起发出来。诊断信息不含密钥。

修好之后点 **「开始生成」**，Mio 会接着生成没完成的分幕，已经生成的图片不会重做。

“请求发出了吗”决定了重试是否安全：

- **没有发出**：放心重试。
- **被拒绝**：服务明确拒绝了请求，一般不会计费。
- **已发出 / 可能**：上游也许已经出图或计费，**先到服务端核对**，再决定是否重跑。

## 连接问题

### MIO-CONN-001 连接被拒绝

**你会看到**：“连接被拒绝：这个地址上没有正在运行的图像服务。”技术详情里可能是 `Connection refused`、`Errno 111`、`WinError 10061`。

**原因**：地址和端口上没有服务在监听，请求根本没有发出去。

**处理**：

1. 确认 ComfyUI（或其他服务）已经启动，浏览器能打开它的地址。
2. 核对端口：ComfyUI 默认是 `8188`，地址写 `http://127.0.0.1:8188`。
3. 服务在另一台电脑上时，确认它监听的是局域网地址（ComfyUI 的 `--listen`），并且防火墙放行了这个端口。
4. 点「测试连接」，显示“已连接”后再点「开始生成」。

### MIO-CONN-002 找不到服务器

**你会看到**：“找不到服务器：地址中的域名无法解析。”技术详情里可能是 `Name or service not known`、`getaddrinfo failed`。

**处理**：检查地址拼写，例如 `api.openai.com` 有没有写错；检查网络和代理设置。

### MIO-CONN-003 网络不通

**你会看到**：“网络不通：无法到达服务地址。”

**处理**：检查网络连接、代理和防火墙。局域网地址要确认两台电脑在同一网络。

### MIO-CONN-004 安全连接失败

**你会看到**：“安全连接失败（SSL / 证书）。”技术详情里可能是 `CERTIFICATE_VERIFY_FAILED`、`wrong version number`。

**处理**：

- 本机 ComfyUI 一般用 `http://`，**不是** `https://`；
- 云服务检查系统时间是否正确；
- 公司网络的代理证书可能拦截了连接。

### MIO-CONN-005 连接超时

**你会看到**：“连接超时：服务地址没有响应，请求没有发出。”

**处理**：确认地址正确、服务已启动；检查代理。服务所在的电脑负载很高时，也可能暂时无响应。

### MIO-CONN-006 连接中断

**你会看到**：“连接中断：服务在返回结果前断开了连接，请求可能已被接收。”

**处理**：请求可能已经被服务接收。先在服务端核对，比如 ComfyUI 的历史记录、云服务的用量页面，再决定是否重跑。如果提示的是“连接在发送请求时中断，请求没有完整发出”，就可以直接重试。

## 密钥、额度与权限

### MIO-AUTH-001 密钥无效

**你会看到**：“服务拒绝了密钥：请检查 API 密钥是否有效、过期或绑定了错误的服务。”（HTTP 401）

**处理**：

1. 打开「图像服务设置」→「管理密钥」，确认选的是这个服务的密钥。
2. 密钥和基础地址绑定，改过地址要重新选择密钥。
3. 到服务商后台确认密钥没有过期或被撤销，必要时重新生成并保存。

### MIO-AUTH-002 余额或额度不足

**你会看到**：“余额或额度不足：请检查账户余额（NovelAI Anlas / API 额度）或计费设置后再继续。”（HTTP 402）

**处理**：到服务商后台充值或调整额度上限，再点「开始生成」续跑。

### MIO-AUTH-003 拒绝访问

**你会看到**：“服务拒绝访问：请检查模型权限、账户授权及服务地区限制。”（HTTP 403）

**处理**：确认账户有权使用这个模型。部分模型需要单独申请或实名认证；有些服务限制地区。

### MIO-RATE-001 服务限流

**你会看到**：“服务暂时限流：正在按服务端要求等待。”多次等待仍被拒绝时，这一幕会停下。

**处理**：稍后对这一幕点「单幕重跑」；或在「装配与队列」里降低分幕并发。限流等待不计入连续失败。

## 请求与模型

### MIO-REQ-001 请求参数被拒绝

**你会看到**：“服务拒绝了请求参数（HTTP 400/422）：……”，冒号后面是服务返回的原话。

**处理**：按原话修改。常见问题：

- 尺寸不被支持：NovelAI 要求宽高是 64 的倍数；
- 步数超出上限；
- 模型不支持某个参数。

### MIO-REQ-002 模型或接口地址不存在

**你会看到**：“模型或接口地址不存在（HTTP 404）。”

**处理**：

- 核对模型 ID，可以点「获取模型」从列表里选；
- OpenAI 兼容服务的基础地址通常写到 `/v1` 为止，不要带 `/images/generations`。

### MIO-REQ-003 只返回了文字

**你会看到**：“服务只返回了文字，没有图片。”或者直接显示模型回复的文字。

**处理**：所选模型可能不支持图像生成。Chat Completions 协议需要模型支持图片输出（modalities 包含 image）；否则改用 Images API 协议，或换一个模型。

### MIO-REQ-004 内容安全审核

**你会看到**：“触发内容安全审核：服务拒绝生成这一幕。”

**处理**：点「查看分幕」找到被拒的那一幕，修改提示词后 **只重跑这一幕**。

## ComfyUI 工作流

### MIO-WF-001 缺少模型文件

**你会看到**：“缺少模型文件：请检查工作流中的模型、Checkpoint 或 LoRA 是否已安装。”

**处理**：在「工作流与 API 配置」点「同步模型列表」，找不到的模型会标红；然后在装配向导的「模型与 LoRA」里选一个已安装的模型。随包工作流里的 `your-anime-model` 是占位名，必须替换。见 [ComfyUI 工作流](WORKFLOW.md#4-模型与-lora)。

### MIO-WF-002 工作流节点缺失

**你会看到**：“工作流节点缺失或不兼容：请安装所需节点，并重新检查工作流。”

**处理**：工作流用到了你的 ComfyUI 没装的自定义节点。先在 ComfyUI 里打开这份工作流，按提示安装缺失节点（例如用 ComfyUI Manager），确认能在 ComfyUI 里跑通，再回 Mio 生成。

### MIO-WF-003 显存不足

**你会看到**：“GPU 显存不足：请减小分辨率或批量数，或释放显存后重试。”

**处理**：

- 降低宽高；
- 把分幕并发调到 1；
- 关掉其他占用显卡的程序后重跑。

### MIO-WF-004 画面几乎一样

**你会看到**：整本画册每一幕构图几乎相同。开箱检查或装配向导会提示“没有种子映射”。

**原因**：工作流没有种子映射，每一幕都用工作流里写死的同一个种子。

**处理**：点 **「一键添加种子映射」**。之后默认每一幕随机种子；需要可复现时，在装配时开启「可复现种子」。见 [ComfyUI 工作流](WORKFLOW.md#种子)。

## 上游与结果

### MIO-UP-001 服务端暂时故障

**你会看到**：“服务端暂时故障（HTTP 5xx）：上游服务或中转不可用，请稍后重跑本幕。”

**处理**：等几分钟再对失败的幕点「单幕重跑」。使用中转服务时，也可能是中转本身的问题。

### MIO-UP-002 等待结果超时

**你会看到**：“等待结果超时：上游可能仍在处理或已完成。”

**处理**：先到服务端看看这一幕有没有已经出图。生成本来就慢时，可以在队列运行设置里调大超时。

### MIO-RES-001 结果未确认

**你会看到**：分幕状态“结果未确认”。重跑时会弹出确认：“存在未确认的结果”。

**原因**：请求 **已经发出**，但 Mio 没有拿到结果，例如运行中关掉了 Mio、网络在返回途中断开。上游可能已经出图，也可能已经计费。**只有请求确实发出后才会出现这个状态**；连不上服务这类“请求没发出”的失败，不会标成结果未确认。

**处理**：

1. 到服务端核对：ComfyUI 看历史记录，云服务看用量或历史页面。
2. 图片已经生成、只是没存进 Mio：展开分幕，点 **「恢复已生成结果」**。它只重试本地保存，不会再请求模型。
3. 确认上游没有生成：再点重跑，并在确认框里确认。

各种状态的含义见 [生成任务](FOUNDATION.md)。

## 装配与变量

### MIO-VAR-001 台词引用了未定义的变量

**你会看到**：装配向导第 2 步显示 ⛔：“第 N 幕的台词引用了未定义的变量 {…}”，“下一步”按钮是灰的。

**原因**：台词里写了 `{某变量}`，但所选预设都没有定义它，生成出来的台词会缺字。

**处理**：点 **「选择包含它的预设」**，或点 **「去第 N 幕修改」** 改掉这个变量。提示词里的未定义变量只算 ⚠️ 提示，生成时替换为空。规则见 [变量与预设](IMAGE_VARIABLES.md#空值和未定义)。

## 启动与保存

### 打不开 http://127.0.0.1:8777

- 看运行 `python server.py` 的终端里有没有报错。缺依赖就先执行 `python -m pip install -r packaging/requirements.txt`。
- 端口 8777 被占用时，关掉占用它的程序后重启 Mio。
- 用手机或其他电脑访问的设置见 [手机访问](MOBILE.md)。

### 状态栏显示“保存未完成”

点状态栏查看原因：

- **保存服务没连上**：确认终端里的 Mio 还在运行；
- **文件版本冲突**：另一个窗口或进程改过同一份文件。本页草稿不会覆盖磁盘，刷新页面后重新编辑；
- **磁盘权限或空间**：检查数据目录能否写入、剩余空间是否足够。

### 导入失败

- **ComfyUI 工作流**：必须是 API 格式 JSON，见 [ComfyUI 工作流](WORKFLOW.md#1-从-comfyui-导出-api-格式)。
- **分镜 / 预设**：用对应工坊的「导入」，支持 `.json` 和 `.mio.zip`。
- **画册、带图片的资源、完整备份**：用对应的 ZIP 导入入口，见 [备份与恢复](BACKUP.md)。

### 误删了东西

删除后 10 秒内，提示条上有 **「撤销」**。错过了也不要紧：画册、分镜、预设、画册集和工作流删除后都会先进 **回收站**（「设置 → 数据与备份 → 回收站」），可以恢复。见 [回收站](BACKUP.md#回收站)。

回收站默认保留 30 天，可以在同一页改成 7 天、90 天或不自动清理。

## 日志在哪里

| 位置 | 内容 |
|---|---|
| 任务卡「技术详情」 | 这个任务的原始错误和请求记录，可「复制全部」 |
| 「运行日志」页 | 按时间排列的生成、连接、保存记录。在「设置 → 功能开关」里打开后出现在侧栏 |
| 顶栏「?」→ 诊断信息 | 版本、界面、图像服务、工作流、开箱检查和最近错误的摘要，不含密钥 |
| 运行 `server.py` 的终端 | 后端启动信息和异常堆栈 |

## FAQ

### 为什么 12 张图一模一样？

ComfyUI 工作流没有种子映射，见 [MIO-WF-004](#mio-wf-004-画面几乎一样)。

### 为什么显示“就绪”，生成时却失败了？

“就绪”表示配置齐全：地址、模型、需要时的密钥都在。ComfyUI 的“已连接”是实际检测过的；云服务的密钥是否有效、额度够不够，只有真正请求时才知道。

建议先装配一个一两幕的小任务试跑。OpenAI 兼容服务可以用「获取模型」快速验证地址和密钥。

### 数据存在哪里？

默认在程序目录下的 `data/`，也可以用环境变量 `MIO_DATA_DIR` 指定别的目录。分镜、预设、画册都是独立的 JSON 文件和图片，见 [文件与保存](FILE_LIBRARY.md)。

### 升级程序时怎样才能不丢数据？

升级前先在「设置 → 数据与备份」里 **导出完整备份（ZIP）**。更稳妥的做法是用 `MIO_DATA_DIR` 把数据目录放在程序目录之外，这样替换程序文件不会碰到你的数据。见 [备份与恢复](BACKUP.md)。

### 生成会花钱吗？

- **ComfyUI**：用你自己的显卡，不产生费用。
- **NovelAI / OpenAI 兼容**：按服务商计费。

只有点「开始生成」并确认之后才会请求服务；装配、试看页面都不花钱。失败或结果未确认时，Mio 不会自动重发请求。
