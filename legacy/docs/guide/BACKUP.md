# 备份与恢复

## 完整备份

1. 停止 Mio 服务。
2. 复制整个工作室目录（默认 `data/`）。
3. 恢复时把副本放回工作室路径，再启动服务。

## 可移植导出

在「设置 → 数据与备份」里点 **「导出完整图片目录 ZIP」**。只想分享一本画册时，用画册菜单里的导出功能。

## 回收站

画册、分镜、预设、画册集、工作流、画册版式和创作计划删除后不会立刻消失。它们会先移进回收站，恢复时原样放回原来的位置，图片也一起回来。

### 刚删完：点「撤销」

删除后，屏幕下方的提示条上有 **「撤销」**，10 秒内有效。点一下，刚才删掉的内容就回来了。

删除画册集时，里面的画册、分镜、预设和计划会跟着一起删除，撤销时也一起恢复。

### 过了 10 秒：到回收站里找

打开「设置 → 数据与备份 → 回收站」。列表按类型分组，每一项显示删除时间、大小和原来的位置。

| 操作 | 作用 |
|---|---|
| **恢复** | 放回原来的位置，然后重新读取工作室 |
| **永久删除** | 从磁盘上删掉这一项，之后无法再恢复 |
| **清空回收站** | 永久删除回收站里的全部内容 |
| **自动清理** | 选择保留多久：7 天、30 天（默认）、90 天，或不自动清理 |

自动清理在每次打开工作室后执行一次，只删除超过保留天数的项目。把天数改短时，如果已经有项目超过新期限，会先问你再删。

### 恢复不了的情况

- **「原位置已有同名文件」**：原来的位置又放进了一个同名文件。先把它改名或移走，再点「恢复」。
- **「已存在同一 ID 的内容」**：这一项多半已经恢复过，或者你导入了同一份文件。确认工作室里已经有它之后，把回收站里这一项永久删除即可。
- **恢复出来的内容找不到**：如果它原来的画册集已经不在了，它会被放进当前画册集，提示条上会说明。

Mio 不会用回收站里的内容覆盖任何现有文件。

### 素材文件

在「素材索引与完整性」里回收的未引用图片也在回收站里，列在 **「素材文件」** 一组，同样可以恢复或永久删除。回收站里的画册和分镜仍然算作在用它们的图片，所以清理未引用图片时不会把它们的图片也清走。

### 在磁盘上的位置

回收站就是工作室目录里的 `.trash/` 文件夹。每个删除的项目占一个子文件夹，里面有原文件和一份 `receipt.json`（记录类型、ID、原位置和删除时间）。

需要手工找回时，先停止服务，把文件夹里的文件移回 `receipt.json` 记录的原位置，再启动服务。

完整备份会连同 `.trash/` 一起复制。想让备份小一些，可以先清空回收站。

## 升级

备份工作室目录，更新程序文件，再使用原工作室路径启动。
