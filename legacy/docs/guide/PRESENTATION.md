# 阅读与导出

## 阅读

从画册集打开画册，选择连续阅读、单幅或双页模式。使用页码、缩略图和方向键切换页面。

## 展示模板

打开模板与导出面板，选择版式，调整主题色、边框、签名与台词。

## 导出

选择 HTML、图片 ZIP 或 PDF。HTML 可直接在浏览器打开；带有源素材的画册可导入到工作室。

### 图片处理

ComfyUI 输出的 PNG 内嵌完整工作流与提示词。「图片处理」决定导出时如何对待这些图片，三种格式共用同一选择：

| 选项 | 图片 | 内嵌工作流 / 提示词 | 适合 |
| --- | --- | --- | --- |
| 自动（默认） | 先按「无损清洗」；单文件 HTML 超过 128 MiB 时自动改用「轻量发布」，完成后会说明 | 移除 | 日常导出 |
| 无损清洗 | 像素、分辨率、格式与原图一致 | 移除 | 需要原始分辨率的分享 |
| 轻量发布 | 高画质 WebP，长边不超过 2560 px，不会放大文件 | 移除 | 对外发布、手机阅读 |
| 无损归档 | 原文件逐字节写入 | 保留 | 本地备份；不要直接分发 |

清洗只删除 PNG 文本块、JPEG / WebP 的 EXIF、XMP 与注释，方向信息会保留，不重新编码画面。ZIP 与 PDF 不受 128 MiB 单文件预算限制，图片同样按所选方式处理；ZIP 的 README 与文件名会标明所用方式。
