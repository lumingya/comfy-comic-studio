# 角色与画面设定 UI 优化

基于上游 main 提交 `7619a94`，在原项目中修改，未更换数据模型及生成流程。

## 信息架构
- 本册编辑区 + 常驻公共预设侧栏；小屏侧栏收为顶部入口。
- 属性按角色、画面氛围、其他自定义属性分组；文本区收紧，变量标识保留，删除操作降低视觉权重。
- 预设库保留独立弹窗，支持名称搜索、数量摘要、选中状态、草稿范围说明、底部固定应用目标。
- 原有的预设应用、更新、另存、导入导出动作继续使用原事件处理器。
- 新增侧栏预览动作只选择并打开预设，不自动应用。

## 修改文件
- `js/ui-settings.js`：属性分组、编辑工作台、预设侧栏。
- `js/creative-context.js`：搜索、预览入口、预设库结构。
- `styles.css`：主题变量驱动的局部样式和移动端适配。
- `.eslintrc.json`：新增共享函数声明。
- `index.html`：构建刷新资源哈希。

## 验证及限制
- `node js/build.js dev` 通过。
- `npm run lint`（JS + HTML）通过。
- UI 演示的 Playwright 测试通过：搜索、选择、草稿与本册隔离、应用、桌面及移动端无横向溢出、无浏览器 JS 异常。
- 原项目预设隔离回归未能执行完成：仓库缺少 `data/distribution.json` 与 `data/catalog/`，`/api/content` 返回 500，阻止应用初始化。没有以旧数据备份覆盖或绕过初始化保护。
- 独立演示使用相同渲染函数和样式，但使用内存示例数据及演示处理器，刷新会重置，不代表完整业务回归通过，也不连接任何付费生成服务。

## 使用
将改动文件合入相同版本的完整项目。先备份自己的数据，补齐上游完整发布包的必需资源，再按原项目方式运行 `python server.py`。不要用缺失资源的克隆目录替换已有数据。

补丁包仅含改动文件、说明与演示，不含用户数据。完整 Git 克隆位于工作区 `comfy-comic-studio/`。
