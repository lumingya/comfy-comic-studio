# 装配车间重构 · 实施边界

本轮需求替代 3.0 的“源画册统领创作”模型，不保留旧 UI 或数据迁移兼容。

## 领域划分
- 分镜工坊：独立故事资产，名称、主线、分幕内容与参数；不持有画册和角色身份。
- 预设工坊：独立视觉资产，变量、图片、LoRA/节点绑定、负向提示词与分组；不持有故事身份。
- 装配中心：选择故事和多份预设、命名产出画册，保存独立生产输入快照。只创建待命任务，不求值脚本、不提交模型。
- 启动阶段：显式执行阶段 0，再提交选定任务的阶段 1。不得通过全局 runQueue 间接启动其他待命任务。
- 局部重跑：新执行尝试引用明确的原始页索引；不先删除旧图，成功后原子替换；保留尝试历史与未确认请求保护。

## 控制语义
- 单本开始：仅启动指定任务。
- 从当前顺次生成：冻结本次批处理的任务 ID 顺序，逐本执行；不包含之前的任务和后来新增的任务。
- 全局暂停：停止新分幕/任务调度；明确区分已提交请求可能仍返回。
- 全局取消：取消当前批次与运行任务；不得自动重试或启动下一本。
- 单幕重跑只影响指定页；从该幕重跑只影响选中页及之后的页。费用风险与未确认结果需明确确认。

## 界面规范
- 阅读偏好 → 通用偏好：保留全部功能，按语言/常规、字体/显示、阅读操作分类。
- 外观与主题 → 自定义主题：仅第三方 UI 换肤生态。
- 内置扩展功能 → 可选功能；第三方扩展中心保持原名。
- 所有启闭使用统一 Switch，选择/批选仍使用 Checkbox。
- 文件导入采用箭头入容器（向下），文件导出采用箭头出容器（向上）；与图片上传、网络下载等底层动作分开命名。

## 验证要求
- 装配/保存待命任务产生零模型调用。
- 单本启动不触发其他任务；顺序批次最大一本运行；暂停/取消不补发。
- 脚本阶段 0 只在显式启动时执行。
- 单幕/后缀重跑页索引正确，失败不覆盖已有图片。
- 故事/预设修改不反向改变已装配快照。
- 设置功能完整性、开关统一、文件图标语义、桌面与移动留白/横溢检查。
