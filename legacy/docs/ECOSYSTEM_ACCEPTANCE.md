## 本轮关键用例

- AST 依赖推导排除注释/普通字符串；循环、缺失依赖、语法错误阻止执行。
- 真 Node 进程的种子复现、超时、依赖读取保护、并行 DAG、缓存命中、重启缓存复用。
- 取消不会提交下游节点；磁盘写入失败有明确终态，不放行阶段 1。
- SDK 模型桥接解析保存的渠道、模型与映射，图片写入内容哈希资产路径。
- 真 Python 插件进程的路由、持久笔记、停用、重装保留数据、显式删除数据。
- Git 命令参数/协议限制；更新使用离线 clone 夹具验证代码替换、无效版本回滚与数据保留。
- ZIP 路径穿越/重复路径拒绝、符号链接拒绝、储存覆盖配额、主题并发注册表。
- 浏览器真实导入 CSS/扩展 ZIP、信任确认、全局导航主题切换、`?safe_mode=1` 恢复、移动端不横溢。
- 脚本元数据经过编辑器→文件保存→浏览器重载仍存在；求值快照不包含脚本，源稿脚本不被覆盖。
- 源选择器仅源计划；历史不会绑定到源稿；生成中的后续帧继续使用其快照，源修改不偷偷替换参考图。
- 已导入故事再次导入前，未失焦的原故事编辑正确保存；导出得到真实 ZIP。

## 验证边界

所有模型请求都指向受控本机服务或测试适配器。**未测试真实付费云模型、用户 ComfyUI 服务或第三方未知扩展。** 公开 Git 远端下载可用性未作为离线自动化通过项；测试验证的是传输参数、安装/更新事务与故障处理。

Windows 进程和锁分支未在本轮 Linux 环境实测。Shift 刷新的浏览器快捷键差异不作跨平台保证，明确 URL 安全入口已实测。

旧“全局选择生成版本并直接修改它”的界面测试按新契约重写，而非保留兼容。底层任务修订与恢复仍有独立测试，显式修订不会变成源稿联动。

部分原有 Python 测试退出时仍报告 SQLite 连接 ResourceWarning；未出现断言失败。新增生态进程的管道已在退出时关闭。

验收截图和原始日志在 `docs/acceptance-ecosystem/`；这些运行产物不包含在源码发布 ZIP 中。指南、示例和测试源码包含在发布包内。
