# 样式片段示例

把任意一个 `.css` 文件拖进 **设置 → 外观定制 → 样式片段 → 导入 .css**，或者直接复制内容到一个新片段里。片段按顺序叠加在所有主题之后，因此总能覆盖主题。

| 文件 | 做什么 |
| --- | --- |
| `bigger-ui.css` | 整体放大 12%，触屏更好点 |
| `compact-sidebar.css` | 侧栏只留图标，给分镜编辑器腾空间 |
| `focus-writing.css` | 写分镜时隐藏一切干扰，只剩正文 |
| `custom-font.css` | 用本地上传的字体文件（资源文件面板）替换界面字体 |

小技巧：按 <kbd>⌘/Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> 在任意页面点一个元素，会自动生成选择器并新建片段。
