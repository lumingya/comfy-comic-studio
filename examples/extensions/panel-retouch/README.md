# 单格精修工作台

独立可选的剧集面板：局部重绘、向四周外扩和指令编辑。启用后从具体话的「扩展」菜单打开「单格精修」，不增加主导航。

## 安装与使用

1. 把本目录打成 ZIP，在 Mio 的「扩展市场」导入，审阅内容摘要后启用。
2. 打开已有候选图的一话，在「挑图 / 分镜」旁的「扩展」菜单选择「单格精修」，点击「读取候选与配置」。安装、启用、打开工具都不会出图。
3. 选择原图与方式。局部重绘可拖动矩形，或逐点点击后「完成多边形」；着色区域会重绘。也可以展开坐标编辑器，用键盘填写 `{"boxes":[[左,上,右,下]],"polygons":[[[x,y],...]]}`，坐标为原图宽高的 0–1 比例。
4. 外扩填写左、上、右、下原图像素；指令编辑填写修改说明。按需选择出图配置、提示词、负向词、羽化、强度与种子。
5. 明确点击「提交精修，新增候选」，查看逐项任务状态及原图/结果对比；回到挑图页后自行采用结果。

局部重绘与外扩需要所选出图配置中存在对应的 `edits.inpaint` / `edits.outpaint` 工作流。指令编辑优先走 `edits.edit`，没有时沿用现有云端编辑能力，需要配置支持图像编辑的渠道。配置中的云端渠道 ID 自动作为默认值，也可在本次指令中覆盖。没有可用配置时应到「高级出图方案」设置后重新读取。

矩形和多边形可以混合；「清空区域」移除全部，「应用坐标」校验后更新预览。原图始终完整显示；蒙版和外扩都由服务端按原图尺寸处理，不依赖屏幕缩放。新图保留 `parent_take_id`、参数与任务来源；**不会替换已采用图**。

## 任务与重试

提交后的任务每 5 秒读取一次状态，最多自动读取 100 次；可取消勾选或手动刷新。可从近期精修任务恢复查看，也可粘贴任务 ID。失败、超时、取消都不会自动提交第二次生成。相同参数的重复点击保留幂等键；若需要相同参数重新画一次，请点击「开始新的编辑请求」。网络超时应先刷新近期任务，确定是否已创建，再决定重试。

停用后菜单入口与后续请求立即撤销，已提交任务可能继续执行；在停用前用「停止任务」明确取消。不删除作品或候选。卸载沿用宿主的保留数据默认行为；本扩展自身没有持久化设置与私有数据。

## 契约与离线验证

仅使用 `contributes.panels.requests`，无 Python 入口、宿主内部接口、直接联网或凭据访问。图片通过 `response: "image"` 的受控媒体桥读取，换图时释放媒体句柄。JSON 请求保留核心的类型校验、`read` / `render` 权限、上下文与摘要信任检查。面板协议和媒体返回约定见[媒体桥说明](../../../docs/EXTENSION_MEDIA_BRIDGE.md)。

```bash
python tools/check_extension_package.py examples/extensions/panel-retouch
node examples/extensions/panel-retouch/logic.test.cjs
node examples/extensions/panel-retouch/bridge.test.cjs
python -m unittest discover -s server/tests -t server -p test_professional_retouch.py -q
```

测试使用隔离作品与模拟 ComfyUI，覆盖 ZIP 安装、摘要启用、编辑三种请求、任务及图片读取、候选回流、幂等和停用/卸载。模拟通过不代表某个真实工作流或云渠道已可运行；真机出图由已配置的服务决定，可能消耗额度。
