# 余光 · AFTERGLOW 演示

双击 `余光_AFTERGLOW_演示画册.html` 即可离线阅读，不需要运行 Mio；此文件由真实 UI 导出路径生成。

这些演示素材不会导入用户画册，也不调用供应商。`cover.webp`（928×1152）与 `coast.webp`（1376×768）来自本轮 AI 生成的虚构海岸车站插画；`station.webp`（768×768）和 `postcard.webp`（240×180）是海岸图的演示裁片，用于检验方图与小图排版。正文显示原图比例，装饰封面单独取景。

字体为系统字体，不加载外部资源。点击末尾项目链接需要网络；画册阅读与内置交互不需要。

## 1.2.1 阅读修订

同一个余光模板的正文现为居中连续画面和贴图说明，不再左右交替。`dense-portrait.webp`（1024×1408）和 `dense-square.webp`（1024×1024）是用上述 AI 插画添加多格、气泡与选项文字构成的排版测试素材，不是用户图像；专项交替使用这两张图检查 24 幕阅读几何关系。
