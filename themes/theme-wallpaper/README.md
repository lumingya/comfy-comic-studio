# 壁纸播放器

这是 Mio 的纯数据主题示例，不是扩展，也不包含可执行代码。导入文件夹或 ZIP 后，在主题卡的「更多设置」中导入本地图片或视频，选择壁纸并调整视频速度与循环播放。

壁纸保存在本机数据目录 `themes/theme-wallpaper/user_wallpapers/`，与主题包文件分开管理，不会被主题导出或同步进主题清单。支持的图片与视频类型、文件大小和内容签名均由 Mio 后端校验。

`theme.css` 中的 `.theme-card[data-theme-id="theme-wallpaper"]` 规则仅定制此主题卡片；卡片样式通过独立的局部样式表加载，不会影响设置页其他区域。
