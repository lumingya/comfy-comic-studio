# Mio 1.1.0 — 画册展示与非破坏性图片编辑

2026-09-12 · 本地改进构建，不代表上游官方发布。

本次直接基于已交付的 **1.0.1 完整包**继续改进；上游源码基线为 `0b63298`。完整运行包仍保留独立 `js/*.js`、`styles.css`，没有改成单文件巨型 HTML。

## 启动与升级

需要 **Python 3.10+**，运行不需要 Node.js/npm。

- Windows：解压后双击 `start.bat`。
- macOS / Linux：在目录中运行 `sh start.sh`。
- 或运行 `python server.py`，打开终端显示的地址，默认 `http://127.0.0.1:8777`。
- 不要直接双击 `index.html`。本包不含 Windows exe。

**从旧版升级：** 关闭旧网页及服务 → 备份完整旧目录 → 将新包解压到新目录 → 把旧 `data/` 整体复制过去；旧 `images/` 和旧式 JSON 如仍存在也按原位置保留 → 启动并强制刷新网页 → 核对画册、渠道、原图和保存状态。

新包不含用户数据，不会用测试数据覆盖你的工程。不要同时运行新旧两份服务编辑同一工作区。回退必须恢复升级前的整套备份，不要混用新旧 JSON 与数据库。

**必须保留 `data/execution/jobs.sqlite3`**：本版在原有任务记录和画册删除标记之外，增加了每页编辑配方、原图引用及单图删除记录。

## 展示改进

- 网格封面统一方形，横/竖/小图不再改变卡片高度；添加图片数量角标。
- 可指定封面来自哪一幕，选择填满/完整留白，并设置焦点。封面取景不改变原始图片。
- 单图阅读保持完整比例，并限制小图放大。
- 连续阅读采用一致的容器、背景、间距与旁白样式；横、竖、小图保留本身尺寸关系。
- 双页组遇到横幅图自动上下排布，不把横图挤入竖页。
- 默认离线模板同样保持完整画面并限制小图放大；用户自定义模板不被强制改写。

## 本地图片编辑

阅读器右上角 **编辑图片**：

- 裁剪比例和百分比范围，90° 旋转、水平/垂直翻转。
- 亮度、对比度、饱和度。
- 圆角、椭圆、思考、喊话、旁白气泡，以及可编辑文字。
- 贴纸导入、拖动/缩放、精确位置、图层顺序、复制/删除、撤销/重做、底图对比。
- 原图、当前底图、配方、图层和最终 PNG 分开保留；再次打开可继续编辑。
- 已编辑页面的实验室精修结果也通过同一持久提交，避免生成后又回滚到旧编辑图片。
- 本地替换、单图删除、恢复初始原图。单图删除保留分镜文字，不自动补图、不调用付费生成服务。
- 导入安全 SVG、PNG 和 JSON 素材包。示例在 `examples/image-assets/starter.json`。

完整操作、格式、安全规则及限制见 [图片编辑教程](guide/IMAGE_STUDIO.md)。

## 持久性和兼容性

页编辑使用独立版本检查和 SQLite 权威记录。刷新、硬重启、旧标签页配置回写和迟到生成结果不能覆盖编辑或复活已删除图片。冲突/网络失败时保留当前草稿，不自动重试图片变更。

已有生成、渠道、队列和画册删除规则不变：画册删除仍只确认一次；未知生成结果不盲目重发；真实任务不会借当前演示渠道重跑；已有任务不能保证在上游取消或退款。

编辑结果使用裁剪后的原始像素生成，不用缩略预览保存。编辑上限为 3200 万像素、长边 8192 px；源图及输出单文件 50 MiB；不静默缩小超限图片。SVG 素材栅格化后作为贴纸，自定义对白底板的文字需另加文字图层。当前没有任意代码插件或 SVG 路径编辑器。
