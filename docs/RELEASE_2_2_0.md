## 本次交付

### 1. 真实的内容拆分

发行 ZIP 包含 `data/`，不是占位目录。59 个明确批准的内容文件及发行清单，覆盖独立画册与真实图片、分镜、设定、计划、工作流、七种版式、市场条目、SVG、演练和基础内容材料。

内容从本机文件读取，源码中不再嵌入这些资源的工厂与封面 base64；删除内容不会触发自动恢复或角色名字迁移。模板编辑和删除以文件为准。程序 JS/CSS 仍分离。

构建器验证逐文件哈希，仅打包发行清单内容，排除个人凭据、任务数据库、缓存、临时文件与工作区备份。不再保留会生成不完整程序的旧 EXE 打包配置。

### 2. 预览与原图导出一致

导出预览与下载使用相同的编译文档和尺寸规则。缩略预览保留实际原图尺寸信息；下载使用实际原图及编辑后的原生分辨率，不使用请求参数里的占位宽高。

同视口下验证横图、竖图、小图的完整比例与布局。小尺寸图不被强制拉大；普通原生阅读仍按需加载。AFTERGLOW 保留已接受的设计；无缝版式继续纯图零间距，不抹掉原始台词。

### 3. HTML / 原生 ZIP 的独立源素材选择

- 导出分别选择附带分镜和变量；首次默认都不附带，并披露提示词、变量值、逐幕覆盖与参考图的隐私风险。
- 接收方在一个确认窗口分别选择是否导入；支持画册单独导入。
- HTML 惰性数据解析，不执行文件脚本；支持新版元数据及具有明确帧标记、内联图片的旧 Mio 导出，不接受任意网页。
- 原生 JSON / ZIP 同样遵守独立同意；新 ID、独立图片、分镜与变量引用重映射，不覆盖原资源。
- 附带分镜生成的新计划为禁用状态。变量只加入预设库，不自动替换现有设定；仅导入变量也保留参考图和逐幕变量供再次分享。
- 错误、取消与检查不写资源；已通过的多个资源作为同一批次提交。

### 4. 与资源页面协调的入口

画册集首页导入画册；单册菜单导出原生分享包；分镜导入/导出在模板选择器旁；变量在设定页导入/导出；工作流、展示模板保留各自入口。设置页只保留全局服务、保存和维护。

## 升级方式

停止旧服务，保存工作区备份，将新版解压到新程序目录，再用 `MIO_DATA_DIR` 指向原 2.1 `data/`。**不要把新版 ZIP 的随包内容覆盖解压到自己的唯一工作区。**

实际原始 2.1 交付包的升级对照覆盖了编辑后的七种版式、默认导出选择、画册标题与单册版式。1.x 聚合格式仍通过显式转换工具输出到新目录；新版不自动迁移或删除旧文件。

## 保持不变

摘要启动及按需读取画册正文；版本条件写入与跨字段合并/冲突保护；不可变图片与可编辑图层；本机权限受限的凭据；持久任务和幂等；未知请求不自动重发；画册删除只需一次确认，迟到结果不复活已删画册。

可选《晴天借阅室》仍是独立示例，不自动装进现有工作区。
