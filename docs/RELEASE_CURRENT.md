## 保持的产品规则

独立分镜/预设、三步装配向导、真实 N:N 连线画布、待命默认、冻结批次、局部重跑、显式负向变量、唯一规范配置继续保留。可选功能与助手默认开启但尊重已保存的 false；视觉审校 API 仍只有工具卡入口；市场保持独立全页。扩展代码与用户数据保持分离。

## 安装变化

首次运行需要安装 Pillow 11.3–12.x：

```bash
python -m pip install -r packaging/requirements.txt
python server.py
```

启动器不会自动联网；缺少依赖时显示安装命令。可执行变量仍需要 Node.js 20+。

## 必须明确的边界

- ComfyUI 运行中任务的安全物理中断需要其原子按任务取消 API。旧版不能安全中断运行项时显示未确认/升级提示，不使用可能误停他人的全局 `/interrupt`。收到任务 ID 前取消也无法宣称已撤销接单。模型缓存显存不等于正在执行的任务，本版本不宣称释放全部显存。
- ZIP 使用简洁阅读页，精确保留原图，不复制自定义模板脚本。PDF 是逐页图片，不含可编辑台词层；非 JPEG 会转换，有 SVG 或缺页时改用 ZIP。没有另做无上限拼接长图。
- 原图入口上限为 50 MiB；缩略尺寸为 16–1024，按 64 像素量化。SVG 使用有体积限制的矢量预览，不伪称已经栅格化为 WebP。
- 自动化覆盖不等于真 GPU、真实付费供应商、Windows 实机或系统级输入法验证。未做的验证不作为已完成项宣传。
