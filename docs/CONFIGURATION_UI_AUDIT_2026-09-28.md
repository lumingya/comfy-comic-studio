# 配置界面衔接与回归记录 · 2026-09-28

## 范围与原则

保留当前 `server/` 新后端与经典界面外壳，重点修复「工作流与 API 配置」和通用模型接口页。对照冻结的旧版配置工作台、当前 API、现有测试与用户提供的云端渠道截图：不是回滚后端，也不是只换皮肤。

未修改个人 `data/`、没有重启正在使用的服务，也没有调用真实 ComfyUI / 付费图像或文本服务。测试使用临时数据库、随包夹具与模拟接口。

## 界面组织

- **本地 ComfyUI：** 按「连接服务 → 工作流与映射 → 选择出图配置」组织；检查连接前先保存正在编辑的地址，失败不丢草稿。
- **云端出图：** 渠道列表与单渠道编辑分开；名称可改，内部 ID 只读并放在高级项。默认渠道明确选择，不因新增、排序或删除而悄悄切换。
- **出图配置：** 出图方式、渠道 / 工作流、候选数优先展示；多阶段精修、修图链、变体、调度与提示词默认值保留在高级项。新建纯云端配置不再附带本地工作流或实例。
- **通用接口：** 地址、密钥、文本模型优先；视觉 / 共享图像模型、请求节流、质检与安全项折叠。
- **保存反馈：** 明确区分未保存、保存中、已保存；失败保留输入；切换查询参数页签也会拦截未保存的离开。底栏的数据入口不再固定声称“已保存”；保存栏和 Toast 避让底栏，不遮住保存按钮。
- 保留 `/settings?tab=instances|workflows|profiles|channels` 旧链接；中英双语、键盘页签、明暗主题与窄屏布局一并处理。

### 云端参数不再混用

| 协议 | 常用配置 | 不再造成的误解 |
|---|---|---|
| OpenAI Images | 地址、密钥、模型、`size`、`quality` | 不再显示实际未传给该适配器的独立宽高输入；尺寸 / 质量允许服务商自定义值 |
| NovelAI | 地址、密钥、模型、宽高；其余采样参数在高级项 | 旧数据中非 64 倍数的尺寸仍能保存，由后端按既有规则对齐 |
| Chat 图像反代 | 地址、密钥、图像模型；负向描述在高级项 | 不再展示该协议未接入的尺寸 / 质量控件；明确这不是普通文本聊天模型 |
| 扩展适配器 | 保留未知类型和值 | 不把自定义协议强制转成内置类型，不丢弃原有配置 |

保存配置和编译预览均不提交生成任务。单纯添加渠道不代表已切换生成方式；页面提供进入「出图配置」及装配的下一步入口。已有装配快照不会被模板编辑追溯修改。

### 工作流能力保留

常用映射只展示正向、负向、种子、宽、高、输出六项；绑定报告、参数 JSON、原始节点图、编译预览和备注统一收进「高级工作流工具」。

仍支持：

- `[mio:*]` 标记与自动识别；JSON Pointer 的任意字段和一对多映射。
- 原有 `values`、`overrides`、`variants`、`guard`、`frontend` 等配置原样保留，不被常用表单重建丢失。
- API 工作流导入、带映射的 JSON 导入导出、复制、删除及选择实例后诊断节点 / 模型。
- 内置节点图只读，但映射可编辑；可复制后再改图。
- 仅编译已保存的配置；存在未保存修改时禁用编译 / 复制 / 导出，避免拿旧配置当成新结果。

## 后端修复（向前修，不回滚）

1. **Chat 图像渠道：** 独立地址使用自己的密钥；不会把共享文本服务密钥发送给另一服务。空地址可沿用共享接口，专属参数不污染共享客户端。
2. **配置引用：** 校验重复渠道 ID、未知 ID 的掩码密钥、失效默认值；拒绝删除仍被出图配置引用的渠道、工作流或实例。只校验本次变更涉及的设置，不把历史配置变成全局写入障碍。
3. **工坊保护：** 保留新增的克隆能力，补回后续覆盖中丢失的并发初始化锁、装配前验证和快照复制。克隆保留变体及画布，但不复用生成候选 / 图片。
4. **本地基础宽度：** `RenderProfile.base_width` 原来没有进入编译链路；现在进入实际节点输入和任务快照，按画幅推导高度并对齐 64，单格显式宽高仍优先。未提供该参数的独立编译调用保留原来的约百万像素策略。
5. **提示词预览：** 按单格覆盖 → 变体覆盖 → 作品 / 默认配置解析有效出图配置，带上其质量词、负向词和本地尺寸。接口响应形状不变。

注意：基础宽度现在真正生效；默认配置为 832 时，本地正方形输出不再因为忽略配置而固定为 1024。云端尺寸仍由其适配器配置决定。
