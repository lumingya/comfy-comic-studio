# Mio 1.1.1 — 连续阅读与无重载模板面板

2026-09-12 · 本地改进版，基于已交付的 1.1.0 完整运行包；不是上游官方发布。

## 这次改动

### 打开就能下滑阅读整册

默认「留白 · 完整画面」现在采用连续卷轴：按分镜顺序展示整册，滚动即可阅读，不必逐张翻页。图片保持原始比例和小图尺寸上限，使用懒加载；有尺寸信息的图片会预留空间，减少载入时的跳动。

单幅完整画面、双页模式仍可在「版式 → 本次展示与导出设置 → 阅读方式」选择，选择结果按画册记住。已明确设置过的全局阅读偏好、画册选择过的其他模板不会被升级强制清除。

连续阅读中的旁白、提示词和框线设置现在也正确作用于正文。

### 打开模板选择面板不再重载画册

1.1.0 的缺陷已对实际交付 ZIP 复现：只收起模板面板，没有切换任何模板，就更换了 iframe、递增预览版本，并再次调用图片准备函数。

本版将面板可见状态与阅读内容分离：

- 点击顶部「版式」按钮或面板关闭按钮，只展开/收起面板。
- 搜索模板不会重新准备图片。
- 再次点击当前已选模板，不重复重建当前阅读文档。
- 图片正在载入时展开/收起面板，不中止原来的载入任务。
- 保留当前 iframe、图片节点及模板内脚本状态，不通过清缓存或强制刷新掩盖问题。
- 按钮增加展开状态与面板关联的无障碍属性。

真正切换模板、修改影响画面的展示设置，仍会更新预览。原有明确点击导出后的三图样张功能保留；单纯展开/收起面板不会偷偷切换整册/样张状态。

### 内置模板的低调落款

五个内置模板的预览及导出底部加入一致的小诗：

> 一念成画，片刻成章。  
> 把未完的故事，留给下一束光。

下方以小号文字显示 **Mio · github.com/lumingya/comfy-comic-studio**。

落款随内容位于底部，不固定悬浮、不压住画面，不替换创作者原有签名。交互翻页模板只在末页显示。用户自行创建、导入或另存的模板不被强制加上落款。

预览中的项目链接只打开固定项目地址；iframe 仍保持 `sandbox="allow-scripts"`，没有为了外链放开父页面访问或任意弹窗权限。离线 HTML 的地址可正常显示，点击访问项目网站仍需联网。

## 启动与升级

这是**完整源码运行包**，保留独立 JS/CSS；运行只需 Python 3.10+，不需要 Node.js/npm，也不含 Windows exe。

1. 关闭旧版网页和服务，备份旧项目完整目录。
2. 将新包解压到新目录，把原 `data/` 整体复制进去；旧 `images/` 和旧式 JSON 如仍在使用，也按原位置保留。
3. Windows 双击 `start.bat`；macOS/Linux 运行 `sh start.sh`；或者运行 `python server.py`。
4. 打开终端给出的地址（默认 `http://127.0.0.1:8777`），强制刷新网页，核对画册与保存状态。

不要直接双击 `index.html`，不要同时运行新旧服务编辑同一数据目录。

**必须保留 `data/execution/jobs.sqlite3`。** 它包含任务记录、画册删除标记和图片编辑记录。本次不清空或迁移这些记录，1.1.0 的气泡图层、原图恢复、删除防复活与生成队列保护继续保留。
