# 新版前端体验修复方案（对照旧版）

日期：2026-09-27。起因：重构后的 React 前端在“功能面”上不如旧版 `legacy/`：
操作步骤变多、批量操作和右键菜单消失、界面看不出该在哪改、编译出来的提示词
不知道从哪来、景别 / 角度这类结构化下拉被当成必填。后端（领域模型、任务引擎、
编译器）本身没问题，问题集中在**前端的信息架构和交互模型**。本文给出：
根因、旧版 vs 新版的功能差距清单、按优先级排好的改法。已经落地的项打 ✅。

## 1. 根因

| # | 根因 | 表现 |
| --- | --- | --- |
| R1 | **“结构化表单优先”取代了旧版“提示词优先”**。旧版一格 = 一段自由提示词（可带 `{变量}`）+ 台词；新版把一格拆成 15+ 个等权重字段，真正决定画面的“追加提示词”被埋在“高级”折叠区。 | 用户找不到“在哪写提示词”，觉得每个下拉都要填。 |
| R2 | **编译过程不透明**。旧版预览里每个 `{变量}` 都标了来源；新版只显示最终字符串，`no humans`、`upper body`、`general` 这些由内置规则加进去的词没有任何解释。 | 用户以为“提示词被篡改”，不信任编译器。 |
| R3 | **没有选择模型**。旧版有框选 / Ctrl 点选 / 右键分组菜单 / Ctrl+A / Esc / Delete，作用于画廊、分格、任务、工作流库、映射；新版一切操作都是“先点进单个对象再点按钮”。 | 批量删格、批量改字段、批量重跑全部消失。 |
| R4 | **分格对象操作缩水**。旧版格级操作：前移 / 后移 / 复制 / 删除 / 新增 / 导入 / 导出 / 历史 / 只跑这一格测试；新版只有拖动排序、复制、删除。 | 长条漫（30+ 格）编辑效率明显低于旧版。 |
| R5 | **出图参数按格覆盖只剩 JSON**。旧版每格可直接改宽 / 高 / 步数 / CFG / 去噪 / 种子；新版只有种子，其余要写 `node_overrides` 的 JSON Pointer。 | 普通用户不会写 `{"/3/inputs/steps": 30}`。 |
| R6 | **缺少引导**。旧版有帮助抽屉、快捷键（Alt+1/2/3）、每步的说明文案；新版靠字段名自解释，而字段名又是术语（“版式 / 内嵌 / 出血”）。 | “界面不清晰”“不知道在哪改”。 |

## 2. 功能差距清单（旧版 → 新版）

图例：✅ 已恢复 · 🟡 部分 · ❌ 缺失 · ➕ 新版独有

### 2.1 分格编辑器

| 旧版能力 | 新版状态 | 说明 |
| --- | --- | --- |
| 自由提示词是主输入，支持 `{变量}` | ✅ | `overrides.append_prompt` 提升为第一个字段“画面提示词”（多行），原样追加到自动标签之后。 |
| 台词 / 旁白 | ✅ | 台词编辑器保留。 |
| 负向词（可选） | 🟡 | 在“高级”里，仍是单行；批量编辑可对多格统一设置。 |
| 每格出图覆盖：宽 / 高 / 步数 / CFG / 去噪 / 种子 | ✅ | “出图参数覆盖（只对这一格）”：渲染档 / 宽 / 高 写入 `overrides.profile_id / width / height`；步数 / CFG / 去噪 / 采样器写入 `overrides.values`（对应渲染档 `[mio:*]` 槽位）；`node_overrides` 保留给高级用户。 |
| 每格变量覆盖 | ✅ | 同一区块的“变量覆盖”键值表（`overrides.values` 中的 `$name`）。 |
| 解析后的提示词预览，`{key} ← 来源` | ✅ | 编译结果改为按来源着色的标签条，悬停显示具体字段，附图例；纯文本仍可展开复制。后端 `sources` / `negative_sources` 字段。 |
| 景别 / 角度可不填 | ✅ | 两者新增“不指定”（`""`），新格默认不指定；不指定时不生成构图标签，自然语言版也不再写“a medium shot, at eye level”。景别 / 角度 / 地点 / 时间 / 标签收进可折叠的“镜头、场景与标签”。 |
| 描述字段的用途说明 | ✅ | 标明“描述”只给剧本助手和自然语言模型看，不进入 tag 提示词（之前用户以为它会变成提示词）。 |
| 前移 / 后移 | ✅ | 右键菜单：上移 / 下移 / 移到开头 / 移到末尾 / 移到第 N 格；拖动保留。 |
| 复制 / 删除 / 新增 | ✅ | 保留。 |
| 导入 / 导出单格 / 多格 | ✅ | 右键“导出 N 格（JSON）”下载 / 复制；“导入分格…”支持粘贴 JSON 或选文件，插到当前格之后（`POST …/panels/import`，id 重新签发）。 |
| 历史（版本回退） | ✅ | 每次保存留一条快照（同一 revision 去重、每格最多 50 条），“历史…”对话框可按格回退（`GET …/history`，`POST …/restore`）。 |
| 只跑这一格的测试出图 | ✅ | 编辑器底部“试出这一格”：排单格任务，进行中的进度和最近几张缩略图直接显示在编译结果下方。 |
| 共享 / 按书 作用域切换 | ➕ 由“设定集 / 变体”替代 | 设计上更合理，不回退。 |
| 出场角色（带服装 / 表情标签）、构图（区域 / 控制图）、版式 | ➕ | 新版独有，保留但降级为折叠区。 |

### 2.2 选择与批量

| 旧版能力 | 新版状态 |
| --- | --- |
| 框选 / Ctrl 点选 / Shift 连选 | 🟡 `useSelection`：点选 / Ctrl 点选 / Shift 连选 / 右键保留多选；框选未做（列表是窄栏，收益低）。 |
| 右键分组菜单（按对象类型） | ✅ `ContextMenu`：分格（单 / 多）、候选图、任务三种对象各自一套。 |
| 批量：删除 / 复制 / 改字段 / 重跑 / 采用 / 导出 | ✅ 分格：删除 / 锁定 / 批量编辑 / 追加提示词 / 出图 / 导出；候选图：采用 / 拒绝 / 恢复 / 质检；任务：暂停 / 继续 / 取消 / 重试失败项。 |
| Ctrl+A / Esc / Delete / Enter | ✅ 分格列表：Ctrl+A 全选、Esc 清除、Delete 删除选中（锁定格跳过）；任务栏：Ctrl+A / Esc。 |
| 选择状态栏（“已选 5 格”） | ✅ `.selection-bar`，剧本页 / 出图板 / 任务页三处。 |

### 2.3 任务与其他

| 旧版能力 | 新版状态 |
| --- | --- |
| 任务列表带进度 | ✅ 列表接口返回 `done / total / failed`，任务栏显示 `3/12` 和细进度条。 |
| 帮助抽屉、快捷键 | ✅ `?` 键或侧栏问号打开，按页面列出操作、问答和快捷键。 |
| 主题快速切换 | ✅ 记住每种明暗模式下最后用的主题，切换不再跳回内置墨 / 纸。 |

## 3. 修改方案（按优先级）

### P0 · 先让单格编辑不再别扭（本次已落地 ✅）

1. ✅ 提示词来源可视化：`compiler.compile_panel` 输出 `sources` / `negative_sources`
   （每个标签 + 来源：`quality` `rating` `style` `cast` `character:<id>` `shot` `angle`
   `location` `time` `panel` `append` `profile` `negative` `style_negative` `extra`），
   `PromptPreview` 按来源着色。
2. ✅ 景别 / 角度可为空，新格默认为空；LLM 生成的剧本仍会给出具体值。
3. ✅ 分格编辑器重新分层：画面提示词 → 描述 → 出场角色 → 台词 → 折叠“镜头、场景与标签”
   → 折叠“画幅与版式” → 折叠“构图” → 折叠“高级：原始提示词与节点覆盖” → 编译结果。

### P1 · 把旧版的操作效率拿回来（已落地 ✅）

1. ✅ **选择模型**（`app/selection.ts` 的 `useSelection(ids)`）：点选 / Ctrl 点选 / Shift 连选；
   Ctrl+A、Esc、Delete；`.selection-bar` 显示数量和批量按钮。剧本页、出图板、任务页共用。
   框选未做。
2. ✅ **右键菜单**（`components/ContextMenu.tsx`）：
   单格：上移 / 下移 / 移到开头 / 末尾 / 第 N 格 / 复制 / 锁定 / 删除 / 只出这一格 / 复制提示词 / 历史 / 导出；
   多选：批量编辑 / 追加提示词 / 锁定 / 解锁 / 出图 / 导出 / 删除。
   后端新增 `POST …/panels/batch`（`changes` + `append_text`）、`POST …/panels/batch-delete`，一次提交、一次 revision。
3. ✅ **导入 / 导出**：选中格导出为 JSON（`Panel` 模型，去掉 id / order），粘贴或选文件导入到当前格之后
   （`POST …/panels/import`）；跨话复制用同一格式。
4. ✅ **每格出图覆盖表单**：渲染档 / 宽 / 高 / 步数 / CFG / 去噪 / 采样器 直接字段
   （宽高与渲染档走模型字段，其余走 `overrides.values` → `[mio:*]` 槽位；`node_overrides` 保留）；
   同一区块的“变量覆盖”键值表。
5. ✅ **批量编辑对话框**：景别 / 角度 / 地点 / 时间 / 画幅 / 锁定 / 负向词 / 追加提示词，
   每个字段三态（保持 / 设为 / 清空），只提交被改动的字段。

### P2 · 引导与可发现性（已落地 ✅）

1. ✅ 帮助抽屉（`?` 键 / 侧栏问号）：按页面（作品 / 设定 / 剧本 / 出图板 / 画布 / 任务 / 设置）列出操作、
   常见问题与字段解释，底部是全站快捷键。
2. ✅ 剧本页内“试出这一格”：不切页，排单格任务，进度与最近缩略图显示在编译结果下方。
3. ✅ 分格历史：`storage.py` 每次保存留快照（同 revision 去重、每格 50 条上限），可按格回退。
4. ✅ 任务页（Ctrl 点选 → 暂停 / 继续 / 取消 / 重试失败项）与出图板（Ctrl / Shift 点图 → 采用 / 拒绝 / 恢复 / 质检）复用选择模型和右键菜单。

### 不做的事

- 不恢复旧版“共享 / 按书”作用域切换与旧的画廊页；设定集 + 变体已经覆盖。
- 不把结构化字段全部去掉：它们服务于剧本助手、自动参考图、动态漫镜头运动；只是不再强制、
  也不再和提示词抢位置。

## 4. 验收方式

验收记录（2026-09-27）见文末 §5。

- 一个 30 格的话：从空白到全部填好提示词、删掉 5 格、把 3 格挪到开头、批量把 10 格改成夜晚，
  操作次数不多于旧版。
- 任意一格的编译结果里，每个标签都能悬停看到来源；用户写的词永远在最后且原样保留。
- 新建格不选任何下拉也能出图，提示词里没有 `upper body` / `eye level` 这类没选过的词。

## 5. 验收记录（2026-09-27）

| 验收项 | 结果 | 依据 |
