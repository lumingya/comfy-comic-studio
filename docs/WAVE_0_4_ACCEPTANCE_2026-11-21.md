**复审中修掉的实际问题**

- 变体改为原子追加，避免整表保存覆盖另一窗口新建的版本。
- 过期剧本提案的设定集与分镜一起回滚；停用的编辑阶段在核心提交前被拒绝。
- 隔离面板使用 MessagePort 接收原生 Blob，并在自身创建 URL；下载由宿主的明确点击触发。
- Webhook 已消费 ID 不因首次签名时间窗结束而释放，合法重签的旧投递仍被拒绝。
- Markdown 创建请求先落盘 pending；响应丢失时不盲目再建，可明确绑定并核对已有分镜。
- 云端传输逐原始块检查截止与停止，429 后重新排发送时隙；ZIP 构造前有界预检，截断 JPEG 被拒绝。
- 受管暂存文件拒绝硬链接；pending 结果再次核验实际文件后才回流作品。

持久发布专项共 155 项通过：154 项集中回归，加一项真实子进程 `os._exit(91)` 强退。强退点位于完整暂存文件已 fsync、尚未 rename；连续两次重开工作区恢复同一候选，模拟收费请求日志只有一次。另有独立审计复验硬链接与文件篡改案例，补交付不增加上游提交。
