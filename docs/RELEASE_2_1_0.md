# Mio 2.1.0 — 无缝 · 纯图阅读

2026-09-13。新增一个内置画册模板，不替换已有六个模板，也不擅自改变默认选择或原有画册的版式。

## 效果与入口

打开画册 → **版式** → **无缝 · 纯图阅读**。

- 正文只显示图片，没有配文槽位、幕标题、可见编号、重复封面或结尾落款。
- 每幕上下零间距，无边框、圆角、阴影。按 `stepIndex` 排序，连续向下阅读。
- 横竖图保持完整比例，不裁切。小图保持原尺寸居中，不强行拉大。
- 原始配文、提示词、图片及编辑记录仍在画册中。图片内部已经绘制的对白和气泡不会移除；图片自身的白边也不会自动裁掉。
- 同一版式用于整册阅读、预览及离线 HTML。即使打开配文/提示词/边框选项，该模板也不会新增文字区和框线。
- 不使用自定义脚本；纯 CSS 即可排版。既有预览沙盒、CSP、原图导出与原始图片保留机制不变。

[直接打开离线演示](../examples/seamless/无缝_纯图阅读_演示画册.html) · [展示与导出教程](guide/PRESENTATION.md)

## 更新方式

2.0 → 2.1 **不需要再转换工作区**。停止旧服务、备份数据，将新版完整程序解压到新文件夹，用 `MIO_DATA_DIR` 指向原来的 v2 工作区。第一次载入会补充这一项内置模板，不改写现有模板或自定义副本。

1.x 仍请先按[独立文件转换教程](guide/FILE_LIBRARY_CONVERSION.md)输出新目录。不要直接覆盖唯一的旧数据。

源码运行包需要 Python 3.10+；普通运行不需要 Node.js。开发测试需要 npm 与 Playwright。

## 实际验证

以**真正交付的 2.0.0 ZIP**为基线：在旧程序中保存六个模板、自定义副本、默认选项及画册选择，停止旧服务后，用新版打开同一个隔离工作区，核对这些内容保持不变。

新增回归验证了真实界面选择、零间距测量、完整比例、无可见配文、乱序分镜排序、原始对白/提示词保留、240 px 小图及图内对白字节不变、实际下载并离线打开、禁用 JavaScript，以及原生文件保存/重载。

桌面 1440 px、移动 390/320 px，浅色/深色均检查了无横向溢出和图像衔接，并人工查看截图。完整原有回归、AFTERGLOW 排版和最终 ZIP 解压运行也纳入交付验收。日志与说明见 [2.1 验收](acceptance-2.1/README.md)。

没有调用付费生成供应商，没有实体手机、原生 Windows/macOS 或 Safari/Firefox 实机认证。当前模板沿用已有模板预览链：四路图片准备、整册准备上限 64 MiB；不把此项样式更新宣传为无限大图库优化。
