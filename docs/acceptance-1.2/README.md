## 本轮关注的真实行为

1. 仅注册一个新内置模板，不替换原有五个模板或默认连续阅读。
2. 选中第二幕作封面，正文仍从第一幕开始；封面索引与原画面顺序分离。
3. 横图 1376×768、竖图 928×1152、方图 768×768、小图 240×180；离线原分辨率不变，小图不被放大。
4. 目录定位、图片键盘打开、实际尺寸、前后边界、缺图跳过、Escape 和焦点返回。
5. 预览 iframe 保持原有 sandbox/CSP，完整导出没有 HTTP 请求。
6. 明暗配色、减少动态效果、无 JavaScript、无 dialog/IntersectionObserver、夜间打印。
7. 手机 390px、窄屏 320px、长标题、长篇章/角色信息、转义正文、多册及缺页。
8. 模板包导入导出保留固定增强标记；删掉可选装饰节点的模板副本仍可编译。
9. 原面板展开/收起不重建已载入 iframe；新预设不误继承未经修改的旧预设色。
10. 默认正文小字与场景标记在纸色上的对比度达到 4.5:1；这不是整站或全部用户配色的 WCAG 认证。

## 调试记录

- 竖图接近 4:5 时，原 0.8 分类阈值将 928×1152 误归入近方图；根据真实图像比例调整为 0.9，并统一编译和运行时分类。
- 测试等待懒加载图片时曾卡住；仅在测试的全图解码步骤主动 eager，生产懒加载保留。
- 无 dialog 时 hidden 曾会被增强样式覆盖；明确保证 hidden 优先并执行功能降级测试。
- 小字灰色和场景标记提升对比度；打印从暗室模式回到白纸；大图等待解码后才允许实际尺寸。
- 版本更新最初漏掉启动器标题，随后编辑又破坏 CRLF；已恢复 Windows 规范换行，启动器静态检查及最终完整回归通过。未执行原生 Windows。
