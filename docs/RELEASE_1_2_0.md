# Mio 1.2.0 — 余光 · AFTERGLOW

2026-09-12 · 本地改进版，基于已交付的 1.1.1 完整运行包；不是上游官方发布。

## 这一轮，只新增一个模板

**余光 · AFTERGLOW** 是一册暖纸色的艺术书。铜色细线、深绿文字、拱形封面、中英文字体对照和有节奏的留白，将画册从封面、卷首、正文带到收尾。

原有五个模板保留；没有选择过模板的画册仍默认使用「留白 · 完整画面」连续阅读。升级不会替换已选模板，也不会改动图片或编辑图层。

### 打开方法

1. 打开已有画册，点击顶部 **版式**。
2. 在模板列表选择 **余光 · AFTERGLOW**，收起侧栏即可阅读整册。
3. 点击 **翻开这本画册** 进入正文；**目次** 可定位分镜。
4. 点击图片或 **细看这一帧** 查看大图，可切换实际尺寸、上一帧/下一帧，按 Escape 关闭。键盘也可聚焦图片并按 Enter 打开。
5. 右下角 **暗室 / 日光** 切换本次阅读的明暗配色，不修改图片或全局界面主题。
6. 顶部 **导出** 下载完整离线 HTML。导出的画册双击即可阅读，不需要启动 Mio。

包内 `examples/afterglow/余光_AFTERGLOW_演示画册.html` 是可直接打开的示例，不会导入、覆盖或添加任何用户画册。

### 图片如何排版

- **横图**：展开为宽幅，图下采用两栏标题和旁白。
- **竖图**：完整显示画面，图文左右交替；不会统一裁成横向卡片。
- **近方图**：沿用图文对照，保持原始比例。
- **小尺寸图片**：置于留白画框，显示尺寸不超过原始像素，不强行放大。
- 只有封面装饰区域取景裁切，使用画册已选择的封面与焦点位置；正文顺序不变，正文不裁切。
- 未生成、已删除或读取失败的图片保留明确状态，不使用演示图假冒完成。
- 创作者签名保留，项目小诗和链接继续位于末尾。

模板选色时也修正了一个细节：没有改过的上一个模板预设色不再误盖住新模板的设计色；与旧预设不同的自定义主题色仍保留。

### 动效不是联网插件

这一版扩展了模板编译器，为 AFTERGLOW 提供固定、内置的增强程序：轻微封面视差、滚动入场、阅读进度、目录、大图、实际尺寸与日夜切换。没有自动播放、远程字体、CDN 或网络请求。图片仍使用懒加载。

导出文件自包含图片、样式与固定程序。原有隔离 iframe 和内容安全策略不变；自定义或导入的任意脚本仍需要原有授权，不因为模板标记而自动获得执行权限。

系统设置「减少动态效果」时取消视差及入场动画。禁用 JavaScript 仍可完整阅读静态画册；不支持原生 dialog 的浏览器隐藏不可用的目录/大图按钮。打印时隐藏悬浮工具并使用浅色纸张。

## 启动与升级

这是**完整源码运行包**，不是补丁，也不含 Windows exe。应用保留独立 JS/CSS 文件；运行只需 Python 3.10+，不需要 npm。

1. 关闭旧版网页和服务，先备份旧项目完整目录。
2. 解压新包到新目录，把旧 `data/` 整体复制进去。旧 `images/` 和旧式 JSON 如仍在使用，也按原位置保留。
3. Windows 双击 `start.bat`；macOS/Linux 运行 `sh start.sh`；也可运行 `python server.py`。
4. 打开终端给出的地址，默认 `http://127.0.0.1:8777`。强制刷新网页，核对画册、编辑图层及保存状态。

不要双击应用的 `index.html` 启动，不要让新旧服务同时编辑同一数据目录。**必须保留 `data/execution/jobs.sqlite3`**：其中包含任务、删除标记和图片编辑记录。本次没有改动后端任务、删除或原图保存机制。

## 验收与边界

记录见 `docs/acceptance-1.2/` 与 `docs/TEST_RESULTS.txt`。新增专项实际使用 UI 选择模板和导出，再通过 `file://` 离线打开；不是只对模板字符串截图。覆盖横竖方小图、封面索引、目录、大图、键盘、手机视口、明暗、减少动态、无 JS、无 dialog、打印、长文字、多册、缺图及模板包往返。

示例图是本轮 AI 生成的虚构海岸车站插画；方图和小图是演示素材的派生裁片，用于验证不同原始尺寸。它们不属于用户数据，也不用于冒充供应商验收。字体使用系统字体，Windows/macOS/Linux 上的具体字形会有差异。

实际浏览器环境为 Linux Chromium，手机为模拟视口。未在实体手机、Windows/macOS 原生系统、Safari/Firefox 或真实付费供应商上验收；不宣称覆盖全部浏览器或设备。本轮没有真实付费生成请求。
