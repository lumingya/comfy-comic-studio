## 不只检查数量

普通流程包括首次启动、实际本机原图显示、草稿保存、分镜/变量分享、离线阅读、原生图片编辑、画册导入、显示模板选择及升级保留。

异常流程包括受控的慢响应、断开、4xx/5xx、未知执行结果、迟到结果、重启、CAS 同字段冲突和不同字段合并、删除不复活、损坏 ZIP、错误类型、缺图、非法 SVG、无效元数据和取消不写入。上述测试使用本地受控服务，没有真实付费请求。

## 图像检查

检查桌面/窄屏和明暗主题的画册、分镜/变量入口、分享确认、原图导出、AFTERGLOW 与图片编辑界面。图片尺寸断言覆盖横图、竖图、小尺寸原图，以及编辑后原生分辨率。

`original-export-*.png` 是尺寸测试用的简单色块画面，不是模型生成质量示例。`sharing-*` 是实际分镜/变量 UI。模板演示图在 `examples/`，不将这些插画当作新版本实际模型输出。
