# 队列与画册管理更新

本次在上一版独立工作流管理基础上继续修改。主要实现位于 `js/organize.js`，入口安装在 `js/app.js`，仍通过 `npm run build` 生成 `index.html`。

## 更简洁的生成队列

- 移除大块“添加生成任务”卡片，改成单行工具栏：工作流、生成范围、加入队列。
- 只保留页面顶部“生成画册”的高亮绿色。队列操作按钮和悬浮助手在此页使用普通颜色；导航选中状态继续保留。
- 移除重复的“加入并开始”按钮，加入队列后自动依次执行。
- 队列处于暂停状态时，新加入的任务不会擅自恢复执行。可以先暂停，再集中添加和排序，最后继续执行。
- 刷新页面不会直接启动 GPU；恢复的待执行任务可以点击“执行待办”，也可以通过主动加入新任务启动顺序执行。

## 顺序、拖动与删除

任务列表按照实际保存顺序从上往下展示，不再倒序截取最近十条。

- 待执行任务左侧的拖动手柄可调整顺序；同时提供上移、下移按钮，方便键盘或触屏使用。
- 排序修改直接进入实际调度队列，不只是视觉排列。
- 已经开始的任务锁定位置，不能拖动或删除。需要删除正在执行的任务时，请先使用“中止”。
- 待执行或历史任务可以单独删除，需要确认；画册、已生成图片、分镜和预设不会被删除。
- 确认删除期间若任务已经开始，会拒绝删除，避免与渲染竞争。
- 每个任务可以展开修改尚未执行分镜的工作流；已经开始的分镜仍保持快照。
- 单幕任务在概览中显示幕号，便于区分同一画册的多个任务。

**注意：原有“中止”操作仍会中止 ComfyUI 并清空其待执行队列；请不要在共享 ComfyUI 服务上随意使用。单独删除未开始的本地任务不调用此操作。**

每次加入新的生成范围仍创建独立画册版本。若要在同一本画册中让 A、B 分镜使用不同工作流，可加入整本任务，再调整 B 幕的待执行工作流。

## 缺失画面不再冒充成品

- 未生成的封面、任务缩略图、阅读器分镜显示中性的问号和“暂无画面”。
- 图片加载失败不再用示例图替换，也不改写已保存的原图链接。
- 真实 GPU 报错会保持失败状态，也不会生成假的成功画面。
- 导出不完整画册时，未生成页使用纯问号占位，不混入故事示例图。
- 对于已有原图但读取失败的情况，导出/目录打包会报告问题，要求修复图片，不再偷偷使用 `offlineImage` 替代。
- 已有的明确示范画册不删除；显式选择的模拟测试模式仍可用于开发测试，但不再是默认设置。

## 真实服务默认配置

新安装默认值：

| 配置 | 默认 |
| --- | --- |
| ComfyUI | real；`http://127.0.0.1:8188` |
| 自动失败回退 | 关闭，真实生成不再回退到示例图 |
| 文本模型 | real；填写实际 API 密钥与模型 |
| XML 生成 | real，默认复用文本模型配置 |
| 视觉审校 | real；填写实际连接信息 |

未填写密钥不再导致自动调用离线规则生成。


这一操作只影响后续任务，不会改写已入队任务的历史快照。首次使用请导入与你本机模型匹配的 API 工作流，或替换默认蓝图中的模型文件名。

Windows 发布脚本同步使用真实模式，并补齐默认 API 图的输出链路、原生配置的 `chatConfig` / `batchRunState` 字段，以及新源码模块的打包清单。本次未实际编译 Windows 可执行程序。

## 画册右键与批量操作

在画册封面、卡片、精选展示区域右键，打开自定义菜单。输入框等文字编辑区域仍保留浏览器原生菜单。

- Ctrl / ⌘ 点击：多选或取消单本。
- Shift 点击：连续选择。
- 右键一个已选择的画册：保留当前多选。
- 右键一个未选择的画册：切换到该画册；按住 Ctrl / ⌘ 右键可追加选择。
- 支持批量导出为 HTML 合集、批量星标、批量删除、批量编辑标题前缀与追加标签。
- 删除有二次确认；生成或精修中的画册不能删除。
- 菜单支持方向键、Home/End、Esc；聚焦画册后可用 Shift+F10 打开。
- 手机上的“更多”按钮也使用同一菜单。

## 画册排序

- 网格中的画册可以直接拖动。
- 精选展示中可展开 **调整画册顺序**，在完整列表内拖动或用上下按钮移动。
- 排序后自动切换到“手动排序”，不会继续按创建时间覆盖拖动结果。
- 仍可从排序下拉框切换回最近创建、最近修改、分镜数量。
- 手动顺序按画册集独立保存，通过原生配置持久化，刷新后保留。
- 排序不移动图片目录、不改画册 ID，也不影响另一个画册集。
