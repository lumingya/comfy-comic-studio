# Mio 绘页真实体验暗坑清单与验证记录

基线：`c84ce33`。本机 Chrome 使用独立工作区：50 本画册、120 幕及 1,200 张候选图、60／30／12 幕分镜、20 个预设和含 45 个 LoRA 的工作流；最终独立巡检扩到 55 本画册。测试数据为合成样本，不发送出图任务。下表记录在浏览器中复现的问题和修复行为；实际验收结果另记。

## 一、你提的五个问题怎么修的

1. 画册网格从空白处拖动会框选；封面拖过 6 像素才开始排序。短按会打开画册，批量管理时切换勾选；Esc 清空选中并退出批量管理。分镜与任务列表也支持直拖，并保留触控手柄。
2. 生成向导第二步从眼睛图标查看预设全部变量，「查看合并结果」展示最终值、来源和被覆盖的值。预览浮层可滚动，卡片主体仍负责勾选。
3. 第三步改为固定高度的单幕核对台。方向键或标签切幕，问题可筛选和定位，临时补值重新核对后更新计数；12 幕与 60 幕都保持底栏可见。
4. 八类进阶概念统一放在轻量帮助浮层内，Tab 可以进入链接，Esc 返回原入口。中英文离线教程直达对应锚点，不在主页面平铺说明。
5. 动态壁纸在窗口失焦、页面隐藏或被阅读室和画布遮挡时停播；外观设置提供默认开启的失焦暂停和省电静帧。减少装饰循环，空队列等待事件唤醒。

## 三、开动态壁纸与空载的前后实测

同一台 Windows 本机的 Chrome、1440×900 视口。测试用 720p、30 fps 合成壁纸；每个状态采样约 2.2 秒。下面的 Chrome 任务时间来自 DevTools `Performance.getMetrics`，表示被测渲染进程的主线程时间，不等同整机 CPU、电量或 GPU 时间。

| 壁纸状态 | 视频帧数：改前 → 改后 | Chrome 任务时间：改前 → 改后 |
| --- | ---: | ---: |
| 画册集前景 | 68 → 66 | 448.3 → 105.9 ms |
| 打开命令面板 | 67 → 67 | 607.1 → 5.4 ms |
| 窗口真实失焦，标签页仍显示 | 66 → 0 | 484.1 → 1.5 ms |
| 阅读室遮挡 | 68 → 0 | 522.4 → 90.3 ms |
| 条漫画布遮挡 | 63 → 0 | 519.7 → 1.3 ms |

关掉阅读室或切回窗口后恢复播放。静帧与系统减少动态效果都实测为 0 帧；命令面板遮罩从 `blur(2px)` 变成无实时模糊。静置前景活跃循环从 1 降到 0；独立 CSS 对照的 9 个装饰动画也全部停下。任务引擎空载连续三次采样，每 6 秒调度查询由 29 次降到 0 次，装配队列读、写各由 1 次降到 0 次。

补测使用同一后端、同一隔离样本和两个前端构建（`c84ce33`、`f78332b`），以实际 Chrome 窗口切换让标签保持可见但失去焦点。每组取三次约 2.2 秒采样的中位数；旧版和新版交替测量。CDP 跟踪 `devtools.timeline,blink.user_timing,cc,viz,gpu,benchmark`；按页面标记截取区间，渲染进程内累计 `Paint` 与 `RasterTask`，另外累计浏览器合成器的 `Display::DrawAndSwap`。各列可能重叠，不能相加或当作 GPU 芯片时间。

| 壁纸状态 | 解码帧 | 脚本 ms | 绘制 / 栅格化 ms | 合成器绘制与交换 ms |
| --- | ---: | ---: | ---: | ---: |
| 前景画册集 | 66 → 66 | 101.66 → 0.44 | 1.07 / 0.57 → 0.51 / 0 | 21.15 → 19.76 |
| 窗口失焦、标签仍显示 | 66 → 0 | 0.34 → 0 | 0 / 0 → 0 / 0 | 19.08 → 0 |
| 全屏阅读室遮挡 | 66 → 0 | 161.22 → 54.66 | 23.20 / 5.99 → 8.46 / 1.64 | 39.66 → 1.90 |

相同长篇合成样本各跑 3 次，表内为中位数。每次用鼠标连续滚动 18 次，分镜另外跳到第 28、45、59 幕。超过 25 ms 的帧间隔是本次卡顿信号，不能替代设备实际掉帧计数。

- 独立第四视觉审查员先完成 66 组页面／主题／视口检查和 33 项内容／合成色复核；随后在三种主题、两种宽度下复验补修。390 px 底部「设置」由可见 34 px 变为完整 61 px；直达「关于与更新」由 4 px 变为完整 85 px。壁纸设置区域使用原始主题底色 `rgb(23,25,27)`；进入动画结束后标题、说明和选中标签对比度分别为 14.66、7.36、8.77:1。截图仅在内存采样，没有落盘。
- 独立概念与清晰度审查完成 26 项英文和 18 项中文键盘验收。八类概念的九个入口均点击到正确的离线锚点（目标标题可见），Tab 与 Esc 不穿透导出抽屉。首页渠道预选、预设取消和搜索无结果清除均通过。
