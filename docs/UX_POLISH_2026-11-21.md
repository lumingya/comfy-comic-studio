# Mio 绘页真实体验暗坑清单与验证记录

基线：`c84ce33`。本机 Chrome 使用独立工作区：50 本画册、120 幕及 1,200 张候选图、60／30／12 幕分镜、20 个预设和含 45 个 LoRA 的工作流。测试数据为合成样本，不发送出图任务。下表记录在基线浏览器中复现的问题和拟修复行为；实际验收结果另记。

| 页面 | 复现与观察 | 严重度 | 改进 |
| --- | --- | --- | --- |
| 阅读室 | 打开分幕胶卷，按 Esc，整个阅读室退出 | 中 | 先收起胶卷并归还焦点 |
| 阅读室 | 从展示页链接打开后退出，继续 Tab 跳到页脚 | 中 | 退出时恢复原入口焦点 |
| 阅读室 | 分话请求返回 503，同时显示失败和没有画面 | 高 | 分开加载、失败和空态，重试失败项 |
| 阅读室 | 打开已经删除的画册，出现内部编号和仅重试按钮 | 中 | 用易懂的提示和返回画册集入口 |
| 阅读室 | 对 120 幕胶卷滚轮无反应；切到离屏幕的幕时仍找不到选中缩略图 | 中 | 普通滚轮横移，切幕带入当前缩略图 |
| 画册集菜单 | Tab 到关闭按钮后按 Esc，焦点没有返回入口 | 中 | 从菜单和重命名逐层退出并归还焦点 |
| 命令面板 | 打开后按 Alt+3，底层仍切到工作流配置 | 高 | 模态打开时由顶层接管快捷键 |
| 命令面板 | 执行「新建分镜」只跳到现有分镜 | 中 | 直接打开新建对话框 |
| 侧栏 | Windows 显示 ⌘ K，实际使用 Ctrl+K | 低 | 按平台显示键名 |
| 分镜工坊 | 筛选 Scene 42，在搜索框按 Ctrl+Enter 却跳到已过滤的第 2 幕 | 中 | 搜索时不抢快捷键；从列表导航只在可见幕间移动 |
| 预设工坊 | 重命名按 Esc，下一次 Tab 跳回预设选择器 | 中 | 恢复重命名按钮焦点 |
| 预设工坊 | 390 px 窗口中未分组变量仍是两列，长值被挤窄 | 中 | 窄屏两类变量统一单列 |
| 条漫画布 | 窄屏打开时裁掉画幅；在末幕放大跳回中段 | 中 | 默认适应宽度，缩放保持视野中心 |
| 候选看板 | 120 幕长列表无法直达指定幕 | 中 | 增加紧凑分幕跳转 |
| 工作流配置 | 展开 45 个 LoRA，强度标签逐字换行，不能按名字定位 | 高 | 短标签、定高滚动、按名称搜索 |
| 首页 | 选择 NovelAI，再添加渠道，表单默认 OpenAI Images | 高 | 把入口选定的渠道类型带给新草稿 |
| 首页 | 「先翻开示例画册」打开普通作品 | 中 | 按作品实际状态提供阅读入口，使用准确措辞 |
| 分镜工坊 | 打开失效的链接，提示含内部编号，只有重试 | 中 | 提供返回分镜工坊入口 |
| 任务列表 | 空队列与「只看进行中」无结果提示相同 | 中 | 分别提供新建与清除筛选操作 |
| 扩展市场 | 无匹配结果与目录为空提示相同，不能一键清除搜索 | 中 | 区分两种状态并恢复搜索焦点 |
