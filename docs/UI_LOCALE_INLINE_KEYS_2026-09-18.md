## 本轮修改

1. 首页采用「初光映格，微墨生花」衬线标题、右上收起指引，以及 ComfyUI / NovelAI / OpenAI 兼容三张等宽入口卡片；小屏单列排列。删除多余介绍段落，保留清晰的服务类型和下一步说明。
2. NovelAI / OpenAI 兼容配置页直接显示掩码 API Key 输入框和「保存并使用」。无需先打开管理密钥；管理入口保留，用于选用、删除或管理多条密钥。
3. 即使当前选择服务端环境变量，也可以直接填写密钥；保存后显式切换成本地凭据，不改环境变量。保存成功清空输入框，只返回引用；留空不删除原凭据。
4. 草稿仅存在密码控件，不写入普通应用状态、localStorage 或工作室配置请求。切换渠道或地址清除草稿；异步保存中修改地址，不会把旧地址的密钥挂到新地址。失败保留输入供主动重试，且不进入下一步。
5.「保存并编写分镜」会先保存已输入的密钥并等待后端确认，避免输入了却没用上。配置、保存和语言切换均不触发付费生成。
6. 实际打开英文界面检查功能项，补齐首页、渠道、密钥管理、设置、主题扩展、可选工具、组装画布、计算变量、阅读与导出、图片与图层编辑、七页教程、AI 写作、文字模型设置、市场、GitHub 发布／手工上传／导入及日志页面的文案。动态计数、标题、占位符和可访问名称一并处理。
7. 保留用户的故事、模板、工作流和渠道名称及对白；图片图层的用户文字显式标记为内容，避免被当作界面标签翻译。中英切换可逆。
8. 修正旧密码占位符覆盖直填提示的问题；文字模型设置的凭据说明改为实际本地后端管理策略，不再错误声称“默认仅本次会话”。
