## 安全与数据约定

- 浏览器能力令牌用于阻止跨站调用，**不是所有网络客户端的身份认证**。无浏览器来源头的本地 CLI 仍兼容；`/api/v1` 维持原有 bearer 机制。默认回环绑定，不应直接公开到互联网。
- 沙箱模板不再能用 null origin 读取私有配置或控制生产。若后续需要模板能力，应设计逐项授权桥接，而不是恢复 null origin 信任。
- 不自动重发不确定的付费请求，不把超时当成“上游一定未执行”。关闭等待超时不保证供应商取消或退款。
- HTTP 不自动迁移旧浏览器工程；需要旧工程时应先显式导出再导入，避免悄悄覆盖文件库。
- 核对清单可包含上游任务 ID 与错误摘要，分享前仍需检查。空列表导出也是有效 JSON。
- pageSummaries 不是分页 API。每次仍读取任务 manifest、序列化列表并计算 ETag；任务量特别大时仍可进一步分页/版本索引化。

## 获取与启动

使用随交付提供的源码 ZIP；校验同名 `.sha256`，解压后：

```bash
python -m pip install -r packaging/requirements.txt
python tools/check_distribution.py
python server.py
```

按终端给出的本地地址打开。不要把 `index.html` 当作可双击运行的完整应用。升级已有安装前先停服务并备份整个私有数据目录；不要用分发 `data/` 覆盖个人数据，可用 `MIO_DATA_DIR` 指向备份后的独立工作目录。修改只在本地分支和交付包中，没有远程推送。
