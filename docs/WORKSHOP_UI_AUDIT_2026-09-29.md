# 创作工坊新旧 UI 衔接 · 2026-09-29

## 背景与方法

9/26 的重构把旧界面搬进 `legacy/`（只读参考），9/27 又在新栈上复刻了旧界面。复刻遗漏了旧工坊的一批交互；本轮以 `legacy/js/assembly-workshop.js`、`ui-editors.js`、`settings-workbench.js` 为对照清单，逐项补回，实现上优先遵循旧版行为，同时保留新后端与既有能力（选择模型、`ContextMenu`、Radix 弹窗、`PromptSurface`）。

- 对照方式：新旧两套站点并排运行（新栈 Vite + 独立数据目录的后端；旧版 `legacy` 服务器 + 隔离数据），Edge 无头浏览器逐个流程比对，再用 vitest 冒烟 / 单元测试固化。
- 数据边界：全部在临时数据目录里进行，没有触碰 `server/data/runtime/v3` 与 `data/`；没有调用真实出图或付费模型。
- 明确不补回的旧功能（见 `docs/WEB_UX_PLAN.md` / 架构说明）：文件库、市场、可执行变量、用户脚本、离线练习，以及按预设绑定节点。

## 已知边界与后续

- 开发模式 React StrictMode 会让 `/api/ws/jobs` 在控制台报一次「WebSocket is closed before the connection is established」：这是 StrictMode 的双重挂载所致，生产构建不会出现，功能不受影响。
- 画册集之外的页面仍没有手工排序；旧版的「选择并导出…」多选导出对话框未复刻（头部「导出」按钮与菜单里的「导出此分镜 / 预设」覆盖单个资产的导出）。
- `ROADMAP` 中记录的「字段旁术语提示」仍待做。
- 队列尚未复刻：工坊并发数输入、卡片拖动排序与分页、动态标题；卡片元信息里的通道名与覆盖项摘要；限流提示、取消报告与存储空间横幅；单个任务的「停止」按钮。
