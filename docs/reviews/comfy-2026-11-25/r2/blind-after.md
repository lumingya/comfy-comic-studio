## 方法与交付

复制原 `probe.py` 后只调整代码与输入 / 输出路径：代码来自当前 `server`，输入仍读取原 R2 的预期与原件，所有 after 输出均写到本次新目录。`replay_fixed138.py` 从原结果中读取固定 138 次请求定义；`check_manual_boundaries.py` 补充验证剩余人工边界的实际行为；`finalize_after.py` 校验 15 样本、真值、原目录完整性及测试期间产品哈希，并生成脱敏结果。

执行命令均为 `python -B`，避免在原目录或产品目录生成字节码：

```text
python -B prepare.py
python -B probe.py
python -B replay_fixed138.py
python -B check_manual_boundaries.py
python -B finalize_after.py
```

最终源码刷新及整轮重跑由 `python -B run_final_retest.py` 顺序执行，任何子步骤失败都会立即停止；`final-source-run.json` 记录开始、结束时间及最终指纹，该元数据也写入脱敏 after JSON。

主要交付为 `report.md` 与 `sanitized-results.json`。后者包含每份样本的原 SHA / 拓扑指纹 / 类名 / 原真值 / 修复后映射、31 项原差异逐项分类、固定 138 次请求逐条结果、15 次边界检查、关闭缺陷与所有统计。仅私人证据文件含临时文件位置；脱敏交付不含原图、作者提示词、模型名、图片、本机路径或凭据。
