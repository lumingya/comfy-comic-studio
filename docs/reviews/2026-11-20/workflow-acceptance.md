## 范围与独立性

本轮仅新增 `server/tests/test_slot_topology_matrix.py` 与 `server/tests/test_slot_lifecycle.py`，生产修复由主 Agent 负责。断言通过真实 FastAPI 路由导入、查询并编译，不调用真实 ComfyUI、付费渠道或个人数据目录。原图不变性通过重新读取持久化工作流比对验证。

## 覆盖

- 14 种拓扑：标准链、双链、MODEL/CLIP 扇出、编号堆栈、双位置堆栈、对象数组、包装对象、内嵌加载器、标签语法、嵌套节点 ID 与中英标题、Switch 活跃分支、多输出、链与堆栈混用、自定义 JSON 编码扩展。
- 五种核心形态与自定义扩展的关闭、原权重/CLIP 恢复、稳定键、结构化控制面、原图零污染。
- 同名两颗 LoRA 与额外追加同时存在；独立关闭其中一颗；原生关闭对象/堆栈仍可发现、无损开启；Mute/Bypass 与死分支不错误宣称可控。
- 默认→任务→逐幕三级优先级、冻结后修改源工作流、任务克隆、单幕重跑。
- 套装导入/导出 ID 重映射、套装新建任务独立覆写与源套装不变性。
- 关闭/重建真实 AppContext 后的 SQLite 重读；默认无凭据备份、暂存恢复、再次重启安装恢复；槽位快照与云端普通选项保真。
- 云端任务克隆、套装跨渠道显式绑定保留普通选项，并断言凭据不进入可移植快照。

## 首跑发现（已修复并复验）

1. **P1：套装逐幕工作流限定符未重映射。** `_remap` 只替换工作流和阶段 ID，没有替换 `panel.overrides.slot_overrides.workflow_id`。导入后逐幕开关静默失效，第二幕得到任务级 0.6/0.1 而不是逐幕 0.9/0.4。独立测试复现两条失败。
2. **P2：已选 Switch 分支没有无元数据识别为可用 MODEL 路径。** `Graph.active` 的一跳字段判断把 `on_true` 消费边当作非模型边，虽布尔选择为活跃分支，控制面仍不允许独立开关。14 拓扑中的该例失败。
3. **P1：默认备份未剥离 `ImageChannel.extra_options` 嵌套凭据。** 只清理渠道的 `api_key`/URL，最终扫描因 `accounts[].token` 而拒绝整个工作区备份。
4. **P2：云端普通请求配方在套装导出时丢失。** `series.generation=None` 后没有携带普通云端选项，再装配使用目标渠道当前参数。新增跨渠道绑定的保真断言。
5. **P2：默认追加 LoRA 缺少结构化独立控制。** `describe` 仅遍历 pinned，没有合入 `WorkflowConfig.slot_overrides.loras`；默认追加关闭项不可发现、没有可用于组覆写的稳定键。新增从 API 查询并按键开启的断言。

额外观察：云端任务若保留未使用的本地逐幕工作流限定符，曾出现导出套装没有附带该工作流而导入校验拒绝该导出物的问题。主 Agent 已把逐幕限定符引用的工作流加入导出集合；新增 `test_cloud_kit_includes_workflow_referenced_only_by_a_panel_override` 证明档案可导入且限定符被正确重映射。云端选项保真测试另用没有无关本地覆写的独立分镜，单独验证普通选项及模型保真。
