# Mio 官网 · 视觉与交互方向

2026-11-21。交付对象是独立静态官网 `site/`，不是 `web/` 创作软件界面。页面编码前由三个独立侦察角色完成真实网站调研、互动观察及产品源码核对。

## 1. 真实参考与证据边界

| 参考 | 实际观察 | 吸收的原则 |
| --- | --- | --- |
| [teenage engineering](https://teenage.engineering/) | 官网围绕真实器件、图片、功能注释组织内容 | 让作品而非抽象口号做主角 |

| [Pentagram](https://www.pentagram.com/) | 项目、专题、引语与领域分类交错出现 | 刊物式编辑节奏，拒绝同构模块堆叠 |
| [Stripe Press](https://stripe.press/) | 书目编号、Open book / View details / Esc 等明确操作提示 | 书刊身份与明确阅读入口 |
| [Studio Dumbar](https://studiodumbar.com/) | 极简导航、项目优先内容组织 | 给作品更多版面 |
| [The Creative Independent](https://thecreativeindependent.com/) | 采访、指南、Zines 与创作门类组成编辑体系 | 用创作者的语言描述工具 |
| [Readymag](https://readymag.com/) | 互动侦察者在 Chrome 观察到作品拼贴、大 CTA、Hover to try；视觉侦察者的文本请求403 | 能力即演示，不要求访客先读说明 |

补充互动参考：[Figma](https://www.figma.com/) 首屏 Pause / Play 由真实点击和 Space 切换验证；[Spline](https://spline.design/) 案例页真实点击 tab 后 selected 与案例名同步更新。借鉴可暂停与状态反馈，不声称其画布均可现场编辑。

以上不是逐像素复制。视觉侦察者未取得可核验截图，其颜色、尺寸、材质与动效建议是设计推导；互动侦察者实际查看了 Chrome 页面与部分控件，但没有验证参考站手机触控或 reduced-motion。禁止把这些限制写成已亲测通过。

## 2. 拍板：一本正在制作中的独立漫画刊物

- 暖纸 `#F3F0E7`、墨黑 `#20231F`、灰绿 `#687465`，朱红 `#C64B34` 只强调关键动作。浅灰绿是背景，不作低对比正文。
- 中文宋体/英文衬线作刊头，系统无衬线作正文，等宽字体作编号。全部提供本地系统字体降级，不依赖付费字体或第三方字体网络。
- 首屏大字与真实水彩分镜对话；桌面刊头约 88–116px，手机约44–56px，按内容适配。不是固定尺寸验收承诺。
- 最大1320px编辑网格；7/5、4/8、2/10等非对称构图。细线、页码、边注、宽留白提供出版感，画面本身提供纸张材质。
- 暖纸封面 → 墨色画册剧场 → 纸色工作流 → 灰绿本地宣言 → 下载尾章。变化节奏与信息密度，不把每一章装进相同圆角盒子。
- 拒绝紫蓝霓虹、无意义发光卡片、均分三栏图标、假仪表板、无限流光节点和全屏模糊。

## 3. 互动契约

1. 五款精选风格实时改变同一画册的实际版式；主题色、单/双页与页码互相保持一致。手机双页自然降为单页。翻页只在阅读器聚焦时接管左右键。
2. 预设改变角色/服装/情绪等变量值与最终提示词，来源可见。预设切换不伪装成图片即时换人。
3. 同一画面、相同裁切的比较器，明确标注色调处理示意，使用原生 range，并提供点击替代。不能把不同构图当作真实精修效果。
4. 工作流标签高亮真实语义链路，LoRA开关与权重影响演示结果；本机与云端是不同渠道，不暗示云端任意透传本地节点。
5. 滚动不劫持。IntersectionObserver 只更新章节状态；不使用常驻 RAF、自动轮播或背景影片。减少动态效果时取消位移与平滑滚动。
6. 原生按钮、清晰焦点、语义化分组、复制失败反馈；所有拖动都保留键盘和点击操作路径。语言切换保留状态并记住偏好，存储禁用时继续工作。

## 4. 产品事实与素材

核对基线为 `aa06d0a`，当时本地与远端main一致。当前源码 `server/mio_server/album/builtin/` 有7种内置模板，官网精选 Monograph、Nocturne、Folio、Zine、Contact Sheet 五种，不宣传“只有五种”。

- 工作流标题真实标记为 `[mio:prompt]` 等，见 `comfy/bindings.py`；标准 API 格式可映射，特殊协议/浏览器脚本依赖可能需要适配器。导入不等于执行成功。
- 已识别的 LoRA 支持独立设置，但不保证所有第三方节点都能开关。云端可能计费。
- 六个专业扩展默认关闭，审阅并启用；AstrBot 仍在 `clients/astrbot_mio/`，是通用 API v2 的消费者示例。
- 作品本地保存；使用云端会发送提示词与所选参考图。不作“数据绝不离机”承诺。
- RTX4060 Laptop 8GB只是参考，不作硬件性能保证。动态漫目前是离线 HTML，不宣称原生MP4。
- 下载指向 Releases 列表，不编造最新正式版资产。发布包需Python3.11+、首次联网安装依赖，无需Node；源码另需Node20+。
- 当前可信更新公钥为空，不宣传已可直接在线一键升级。

## 5. 验收范围

组件交互测试、TS strict、格式、生产构建与根/项目子路径资源检查；本机已有Chrome（不安装浏览器）在1440×900、1280×800、768×1024、390×844及中英两种语言检查。五位全新上下文审计者分别负责视觉、交互、响应式、性能动效、事实与部署，缺陷交回实现者修复后重新整轮验收。

性能以本地实验结果为证据，不用本机数据假冒真实用户p75。截图属于临时验收材料，不入库；最终保留审计文字记录。预先存在的用户后端修改不纳入官网提交，也不为追求全仓干净而撤销。
