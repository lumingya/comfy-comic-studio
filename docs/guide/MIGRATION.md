# 升级到 Mio 2.0

[教程中心](../README.md) · [独立文件教程](FILE_LIBRARY.md)

2.0 更换了主程序的磁盘结构与保存协议，不保留旧聚合格式的运行时读取。`ComfyComic` / `Mio` 浏览器命名空间不代表旧磁盘格式仍被支持。

1. 关闭旧页面、停止旧服务，备份整个旧项目，包括 `data/`、旧 `images/` 和遗留根数据文件。
2. 将完整新版解压到新文件夹，不覆盖唯一原件。
3. 按[转换工具教程](FILE_LIBRARY_CONVERSION.md)输出到原来不存在的新工作区目录。可先使用 `--dry-run`。
4. 使用环境变量 `MIO_DATA_DIR` 指向新目录，再启动新版。
5. 检查画册、分镜、设定、原图、图层、对白、工作流和队列，再尝试普通编辑与保存。保留旧备份。
6. 启动和导入不会自动生成；已有任务仍须手动继续。未知上游结果不会自动重试。

**不要直接复制旧 `data/` 覆盖新工作区，也不要删除旧原件来解决启动报错。** 缺图、损坏 JSON、重名/重复 ID 会明确停止对应操作。

2.0 内部小版本更新可以保留同一个 v2 `MIO_DATA_DIR`；升级程序与工作区分开放置最方便。

全量停机备份包含 `settings/secrets.json` 明文密钥与 `runtime/execution/` 执行数据库，只能放在可信位置。公开分享请使用界面的单资源 ZIP。
