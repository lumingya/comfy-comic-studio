# 第一本画册：从启动到导出

[教程中心](../README.md) · [English](../en/GUIDE.md)

## 1. 准备环境

安装 Python 3.10 或更新版本。Windows 安装时勾选 Add Python to PATH。解压完整项目，保留 `server.py`、`mio_api.py`、`mio_credentials.py`、`index.html`、`vendor/` 和其他资源的相对位置。运行 `python server.py`，或双击 `start.bat`。

打开 http://127.0.0.1:8777 。默认只在本机访问；端口被占用可设置 `MIO_PORT=8877` 后启动。进入页面后为工作室命名，检查底部后端保存状态。

## 2. 选择图像生产方式

打开「图像引擎」。不要把 LLM 写作服务的连接设置当成图像服务配置。

### NovelAI

1. 选择 NovelAI，默认地址 `https://image.novelai.net`。
2. 默认模型 `nai-diffusion-4-5-full`；确保自己的账户支持这个模型。
3. 在“管理密钥”保存 API Key 并使用。不要粘贴账号密码；已保存密钥刷新后仍可用。
4. 分镜宽高设置为 64 的倍数，例如 768 × 1024；steps 例如 28，cfg 例如 5。
5. 不需要导入工作流。实际费用与分辨率限制由 NovelAI 决定。

### OpenAI 或第三方兼容渠道

1. 选择 OpenAI 兼容；需要多个供应商时点击「复制为新渠道」。
2. 地址填写 API 根路径，例如 `https://api.openai.com/v1`，不要重复追加 `/images/generations`。
3. 模型可手填或点击“获取模型列表”选择。默认模型是 `gpt-image-1`。在“管理密钥”保存凭证；无需鉴权的服务选择“无密钥”。
4. 官方 GPT Image 使用 Images API。第三方 Nano Banana 根据渠道文档选择 Images 或 Chat。
5. 尺寸和质量都是可选开关；不支持的渠道关闭即可，关闭或留空时请求不发送对应字段。[渠道与密钥详解](CHANNELS_AND_KEYS.md)

### ComfyUI

1. 先独立启动 ComfyUI。真实画册由 Python 访问 ComfyUI；填写 Python 所在机器能够访问的地址。浏览器中的工作流检查仍需要恰当的 CORS 配置；常用启动参数是 `--enable-cors-header`，仅在可信网络使用。
2. Mio 中填写 ComfyUI 地址。
3. 导入 **API 格式** JSON，不是节点编辑器 UI 格式 JSON。
4. 确认 checkpoint 是本机真实文件，正负提示词与输出节点绑定正确。
5. 工作流库支持批量导入。不要把默认 checkpoint 占位名当成随包模型。

## 3. 准备分镜和角色设定

进入「创作画册」，选择分镜模板。可以从根目录 `default_comic_template.json` 导入示例。修改画册标题和角色/画面设定。

示例正向提示词：

```text
{character}, wearing {outfit}, standing by a quiet river, soft morning light, {style}
```

给 character、outfit、style 填入实际值。每一幕单独写画面动作和构图，字幕与提示词分开。未定义变量会在预检时提示；不必把普通提示词权重语法改写成变量。

## 4. 先跑一幕

打开队列区域，选择生产渠道与「第 1 幕」范围，加入队列。正常状态下会自动开始；如果之前暂停了，需要手动恢复。

查看结果与日志。首帧失败先检查密钥、模型、尺寸和服务端响应，不要反复点击重试造成重复扣费。

## 5. 整册与阅读

确认首帧设置后选择整册范围生成。新任务创建独立版本；如需补齐已有画册，应使用缺页补齐，不是再次生成整册。

去「画册集」阅读。未完成页面是问号；没有真实输出不会标成成功。可在页内修改提示词精修，参考图/图生图能力取决于服务。

## 6. 导出与备份

画册菜单支持 HTML 导出；多选画册后右键可批量导出。HTML 可用于展示，但不是完整工程备份。

退出前检查保存状态。迁移到另一台电脑时复制整个 `data/`。[备份细则](BACKUP.md)

## 持久任务与素材管理

任务显示“服务端”后，关闭网页也会继续生成。重新打开会恢复结果。暂停/中止不保证撤销上游收费；出现“结果未确认”时先核对，切勿盲目重试。素材索引、完整性检查和安全回收在设置的保存服务区域。[完整基座教程](FOUNDATION.md)。
