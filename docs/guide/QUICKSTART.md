# 第一本画册：从启动到导出

适用于 3.1.0-dev.3。分镜、预设与生成画册独立；不需要维护旧画册所属关系，也不承担旧存档迁移。

[教程中心](../README.md) · [当前发布说明](../RELEASE_CURRENT.md)

## 1. 启动

安装 Python 3.10+，解压完整项目并保留目录结构。在项目根目录运行：

```bash
python -m pip install -r packaging/requirements.txt
python server.py
```

打开 http://127.0.0.1:8777 。Windows 也可双击 `start.bat`；缺少 Pillow 时会给出安装命令。可执行变量需要 Node.js 20+。默认只监听本机，端口可用 `MIO_PORT` 修改，独立数据目录可用 `MIO_DATA_DIR` 指定。

## 2. 配置图像渠道

打开 **工作流与 API 配置**。图像生成与 LLM 写作、可选视觉审校是不同配置入口。

- **ComfyUI**：先启动自己的服务，填写 Python 可以访问的地址；导入 API 格式工作流，绑定提示词、模型与输出节点。随包不含推理模型。
- **NovelAI**：填写真实密钥、模型和可用尺寸，确认账号权限与余额。
- **OpenAI 兼容**：按供应商选择 Images 或 Chat 图像协议，不因模型名称猜测协议。地址填 API 根路径；可搜索模型，也可手填。关闭供应商不支持的可选参数。

先确认接口与费用，再开始生成。[图像渠道](../IMAGE_PROVIDERS.md) · [渠道与密钥](CHANNELS_AND_KEYS.md)

## 3. 保存独立分镜与预设

在 **分镜工坊** 新建或打开分镜，每幕填写名称、正向提示词、可选负向提示词与台词。台词按稳定 ID 关联，拖动重排不会串幕；简介可选。

在 **预设工坊** 定义普通变量，例如人物名、服装、画风与图片。在分镜中明确引用 `{人物名}`、`{画风}`。需要负向变量时也作为普通变量创建，例如 `{人物负向}`，放进分镜的负向提示词中。没有隐式追加的预设专用负向字段。

一个分镜可以配不同预设产出多本画册；生成结果不反向改写源资产。

## 4. 装配并明确启动

进入 **装配与生成**，点击新建任务。向导依次选择分镜与渠道、多份预设、输出名称。也可切换 N:N 画布，拖动节点并拉线组合。

新建只会进入 **待命**，不会执行脚本或调用模型。可以先用单幕分镜或预设试绘确认渠道，再在任务卡点 **开始生成**。选“从此处顺次生成”会冻结当前批次；后续添加的任务不会偷偷混入。

## 5. 阅读、局部重跑与排障

任务卡展示进度与摘要；诊断详情可看脱敏响应和 ComfyUI 上游 ID。单幕或后续幕重跑只影响明确选中的范围，其余已确认结果保留。

暂停阻止后续调度，不代表已发出的云请求退款。ComfyUI 定向取消有回执；旧服务端无法安全确认时会提示核对，不盲目中断共享实例。遇到未确认结果先查上游，不要反复点击付费重跑。

到画册集阅读。图片工作台支持气泡、竖排、独立尾端、原位改字及撤销；未生成的页面不会伪装成成功。

## 6. 导出与备份

- 模板 HTML：保持内联预算，适合独立展示。
- ZIP 原图资源包：独立阅读页和图片目录，无 128 MiB 内联限制；完整解压后打开 `index.html`。
- PDF 图片画册：逐页图片，非 JPEG 会转换；SVG 或缺页请选择 ZIP。

下载由浏览器接管，准备期间不要重复提交。导出不是完整工程备份；停止服务后复制整个数据目录。[备份说明](BACKUP.md) · [本轮限制与验收](../REVIEW_ACCEPTANCE.md)
