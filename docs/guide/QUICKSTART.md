# 快速开始

## 进入工作室

启动 Mio，打开首页。顶部菜单可以新建或切换画册集。

## 连接图像服务

在「工作流与 API 配置」选择渠道：

- **ComfyUI**：填写服务地址，检查连接，导入 API 工作流。
- **NovelAI**：填写服务地址、模型 ID 和 API Key。
- **OpenAI 兼容**：填写基础地址、模型 ID、API Key，选择 Images API 或 Chat Completions。

## 写第一幕

1. 打开「创作工坊 → 分镜」，新建分镜。
2. 填写画面提示词和台词。
3. 在预设中准备角色、服装、场景等变量。
4. 点击「去装配此分镜」，选择渠道与预设，添加任务。
5. 在任务卡点击「开始」。

## 阅读与分享

进入画册集，打开画册。在阅读器里编辑图片、选择展示模板或导出。
