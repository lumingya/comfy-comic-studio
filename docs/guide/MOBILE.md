# 手机访问与触控操作

[教程中心](../README.md) · [English](../en/MOBILE.md) · [安全说明](../../SECURITY.md)

## 手机界面

不需要安装手机 App，用浏览器访问运行中的 Mio 服务即可。电脑仍负责文件存储与服务端图像任务；手机是同一个工作区的操作界面。

- **底部导航**：画册集、创作、图像引擎、设置和已启用的功能。主内容不再被侧栏挤窄；安全区域为系统手势条留出空间。
- **创作页**：标题、画册选择和操作按钮分行，分镜条可左右滑动，表单采用单列。输入框与提示词编辑区使用更适合手机的字号。
- **模型选择**：获取列表后直接在模型 ID 框输入关键词，候选自动浮现。点一下模型就替换同一输入框并保存；列表可滚动，滑动不会作为点选处理。
- **任务队列**：用上移、下移按钮排序，不必依赖拖拽。执行中任务仍受原有保护，不能任意移动或删除。
- **画册管理**：点击画册上的“更多”按钮打开菜单，可导出、编辑、星标、删除或前后移动。多选模式下点击复选框；不是必须使用右键或键盘。
- **阅读与导出**：默认完整显示图片，不为适配手机裁切。顶部“版式”打开可滚动的模板与导出面板；HTML 下载位置由浏览器管理。
- **助手**：触控设备的回车是换行，点击“发送”才提交。可视区域变化不会重新渲染并清空正在编辑的草稿。

常用按钮采用约 44px 触控高度。窄屏、横屏、弹窗、模型列表与助手使用可视窗口尺寸调整，减少键盘遮挡。系统键盘和浏览器工具栏的行为仍可能因设备而异。

## 同一 Wi-Fi 下连接电脑

默认只监听电脑本机，手机打不开 `127.0.0.1` 是正常的：手机上的这个地址指向手机自己。**不要为了手机访问而把私有工作区直接暴露到公网。**

以下方式只适合你信任的家庭/个人局域网。该网段上可访问此端口的人可能操作你的工作区；公共 API Token **不会保护整个网页及私有接口**。远程使用应通过有认证的 HTTPS 反向代理或受控安全隧道。

1. 电脑、手机连接同一受信任网络，关闭会隔离两台设备的访客网络设置。
2. 查电脑局域网 IP，例如 `192.168.1.23`；以下示例中的 IP 必须换成你的实际地址。
3. 停止已运行的 Mio，在项目目录的终端设置监听地址与允许来源，然后启动。

Windows **命令提示符（cmd）**：

```bat
set MIO_HOST=0.0.0.0
set MIO_PORT=8777
set MIO_ORIGINS=http://192.168.1.23:8777
start.bat
```

macOS / Linux：

```sh
MIO_HOST=0.0.0.0 MIO_PORT=8777 MIO_ORIGINS=http://192.168.1.23:8777 python3 server.py
```

4. 仅在需要时允许电脑防火墙的**专用网络**访问 8777 端口，不配置路由器公网端口转发。
5. 手机打开 `http://192.168.1.23:8777/`。若改了端口，启动参数、允许来源和访问地址必须一起改。

`MIO_ORIGINS` 必须是完整来源（协议、IP、端口，不带路径或末尾斜杠）。IP 改变后需修改环境变量并重启；遗漏可能导致页面能打开，但保存或上传返回 403。

**设置 → 服务与保存**中的 Mio/Python 后端基础地址通常留空，使用当前网页同源地址。如果曾手动填入 `127.0.0.1`，请核对并改为同源配置或手机可访问的电脑地址。不要把它与图像供应商的 Base URL 混淆：服务端图像任务访问的 `127.0.0.1` 指运行 Python 的电脑；仍由浏览器直接请求的旧接口/连接检查则从手机发起。

默认本机监听没有被本次更新自动放开。用完局域网访问后，可以在新终端按默认方式启动，恢复本机监听。

## 上传、保存与安全操作

- 图片变量支持 PNG、JPEG、WebP，并保存到电脑的 `data/`。HEIC 等不支持格式请先转成 JPEG/PNG；系统相册权限与文件选择器由手机控制。
- 不依赖浏览器“选择目录”能力：移动浏览器可使用普通图片上传及 JSON/ZIP/HTML 下载。文件下载、分享和解压的界面随浏览器不同。
- 手机和电脑共享同一工作区。避免同时编辑同一份数据；遇到版本冲突时，先保留未保存内容，再重新读取，不强行覆盖。
- 手机关页后，**服务端已接收并开始执行的图像任务**继续运行，前提是电脑与 Python 服务未停止或休眠。尚未提交的编辑或浏览器内对话不因此变成后台任务。
- 更新前停止服务、备份并保留 `data/`。覆盖程序文件后，手机刷新或重新打开页面；不要为了更新界面删除工作数据。

## 验证范围

自动化测试使用 Chromium、WebKit 的触控/手机模拟，覆盖 320、390、430px 竖屏和 844×390 横屏，以及缩短可视窗口。测试包含导航、模型触控回填、草稿旋转保持、图片上传、任务排序与删除确认、画册管理、完整图片阅读、HTML 下载和助手输入。

**模拟测试不等于 iPhone/Android 真机验收**，不模拟真实系统软键盘、相册权限、刘海硬件或厂商浏览器差异；没有借此进行真实云端付费生成。完整记录见 [测试结果](../TEST_RESULTS.txt)。

桌面新增鼠标路径滑选不会拦截手机滚动；手机仍通过复选框多选。队列删除现会明确删除关联画册，需确认；新的失败策略位于队列页，详见 [队列与画册管理](../QUEUE_AND_COLLECTION_UPDATE.md)。
