# 分镜、变量与执行队列

[教程中心](../README.md)

## 创作对象

- **分镜模板**：一组可复用画面，包括名称、提示词、负向提示词、字幕和可选参数。
- **角色/设定预设**：独立于模板的变量值与参考图。
- **画册计划**：选择模板与设定，并保存本册的局部修改。
- **画册**：已经进入生产的具体版本，有原始分镜与执行来源快照。

因此，修改共享模板不等于修改已经排队的每本画册。

## 设置优先级

通常按「全册设定 → 本幕设定预设 → 本幕自定义属性」合并。使用界面预览确认最终展开的提示词。新建空白预设不会要求先清空现有预设。

ComfyUI 可为整册和单幕分别选工作流；NovelAI/OpenAI 不需要工作流，相关选择不可用。API 渠道的模型和 OpenAI 输出尺寸由渠道配置控制。

## 队列规则

1. 从上到下 FIFO 执行；只有待执行任务可以拖动排序和删除。
2. 入队时冻结渠道、模型、变量与参数。改渠道设置不会追溯修改旧任务。
3. 暂停后再追加任务不会偷偷恢复生成；正在执行的帧可能先结束。
4. 任务删除不删除画册和已生成图片；当前执行项需先停止。
5. 更换 API 任务的渠道，应删除待执行任务再重新入队，不能用工作流下拉框覆盖。
6. 页面重新加载不自动向 GPU/付费服务提交遗留任务。

## 图片输入和精修

优先使用精修源图，其次角色正面参考图。ComfyUI 需要图像输入映射；NovelAI 使用 img2img；OpenAI Images 使用 edits；Chat 使用 image_url。

没有把源图默默丢弃再文生图的降级逻辑。不支持该操作的服务会失败。局部蒙版和模型专有控制参数不保证跨渠道可用。

## 缺页与错误

显示问号表示没有可用图片。可以查找缺失分镜并补齐。原图读取失败时导出也可能失败，避免将假图误认为作品。默认示范画册封面是明确的例外。

## 外部 API 与界面队列

公共 API 的单图生成不写浏览器队列，也不自动创建画册。返回的素材保存于本地，可由外部程序使用；整册任务编排仍由界面负责。外部任务和界面任务可能同时占用供应商额度，使用者需要自行协调预算。
