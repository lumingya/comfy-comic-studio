# ComfyUI 工作流

## 导入

在 ComfyUI 中导出 API 格式 JSON。在 Mio 的渠道配置页点击「导入 API 工作流」。

## 映射

选择工作流后，设置正向提示词、负向提示词、图片输入与输出节点。节点 ID 和输入字段取自工作流。

LoRA 名称通常对应 `lora_name`，权重对应 `strength_model` 和 `strength_clip`。

## 使用

装配任务时选择工作流，搭配分镜和预设。运行结果显示在任务卡与画册中。
