# 图像服务与密钥

**图像服务** 是实际出图的服务。Mio 支持三种：ComfyUI、NovelAI 和 OpenAI 兼容接口。Mio 自己不出图，它把每一幕的提示词和参数发给你选定的图像服务，再把图片取回来。

所有图像服务都在侧栏 **「工作流与 API 配置」**（快捷键 Alt 3）里添加和切换。顶栏右侧始终显示 **当前** 图像服务和它的真实状态，点它可以直接打开设置。

## 先选哪一种

| | ComfyUI | NovelAI | OpenAI 兼容 |
|---|---|---|---|
| 在哪里运行 | 你自己的电脑或局域网，需要显卡 | NovelAI 云端 | 服务商云端，或本机兼容服务 |
| 费用 | 不产生费用，只占用显卡 | 按账户点数（Anlas）扣费 | 按服务商计费 |
| 需要密钥 | 不需要 | 需要 | 官方地址需要；本机 / 局域网服务可以不填 |
| 可控程度 | 最高：工作流、模型、LoRA 都自己定 | 中：模型和采样器可选 | 低：主要靠提示词 |
| 宽高、步数、CFG、种子 | 映射到工作流后生效 | 直接生效（宽高需为 64 的倍数） | 步数、CFG、种子不会发送 |

费用只在你点 **「开始生成」** 并确认之后才会发生。添加服务、装配任务、打开页面都不会请求图像服务。

## ComfyUI

### 1. 启动 ComfyUI

按 ComfyUI 自己的说明启动。默认地址是 `http://127.0.0.1:8188`，浏览器能打开这个地址就说明它在运行。

- 连接检查和生成请求都由 Mio 的后端发出，所以 ComfyUI **不需要** 加 `--enable-cors-header`。
- ComfyUI 在另一台电脑上时，要让它监听局域网地址（ComfyUI 的 `--listen` 参数），并确认运行 Mio 的电脑能访问那个地址和端口。

### 2. 填地址并检查连接

1. 在「工作流与 API 配置」里选择 ComfyUI。
2. 地址填 `http://127.0.0.1:8188`，或 ComfyUI 所在机器的地址，例如 `http://192.168.1.20:8188`。
3. 点 **「检查连接」**。这只读取服务状态，不会生成图片。

**预期结果**：显示“ComfyUI · 已连接”，以及服务端返回的延迟和显存信息。

地址改过之后要重新检查。连不上时的常见原因：

- ComfyUI 没启动；
- 端口不是 8188；
- 地址误写成了 `https`。

详见 [常见问题](TROUBLESHOOTING.md#mio-conn-001-连接被拒绝)。

### 3. 准备工作流和模型

ComfyUI 需要一份 **API 格式** 的工作流，Mio 按参数映射把提示词和种子写进去。Mio 自带「Anime · 基础图像管线」，但其中的模型名 `your-anime-model` 只是占位名，要换成你装好的模型。

完整步骤见 [ComfyUI 工作流](WORKFLOW.md)。

> 没有显卡、只想先走一遍流程？首页的 **「先用离线练习体验」** 用本地示意图生成一本三幕画册，不请求任何图像服务。见 [快速开始](QUICKSTART.md#路线-a-离线练习30-秒)。

## NovelAI

1. 在「工作流与 API 配置」里点 **「新增图像服务」**，类型选 NovelAI。
2. 默认值已经填好：
   - 地址：`https://image.novelai.net`
   - 模型：`nai-diffusion-4-5-full`
   - 采样器：`k_euler_ancestral`

   一般不用改。
3. 点 **「添加密钥」**，粘贴 NovelAI 的 **API Token**（在 NovelAI 网站的账户设置里生成）。注意它不是登录密码。
4. 点 **「保存并使用」**。

**预期结果**：顶栏显示“NovelAI · 就绪”。没保存密钥时显示“待配置”，开箱检查和装配向导也会提示“还差一步：填写密钥”。

**NovelAI 的特殊规则**：

- 宽、高、步数、CFG 和种子在生成时直接生效；宽高必须是 64 的倍数。
- 提示词里没有任何预设定义的花括号（比如 `{{masterpiece}}`）会被当作 NovelAI 的权重语法，原样保留。台词里的变量仍然必须定义。
- 每次生成都会扣账户点数，余额不足时任务会停下并提示“余额或额度不足”。

## OpenAI 兼容

适用于 OpenAI 官方接口，以及兼容它的第三方或本机服务。

1. 点 **「新增图像服务」**，类型选“OpenAI 兼容”。
2. 填 **基础地址**：一般写到 `/v1` 为止，例如 `https://api.openai.com/v1`，或 `http://127.0.0.1:1234/v1`。
3. 点 **「添加密钥」** 保存 API Key。
4. 在 **「模型 ID」** 旁点 **「获取模型」** 选择模型，也可以直接输入。能获取到模型列表，基本说明地址和密钥都是对的。
5. 选 **接口协议**：
   - **Images API**：GPT Image 和兼容 `/images/generations` 的服务；
   - **Chat Completions**：通过对话接口返回图片的服务。模型需要支持图片输出（modalities 包含 image）。
6. 表单下方的「请求参数」可以设置尺寸、质量等。

**需要知道的限制**：

- 尺寸和质量由图像服务设置决定。Chat 协议会把宽高比写进提示词。
- 分幕里的步数、CFG、种子 **不会** 发送。

**关于密钥**：

- 官方地址 `api.openai.com` 没有密钥时，会被列为待填写项。
- 其他公网地址只提示“多数公网服务需要密钥”。
- 本机或局域网服务可以留空，选 **“无密钥”**，这时 Mio 不发送 Authorization 头。

## 密钥怎么保存

- 密钥保存在工作区的 `settings/secrets.json` 里。保存后输入框会清空，原文不再回到浏览器。
- 每个图像服务可以保存多条密钥（比如“主账号 / 备用账号”），用 **「管理密钥」** 切换或删除。
- 密钥和“图像服务 + 基础地址”绑定。改了地址要重新选择或保存密钥；**复制** 图像服务时不复制密钥。
- 导出分镜、预设、画册和完整备份时 **都不包含密钥**。换电脑后需要重新填写。
- 本地密钥文件不是加密保险库。请只在自己信任的电脑上使用 Mio，不要把 `settings/secrets.json` 发给别人。

## 管理多个图像服务

| 操作 | 做法 |
|---|---|
| 新增 | 点「新增图像服务」 |
| 复制 | 点「复制」，快速做一个参数不同的版本（不复制密钥） |
| 删除 | 点「删除图像服务」，同时删除它的密钥 |
| 切换 | 用顶部下拉框。装配向导默认用最近一次成功的图像服务；当前服务没配好时，向导会提示并提供「改用已就绪的服务」 |

## 生成时的可靠性规则

- **请求没发出去**（连不上、找不到服务器、证书错误）算失败，可以放心重试，不会重复计费。
- **请求已发出、但没拿到结果**，任务标为 **结果未确认**，Mio 不会自动重发，以免重复计费。请先到服务端核对，见 [生成任务](FOUNDATION.md)。
- 服务明确要求限流（HTTP 429）时，Mio 会按服务端要求等待后重试。
