# 图像渠道

## ComfyUI

1. 启动 ComfyUI。
2. 填写服务地址，点击「检查连接」。
3. 导入从 ComfyUI 导出的 API 格式 JSON。
4. 选择工作流，设置提示词映射和输出节点。

## NovelAI

填写渠道名称、服务地址、模型 ID、API Key 和采样器。

## OpenAI 兼容

填写渠道名称、API 基础地址、模型 ID 和 API Key。点击模型输入框旁的「获取模型」选择模型，也可直接输入。

接口协议可选择 Images API 或 Chat Completions。输出尺寸、质量和 JSON 参数位于表单下方。

## 渠道管理

顶部可以新增、复制和删除渠道；下拉框用于切换。
