# 生成任务

## 装配

在创作工坊进入「生成任务」，点击「新建生成任务」。选择渠道、分镜和预设，为任务命名后加入队列。

向导适合逐步配置；画布适合连接多份分镜与预设。

## 运行

- **开始**：运行所选任务。
- **顺次生成**：按队列顺序运行。
- **暂停／继续**：控制当前任务。
- **单幕重跑**：重新生成指定页面。
- **恢复结果**：重新读取已生成的结果。

## 检查结果

展开任务卡查看分幕进度。错误详情和请求记录在诊断入口；「结果未确认」的任务可按任务 ID 核对上游记录。
