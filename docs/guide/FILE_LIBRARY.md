# 文件与保存

## 工作室目录

默认目录为 `data/`，也可通过 `MIO_DATA_DIR` 指定。

- `albums/`：画册信息、原图及编辑结果。
- `storyboards/`：分镜。
- `presets/`：创作预设。
- `workflows/`：ComfyUI 工作流。
- `layouts/`：阅读展示模板。
- `settings/`：工作室设置。
- `.trash/`：回收站。删除的内容先放在这里，可以在「设置 → 数据与备份 → 回收站」恢复，见 [回收站](BACKUP.md#回收站)。

## 日常保存

编辑内容后自动保存。底部状态栏显示保存结果；保存失败时可重试或重新读取。

## 手工整理

先停止服务，再复制或调整目录中的文件。完成后启动服务并重新读取。
