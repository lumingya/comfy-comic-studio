# 画册展示与本地图片编辑

适用于 Mio 本地改进版 1.1.0 及以上；1.1.1 默认采用连续卷轴阅读。这里的编辑完全在浏览器和本地 Python 服务之间完成，**不调用图像生成渠道**。

## 先看画册，再处理图片

在画册首页选择「紧凑网格」，每本书使用一致的方形封面和图片数量角标。横图、竖图不会再把网格撑成不同高度。进入画册后始终显示完整图片，不沿用封面的裁剪。

- **完整画面**：按可见空间缩放，不放大超过图片原始像素尺寸；小图居中留白，不被强行拉糊。
- **连续卷轴**：统一阅读容器、间距和背景，图片保留各自比例，小图保留自然尺寸。使用阅读器顶部「版式」→「本次展示与导出设置」→「阅读方式」切换。
- **双页阅读**：一组中遇到横幅图时改为上下完整画面，避免把横图挤入狭窄的竖页。仍按原分镜顺序、每组两幕翻阅。
- 自定义展示模板继续使用它自己的 HTML/CSS，不强制改写用户设计。默认「留白 · 完整画面」离线导出也限制小图放大。

## 打开编辑器

翻到需要处理的一幕，点击右上角 **编辑图片**。本幕文字面板中也有入口。旧「图片替换」入口现在打开同一个编辑器。

1. **裁剪和变换**：选择比例，或输入左/上/宽/高百分比；旋转 90°、水平翻转、垂直翻转。
2. **颜色**：亮度、对比度、饱和度。对比底图按钮暂时隐藏调色及图层，构图变换仍保留。
3. **气泡与文字**：圆角对白、椭圆、思考、喊话、旁白；可改文字、字号、文字/填充/边框颜色，以及尾巴方向。
4. **图层**：在画面上拖动移动；选中后拖右下角调整大小。可精确输入坐标、调整上下层、复制或删除。文字自动换行；较长文字应调整字号或图层范围，超出范围的部分不显示。
5. **撤销/重做**：保留本次会话最近 30 个状态，包含本地替换和图层变化。快捷键 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z；输入框中保持原生文字撤销。
6. **保存图片**：将源图、编辑参数和图层单独保存，同时生成用于阅读和导出的 PNG。再次打开可继续编辑，不是在上一次合成图上反复叠加。

关闭未保存草稿会询问是否放弃。**会话撤销历史不跨关闭/刷新保存；已点击保存的图层会保留。** 不应把未保存草稿当作自动备份。

## 本地替换、单图删除与恢复

- **替换为本地图片**：PNG、JPEG、WebP。替换后先预览，再保存；新底图会重置当前构图和图层，以免把旧图层意外套在不同尺寸的新图上。本次会话可撤销替换。
- **删除这张图片**：只移除这一幕的显示图片，保留分镜文字、其他图片及恢复所需记录。一次确认，不调用生成服务，不自动把它作为缺图补齐。
- **恢复初始原图**：恢复首次编辑或替换前的图片，不是恢复上一次合成结果；当前替换和图层不再显示。已删除的图片会显示明确占位，可从「替换 / 恢复图片」进入。
- 原先已经提交或正在执行的生成任务不会因为本地图片编辑而保证取消或退款，但其迟到结果不能覆盖编辑/删除记录。图片删除与画册「停止并删除」是不同操作。

## 与实验室精修配合

对已编辑的页面继续使用实验室 AI 精修时，以当前合成画面作为输入；确认的精修结果通过同一页版本保护保存为新的底图，不会被旧编辑记录悄悄回滚。原图仍保留，但精修前的气泡/文字已在输入中合成，不能再当作原来的独立图层修改。若生成期间发生冲突，保留当前图，不自动重发；结果素材地址会随错误提示保留。

## 设置封面

在编辑器右侧展开 **封面缩略图**，选择「填满方形」或「完整画面留白」，设置水平/垂直焦点，点击 **使用本幕作为封面**。

这是独立的书架设置，不裁剪原图，不改变阅读和导出画面。新图片编辑仍须另点「保存图片」。当前选中封面无图时，自动回退到其他有效图片。精选展示视图保留完整封面，不强制裁剪。

## 导入自己的素材

点击「导入素材包」，支持单个 PNG、安全 SVG，或如下 JSON：

```json
{
  "schema": "mio.image-assets.v1",
  "items": [
    {
      "title": "圆形标记",
      "svg": "<svg xmlns=\"http://www.w3.org/2000/svg\" width=\"200\" height=\"200\"><circle cx=\"100\" cy=\"100\" r=\"85\" fill=\"#fff4d5\" stroke=\"#334433\" stroke-width=\"4\"/></svg>"
    }
  ]
}
```

也可把 `svg` 换成 `dataUrl: "data:image/png;base64,..."`。素材不依赖网络地址。

随完整项目附带 **`examples/image-assets/starter.json`**，包括手绘对白底框、强调标记、章节旁白底板。导入后点缩略图即可添加。

**安全边界：** SVG 使用元素/属性白名单，拒绝 script、事件属性、外部资源、嵌入 HTML、样式脚本和实体声明。允许简单路径、基础图形、文字、分组和安全本地渐变引用；复杂 SVG 不保证兼容，被拒绝时请在绘图软件中另存为 PNG。SVG 在导入时转为本地 PNG，不执行素材包代码。

导入的对白框是贴纸底板；需要可编辑文字时，在它上方另加文字图层。不会把第三方 SVG 路径自动转换为内置气泡的控制点。当前不支持 JavaScript 扩展插件或字体安装包。

### 实际限制

- 本地图像编辑：最多 **3200 万像素**，长边最多 **8192 px**；不会静默缩小超限原图。
- 上传源图、输出 PNG：单文件最多 **50 MiB**。如果完整输出超过限制，会明确报错，保留草稿。
- 编辑预览长边最多 1400 px；**保存使用裁剪后的原始像素尺寸，不使用预览尺寸**。
- 素材文件/JSON 包：7 MiB；每包 40 项、素材库 80 项；每张图片最多 40 个图层；单图层文字最多 2000 字。
- PNG 合成保留透明背景，不保留 EXIF 等原始文件元数据。原始源文件作为独立素材保留。
- 动画 GIF 不作为本地替换格式；既有 GIF 若可读取，仅按浏览器当前帧参与静态 PNG 编辑，不保留动画。

## 刷新、冲突与备份

图片编辑以 `data/runtime/execution/jobs.sqlite3` 的 `picture_edits` 为权威记录，有独立页版本和变化游标。工作区旧 JSON 回写、任务同步和重启不能让已删除图片复活。

另一标签页修改同一张图片后，旧编辑器保存返回冲突，不覆盖较新的版本，当前草稿仍留在编辑器中。图片操作不会自动重试。网络断开时服务可能已经提交了图片，请先重新读取核对；不要把网络报错理解为一定未保存。原有工作区配置冲突保护仍生效。

升级或迁移最可靠的方法是关闭服务后备份 **完整 `data/`**，特别是 `execution/jobs.sqlite3` 和所有图片。只复制几个 JSON 会丢失持久页版本及删除标记。工程目录导出会收集本地编辑素材；HTML 导出只包含最终阅读画面，不是可编辑图层工程。
