# 第一阶段：工作流模块修改说明

> 后续的紧凑队列、自动执行、右键批量管理及真实默认值，以 [队列与画册管理更新](QUEUE_AND_COLLECTION_UPDATE.md) 为准。本文保留第一阶段设计记录。

## 1. 工作流独立模块

左侧导航现在包含独立的 **工作流配置**，不再把它作为设置子页。已有“打开节点映射”等入口重定向到此模块。

- 左侧工作流库 + 快捷下拉切换，右侧保留原有完整节点浏览与映射编辑器。
- 支持一次选择多个 JSON 文件、JSON 数组及 `workflows` 工作流包。
- 单个坏文件不会阻断其他有效导入，导入结果按文件报告错误。
- 原始 API 工作流中未知节点与连线保持不变。
- 不同工作流分别保存名称、节点、映射、输出节点和种子选项。
- 可复制、删除和导出全部。计划/分镜仍引用的工作流不能直接删除；历史任务已有快照，不依赖工作流库条目继续存在。
- 只支持 ComfyUI **API 格式**，编辑器格式会提示重新导出，不做猜测式转换。

## 2. 默认布局

- 运行日志在主导航最后，仍受原来的显示开关控制。
- 扩展功能入口默认关闭，可在“设置 → 功能开关”启用，不删除相关数据。
- 新工作室默认精选展示；保留用户明确保存过的网格偏好。
- 修复桌面缩小到手机宽度时，侧栏未收缩引发工作流页横向溢出的问题。

## 3. 预设与分镜

“角色与画面设定”新增 **新建空白预设**：从空白字段开始，不必删改旧预设。创建后填写内容，点击 **更新当前预设** 即可保存；原有“另存为预设”仍保留。

分镜中，提示词预览之前新增：

- 本幕设定预设（默认继承全册）；
- 本幕工作流（默认继承全册）；
- 仅此幕加入队列；
- 调整此工作流入口。

设定优先级为：

```text
全册引用预设 → 本册属性覆盖 → 本幕选择预设 → 本幕自定义属性
```

预览和实际生成使用同一套设定解析逻辑。分镜选择只影响当前画册计划，不改动共享模板或其他画册。

## 4. 队列中灵活切换

生成队列新增轻量任务配置区：全册默认工作流、生成范围（整本/某一幕）、加入队列、加入并开始。

每个活动任务有折叠的 **查看 / 调整待执行工作流**：

- 已完成、已经开始的那一幕不能改工作流；
- 尚未开始的分镜可以在队列里直接更换；
- 更换后验证节点映射，更新该任务的独立快照，其他任务不变；
- 修改工作流库不追溯影响已入队快照；
- 同时冻结工作流、变量、连接地址、模式与回退选项；
- 中断补齐、单页精修优先使用原分镜的工作流快照。

### 你的 A / B 场景

1. 为各幕选好默认工作流，把整本画册加入队列并开始。
2. A 幕开始后，在队列展开任务详情，将尚未开始的 B 幕改为另一份已导入工作流。
3. A 保持原快照执行，B 使用调整后的快照，不必往返配置页面。

也可在生成过程中继续添加其他分镜任务。**新加入生成范围会创建独立画册版本**，不会静默覆盖已有图像；单幕任务完成时，画册显示待补齐而非错误地标记整本完成。若希望 A、B 保持同一本画册，请使用上面的“整本任务 + 待执行分镜调整”。

## 5. 修复与数据结构

- 全新后端空对象与前端必填字段不匹配，造成首次无法确认保存：改为完整字段和明确的空工作室标志。
- 导入新工作流沿用上一个工作流的映射：改为独立初始化/导入映射。
- 分镜执行及精修覆盖了单幕快照：优先读取单幕快照。
- 本册停用变量不应清除本幕明确选择的预设值。
- 多文件配置的校验/保存并发窗口：检查和写入使用同一锁，并增加中断恢复日志。
- 图片接口返回硬编码 localhost URL：改为同源相对路径，支持同源图片访问。
- 新生成光栅图片按画册目录保存并去重，避免把所有原图重复塞进配置 JSON。
- UI 元数据里不再重复保存完整 ComfyUI、LLM、XML 原生配置副本。
- 模块构建器在 ESM 项目中直接 require CommonJS 生成壳的问题已修复。
- 修复 lint 指向不存在的根目录脚本、全局声明采集漏掉逗号声明、界面冒烟测试等问题。

目录和备份规则详见 [DATA_LAYOUT.md](DATA_LAYOUT.md)。

## 6. 开发与测试

日常启动不需要 npm：

```bash
python server.py
```

修改代码与测试：

```bash
npm ci
npx playwright install --with-deps chromium
node tools/sync-eslint-globals.mjs
npm run build
npm test
```

主要实现：`js/workspace.js`。原 standalone 脚本已按仓库原有构建器提取到 `state/sync/engine/creation/ui/app` 源模块，`index.html` 是它们的构建产物。后续请编辑源模块后执行 `npm run build`，**不要再次 extract 覆盖已修改源码**。

验证结果：

- JS/HTML lint 通过。
- 54 项 JS 契约测试通过。
- 28 项 Python 测试通过，包含数据读写、缺损保护、事务恢复、图片路径与去重。
- 28 项浏览器检查通过，包含真实文件选择器、多文件导入、创建预设、A/B 独立快照、运行途中加入任务、待执行任务切换、后端保存与重载、移动端布局。
- 浏览器测试通过模拟 `/prompt → /history → /view` 响应，验证实际客户端链路及真实 Python 图片保存接口；**没有使用真实 GPU 出图**。

## 边界

- 没有连接用户的 ComfyUI、实际模型或第三方自定义节点，仍应在本机核对每份映射并做一帧试跑。
- 不保证多浏览器同时编辑同一工程没有逻辑覆盖；保留原集合缩减保护，未新增完整的协同编辑冲突合并。
- 原始 API 请求体大小限制仍在，极大的工作流或历史快照集合需控制规模；工作流快照为保证可追溯仍会占用存储。
- 已修改并验证源码与网页交付包，没有编译 Windows 可执行程序，也没有推送到 GitHub。
