### 6.3 扩展启停的宿主与 iframe JS 堆

| 视口     | 六包全停用 | 全启用但未打开面板 | 再次全部停用 | 未打开面板时 iframe |
| -------- | ---------: | -----------------: | -----------: | ------------------: |
| 1440×900 |      5.860 |              6.567 |        6.028 |                   0 |
| 390×844  |      5.773 |              6.565 |        6.036 |                   0 |

未打开面板时 DOM 节点数分别保持 766 和 760，但 JS 堆并非严格零增量。逐个打开专业面板时，每次 1 个隔离 iframe，其自身 retained JS heap 约 1.803–1.857MB；宿主约 7.023–7.061MB。两者必须分开，不能只报宿主堆来声称整个面板只占这些内存。

报告中的界面 ready 与面板 ready 时间是各次实测观察：面板计时从实际菜单点击前开始，120 幕看板准备时间另列。缓存与运行顺序没有构成随机化多轮基准，因此这里不使用 ready 数值宣称启用扩展更快或更慢，也不宣布“零空载 CPU 回归”。本次未测 GPU 占用率、VRAM、瓦数、电池能量、整机总内存或发布包体积差值。
