# 本机真实服务验收（2026-11-15）

使用仓库外隔离工作区，通过 Mio 的实际 API、任务引擎和持久化链路验证。没有修改用户作品、个人 LoRA 或正在运行的服务配置。本记录区分链路通过与效果质量；不代表所有 ComfyUI 插件、所有模型或所有渠道已通过验证。

## 本机 ComfyUI

- 环境：ComfyUI 0.14.1，RTX 4060 Laptop 8 GB，提交前后队列均为空。
- 工作流：内置 `builtin_t2i_sdxl`，已安装的 `anikawaxl_v4.safetensors`；512×512、6 步、Euler / normal、CFG 5、种子 20261115，无 LoRA。
- 内容：窗边木桌上的白色杯子，中性静物。
- 结果：一次提交、一张 PNG，44.77 秒；WebSocket 预览、history / view 取图、素材保存、候选持久化均通过。
- 重复提交同一幂等键返回原任务；重开数据库后候选及图片字节一致；采用后可生成阅读合成图。
- 边界：6 步图片非空但较抽象，不能据此认定美术质量达标。未测试 ParameterControlPanel 状态写入、控制图、个人插件或完整成品细化链路。

## 本机 OpenAI 兼容代理

该服务的已验证配置是 **聊天接口出图**（`chat_image`），地址 `http://127.0.0.1:5104/v1`，模型 `gpt-image-2.5-sunburst`。实际请求使用 `/chat/completions`。

| 检查 | 结果 |
|---|---|
| 请求与候选 | 一次任务、一张候选；33.2 秒完成 |
| 返回图片 | WEBP，实际 1254×1254，视觉核对符合白杯、雨后窗景及低饱和水彩提示 |
| 请求画幅 | 1024×1024，通过提示表达；返回尺寸按实际图片记录 |
| 参数边界 | 负向与尺寸通过提示表达；种子不支持，候选种子为空 |
| 持久化 | 采用成功；重开数据库后图片摘要及候选一致 |
| 阅读 | 640×640 预览可解码 |
| 幂等 | 相同请求复用原任务，没有再次生成 |

先前误选 `openai_images`，请求 `/images/generations` 后返回 502（上游 500）。Mio 只发送一次，代理日志显示其内部尝试上游 5 次；Mio 保留 `blocked / uncertain`，没有自动重发。用户指出正常使用聊天端点后，改用 `chat_image` 成功。两条端点的模型解析不同，前者失败不能推断整个代理不可用，也不能归因于图片尺寸参数。

代理目前没有 `/images/edits`；本次聊天出图未发送参考图。NovelAI、参考图一致性和混合本地细化仍需独立实测。

## AI 剧本辅助

通过相同代理的 `/chat/completions` 使用 `claude-opus-5.5`。两次请求均经过真实的已配置客户端与公开 API，没有模型回退、网络重试或结构修复。

- 生成：45.2 秒返回 12 格剧本，含两名成年人和三个场景；结构、唯一 ID、角色与场景引用均有效。
- 定向修改：64.0 秒生成只修改末格对白的一个操作；创建提案前后，作品及角色设定逐字段一致。
- 显式应用：作品修订号从 0 增至 1，指定短句生效，其余 11 格及角色设定未变。
- 手工边界：没有创建生图任务或候选。AI 建议需要明确应用，不会借助文本请求自动生成图片。

验收准备阶段修复了剧本生成覆盖文本模型设置的问题；公开 API 的离线回归与此次真实请求均确认使用指定模型。
