## ComfyUI

修复三处实际阻断：串联阶段对多个底图节点完整传图；普通 `[mio:ref]` 接收第一张参考图而非静默忽略；`output:*` / `inspect:*` 使用输出节点选择器。未使用的自动参考图仍不强行注入工作流；直接编译不支持的编号参考输入会明确报错。

以下任务通过 Mio 编译和执行器提交到本机 8188，均为 64×64 CPU 图，不调用生图模型。

| 项目 | 实服结果 |
|---|---|
| 普通参考图＋蒙版 → 合成 → PreviewImage / SaveImagePlus | 两个输出成功回收，四处像素与预期一致 |
| EmptyImage → 两个 `[mio:init]` → ImageBatch | 同一结果只上传一次，两个输入都收到图片，回收两张 RGB(51,102,153) 图片 |
| ParameterControlPanel → ParameterBreak → EmptyImage | 执行提交时冻结的 RGB(90,155,199)，后改配置不影响本次；结束后恢复原空参数与展开结构，租约释放 |

共四次提交，全部终态成功，前后队列为空，最大结果仅 1,407 字节。原始证据保存在本机忽略目录 `output/comfy-round-smoke.json`，复验脚本为 `output/comfy_round_smoke.py`。未重复提交任何状态未知的请求。

边界：这不等于所有自定义插件认证。当前收图仍依赖标准 `history.images`，多阶段仍以上一阶段首张输出作为下一阶段底图。138 节点 Alice 完整细化链、任意非图像输出和其他前端状态插件不在此次实测范围。

## 长篇体验

隔离服务 8795 使用合成数据：120 幕、1,440 张候选、12 份各 250 个变量的预设，以及 40 份分镜。素材仅为小尺寸色块图；没有复制用户作品。

真实 Chrome 在前台测量，打开耗时计算到弹窗挂载后两个动画帧；滚动采用连续逐帧移动，记录帧间隔。后台标签页受节流影响的数据已排除。数据用于比较同一机器同一页面，不能作为所有设备的性能承诺。

| 操作 | 修改前 | 修改后 / 核验结果 |
|---|---:|---:|
| 1,440 候选中打开大图 | 1,694 ms | 379 ms，约减少 78% |
| 预设导出列表滚动 p95 帧间隔 | 183.5 ms | 12.6 ms |
| 导出列表超过 32 ms 的帧数 | 39 / 89 | 0 / 89 |
| 120 幕中切到第 120 幕 | — | 12.6 ms |
| 第 120 幕输入到下一次呈现 | — | 8.1 ms；自动保存后 API 读回一致 |
| 250 变量预设输入到下一次呈现 | — | 62.3 ms；自动保存后 API 读回一致 |

候选先统一分组、排序与索引，再按变化行和卡片重绘；保留完整 DOM，框选及跨幕顺序不变。浏览器长帧记录表明，原弹窗还有约 760 ms 的全页样式/布局开销，所以看板大图改用原生顶层弹窗并复用共享视觉。共享遮罩去掉背景模糊，保留半透明颜色并集中为 `--overlay-background`。

已复核左右键浏览、Esc 关闭、关闭返回原焦点与背景不可交互；原生弹窗打开时以根元素的非继承属性锁住背景滚动，关闭后精确恢复原样式。导出保持单一滚动区域。回归覆盖 Ctrl/Shift 选取、全选、采用/拒绝/恢复、实时任务状态、嵌套弹窗和遮罩拖动。大图打开仍约 0.4 秒，完整 DOM 仍有成本；本轮未贸然引入会改变框选几何的虚拟列表。

## 可选扩展

[审稿联系表](../examples/extensions/review-sheet/README.md)仅注册稳定 `exporter` 契约，将现有画布按保存的取景与比例导出为带编号和备注区的离线 HTML；没有新增核心路由、内部 API 依赖或默认面板。

在隔离服务 8796 上，官方 Python 客户端完成安装、摘要启用、发现格式、导出、停用和卸载。只读令牌启用返回 403、匿名导出 401；合法只读导出生成 12 格、315,051 字节 HTML，前后作品数据完全一致。停用后格式消失且导出返回 400；测试令牌已撤销，测试进程已关闭。

产物 `output/review-sheet.html` 在真实浏览器中 12 张图片全部加载、无横向溢出。它保留画格取景，适合审阅构图与打印批注；跨格文字及最终画质需回原画册查看，长图合成仍受核心内存限制。
