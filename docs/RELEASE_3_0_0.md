# Mio 3.0.0 · 可编程创作引擎

日期：2026-09-14。基于最新主线与第二轮 UI 改动继续开发，源码工作区保留 Git 历史；未推送 GitHub。

## 交付范围

- `backend/ecosystem/` 独立管理原子存储、安装包、Python 扩展宿主、主题、可执行变量、DAG 与提供商桥接。
- `js/ecosystem.js` 提供 SDK v1、管理界面、脚本编辑器、阶段 0 进度、取消、缓存诊断和历史入口；`js/safe-mode.js` 先于第三方样式/脚本运行。
- 阶段 0 用 Acorn AST 发现依赖，独立节点并发，结果持久缓存，未确认执行不自动重试。阶段 1 只接收求值后的独立快照。
- 源画册/草稿是唯一全局编辑目标。已有生成任务不会因源稿修改而变动。历史记录从队列/历史弹窗查看；已有图片/任务始终保留独立身份。
- 源画册拥有独立故事；新编辑写入本册故事，导出包含本册有效分镜，重新导入不会丢掉旧故事未失焦的文字。
- 全局 CSS 与含材质/字体 ZIP，拖入安装、即时切换、官方主题回退、安全恢复。
- 公开 HTTPS Git URL + 可选分支，以及 ZIP 安装。物理代码目录与用户数据目录独立；启停、更新、卸载可分别操作。
- 示例：场记本前后端扩展、横向深色主题、纸纹主题包、头像/环境/牌组可执行变量；完整离线中文开发指南。

## 需要明确理解的行为变化

旧测试中“在全局选择器选择 task:版本并直接编辑队列输入”的 UI 契约已移除，不做兼容。对应验收改成源稿/队列隔离；底层已持久化任务的恢复、修订和并发契约仍单独验证，不把任务修订伪装成源稿编辑。

## 运行与信任

Python 3.10+；可执行变量需 Node.js 20+，Git 安装需 Git。源码运行无需 npm 依赖。扩展的 JavaScript/Python 和可执行脚本只适用于可信代码；独立进程/路径命名空间不是恶意代码沙箱。使用 `?safe_mode=1` 恢复前端，`MIO_SAFE_MODE=1` 跳过后端扩展启动。

取消或本地超时不能撤销已发出的外部请求及账单。服务端仍在等待的网络请求会占用并发槽；未确认结果需要明确的强制重算授权，不静默补发。

## 验收方法与边界

完整测试入口 `npm test`，独立生态测试入口 `npm run test:ecosystem`；打包后运行 `node tests/packaged_runtime.mjs <ZIP路径>`。详细结果记录在 [本轮验收](ECOSYSTEM_ACCEPTANCE.html)。

自动化使用自有 ZIP 扩展、真实 Python 子进程、真实 Node 子进程、真实浏览器、临时文件目录和受控本机模型服务。没有调用真实付费云模型或用户的 ComfyUI。公共 Git 网络传输的可用性取决于本机环境；更新事务与命令参数通过离线夹具验证。Windows 的平台专有分支未在 Linux 环境实测。

成功付费缓存不自动淘汰；接近 32 MiB 配额会提前拒绝新执行，提供显式清理。准备记录按数量/体积保留最近一批；图片资产不按时间删除，避免破坏仍在使用的引用。
