## 回归中一并修复的问题

这些问题来自当前仓库内容与先前测试约定的漂移，不是通过停用功能或跳过断言来处理：

1. **随包校验清单过期**：`settings/workspace.json` 与基础 Anime 工作流文件的实际内容和清单哈希不同。保留原数据文件，只重新生成显式文件清单中的这两个校验值。
2. **可选功能测试依赖旧默认偏好**：随包偏好关闭了可选工作区和日志，而部分 UI 测试直接尝试点击这些入口。相关测试现在显式准备启用这些功能的 fixture，不更改用户的运行时默认偏好。
3. **装配渠道旧断言**：应用已经按当前启用渠道预选，旧测试仍要求沿用上一次渠道。改为验证当前安全选择策略，并为后续测试显式选取受控渠道。
4. **工作流测试漂移**：连接设置已改为初次使用时展开，测试增加「默认展开且可折叠」验证；测试编译的分镜补上新工作流必需的 seed。
5. **原工作流界面的英文缺失**：补齐新映射界面词条、计数和渠道提示中的默认名称翻译，恢复既有语言审计。

## 明确的边界

- 未声称支持所有历史测试脚本：验收范围是主回归链、额外工作流测试、新测试和实际包测试；旧版迁移脚本并未全部执行。
- Windows 原生命令执行需在真实 Windows 上验证；本环境仅通过启动脚本格式等静态测试。
- 未连接真实 ComfyUI、NovelAI 或 OpenAI 付费服务；不能将受控测试当作所有真实提供商的兼容认证。
- 可信扩展不是沙箱；JavaScript 同步死循环不能被宿主超时强制打断。
- 完整 CSS 可隐藏或仿冒控件并加载外部资源。预览回退、安全 URL 和后端安全模式仍需保留。
- 没有实现插件商店审核、私有仓库认证、自动安装第三方依赖或扩展间依赖求解。
- 样式工作台针对应用壳层，不会自动穿透阅读器的隔离 iframe；画册 HTML/CSS 仍使用项目原有导出模板编辑器。
- 没有向 GitHub 推送、发布 Release 或合并 PR；本次交付是可运行源码包及可审阅补丁。
