# Mio 2.0.0 — 独立文件工作区

2026-09-13 · 基于已交付的 1.2.1 继续开发。完整源码运行包，不是补丁，也不是仅有转换工具的预览版。

## 本次交付

- **主程序真正改为独立文件读写**：设置、分镜、角色/场景设定、企划、计划、工作流、版式和画册分开保存。每册拥有 `album.json` 和 `images/`，保存提示词、对白、原图和编辑快照。
- **减少覆盖风险**：保存以资源版本为单位；不同字段可以合并，同字段冲突拒绝覆盖并保留本页草稿。导入分配新 ID，不按同名文件覆盖。
- **分享可以带走图片**：设置中的单资源分享 ZIP 带校验清单与本资源图片；不含图片的独立 JSON 可以直接复制/导入。企划引用不等于自动捆绑所有成员。
- **启动只取画册摘要**，打开、编辑与导出时才加载正文。索引可删除重建，并有独立缓存版本；摘要不会当作空正文写回。
- **私密设置单独存放**：图像、文本及独立视觉连接密钥使用本地绑定凭据；文本/视觉代理在服务器解析密钥。留空保留绑定，换地址不携带旧密钥，显式忘记只清除指定连接。
- **执行与画册整理衔接**：持久 SQL 结果、图片编辑和删除墓碑在文件整理失败后保留。整理记录可恢复，不借机重发模型请求；失败会在控制台/文件库诊断中提示。新服务启动暂停已有任务，第二个 worker 不得改变第一实例状态。
- 保留 **AFTERGLOW 1.2.1 图像优先、完整不裁切的连续正文**、原五个模板与默认选择、原图/图层/气泡的阅读和导出一致性。
- 合并分镜导入编辑器修复。`examples/storyboards/晴天借阅室_分镜导入.json` 是可选的纯中文 12 幕分镜，只有一个 `{主角参考图}` 变量；不会自动安装或替换你的分镜；在分镜编辑器的普通「导入分镜」入口导入该可选文件。

## 启动与迁移

1. 安装 Python 3.10+，完整解压到新文件夹；运行 `start.bat`、`bash start.sh` 或 `python server.py`。
2. 新工作区默认为程序旁的 `data/`，也可使用 `MIO_DATA_DIR` 指向独立目录。
3. **1.x 旧数据不能直接交给 2.0。** 停止旧服务，备份旧项目，运行显式转换工具输出到原来不存在的新目录，然后使用新版打开它。
4. 不覆盖唯一旧原件；不删除数据来消除启动错误。执行/生成仍须手动开始。

运行不需要 Node.js 或第三方 Python 包。开发、浏览器测试需要 npm 开发依赖与 Playwright Chromium。此交付是完整源码运行包，**不是声称已实机验证的 Windows EXE**。

## 启动效率

实际运行 Python 服务与 Chromium，不只是测目录扫描。数据集为 **5000 册 × 每册 12 幕，约 183 MB JSON，无图片**。首次冷索引与已有索引分别测量；证据见 `acceptance-2.0/gui-benchmark.json`。

参考运行：冷服务就绪约 **3.34 秒**，热启动约 **0.28 秒**；服务就绪后的 GUI 启动约 **1.24 / 1.26 秒**，首册正文约 **12 / 10 毫秒**。启动未请求任何画册正文；画册卡片数量有界。原始测量数据见日志；服务与 GUI 时间分开计时。

这不是含大量真实图片的 5000 册图库测试，也不是慢硬盘、手机、网络共享盘或所有设备的性能保证。摘要响应仍包含全册目录，约 2.7 MB；极大图库仍可进一步服务端分页。

## 明确边界

- JSON 文件事务与执行 SQL **不是跨存储的单一原子事务**。采用持久记录与恢复整理，不承诺第三方计费 exactly-once。
- 不确定的上游结果不自动重试；已明确配置的确定性 HTTP 失败重试遵循队列策略。画册删除只需一次确认，不要求查询供应商或二次放弃跟踪。
- `settings/secrets.json` 是权限限制下的**明文**，不是加密保险库。完整停机目录备份包含密钥；普通 JSON 引用不等于图片已备份。
- 自动清理已知凭据字段不代表能识别任意提示词、用户自定义字符串、历史工作流中的秘密；公开分享前仍需检查。
- 未验证真实付费供应商、Windows/macOS 原生运行、实体手机或 Safari/Firefox。移动视口自动化不能替代实体设备验收。
- 《晴天借阅室》未进行付费出图或角色一致性实测。用户渠道名 `gpt-2.5-image` 与官方具体模型的映射未确认，没有擅自更改渠道模型。
