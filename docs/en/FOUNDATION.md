# Generation tasks

Create a task in the workshop, select a provider, storyboard and presets, then add it to the queue. Start it from its task card.

Use Pause, Continue, Rerun scene or Recover result as needed. Expand a task to review scene progress. Request records and errors are available in diagnostic details.

For an unconfirmed result, use its task ID to check the provider before choosing recovery or rerun.
