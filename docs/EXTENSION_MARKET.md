# 扩展市场目录

扩展是可独立复制、导入的文件夹。市场只提供查找与下载入口，不改变扩展包格式，也不自动执行下载的代码。安装后须在扩展详情中查看并启用。

扩展可在根目录附带可选 requirements.txt，每行使用标准 Python 包声明（PEP 508，含 extras 与环境标记）。用户确认当前扩展内容摘要并启用时，Mio 递归检查完整基础依赖与所选 extras 的闭包，遵守环境标记并对循环依赖去环。只有闭包不满足时才调用 pip dry-run；计划不得改动共用环境中任何已安装包的版本。

正式安装将 dry-run 的全部动作固定为规范化的 `name==version`，连同宿主全部已安装版本写入临时约束文件，并以 `--no-deps` 安装该精确集合，禁止第二次解析自行增加依赖或选择其他版本。空计划、重复规范化包名、非法版本、遗漏缺失的直接依赖及无法表达为索引包的直接 URL / VCS / 目录动作均拒绝；预检查期间环境发生变化也拒绝。安装后再次核对计划中的精确版本、原有宿主版本与原声明的完整依赖闭包，失败不加载扩展。临时计划随操作结束清理；pip 输出不回显凭据。

若现有版本不满足扩展要求，需用户先自行解决冲突。不创建每扩展虚拟环境，不接受 pip 参数、包含文件、本地路径或直接 URL。版本约束不等同于构建产物哈希锁定，也不提供跨工作区或外部进程的解释器事务；受信安装脚本的副作用无法自动回滚。Python 扩展和依赖安装都不构成进程隔离，可能有共享依赖冲突，启用前只信任可信来源。

默认目录 `extensions/catalog.json` 列出实际随包的 AI 辅助扩展和六个默认停用的专业工作台扩展，名称和版本读取各自的 `mio-extension.json`。独立主题使用自己的 `themes/<id>/mio-theme.json` 包格式，在主题设置中导入；它们不经过扩展启用和代码信任流程。扩展仍可通过 `contributes.themes` 附带主题，随扩展一起启停。可在市场中填写自己的 HTTP / HTTPS 扩展目录地址；留空恢复随包目录。不接受包含用户名或密码的地址，地址片段会被移除。

远程目录是 UTF-8 JSON，例如：

```json
{
  "format_version": 1,
  "items": [
    {
      "id": "example-tool",
      "name": "示例工具",
      "version": "1.0.0",
      "description": "一个独立的创作扩展",
      "author": "Example",
      "homepage": "https://example.org/example-tool",
      "tags": ["创作"],
      "package_url": "https://example.org/example-tool-1.0.0.zip",
      "sha256": "填写 ZIP 文件的 64 位 SHA256 十六进制摘要"
    }
  ]
}
```

`id`、`name`、`version`、`package_url`、`sha256` 必填，其他元数据可省略。ID 由小写字母、数字、下划线与短横线构成，长度 2–48；一个目录中的 ID 不可重复。ZIP 可直接包含扩展文件，也可包含单个顶层扩展目录。包内清单 ID 与版本须和目录完全一致。目录不超过 2 MB / 500 项，压缩包不超过 50 MB，解压安全检查由扩展导入器统一完成。

目录默认缓存 10 分钟，手动刷新立即重新获取。刷新失败会保留同一来源上一次成功的目录并显示错误；切换来源会清空旧远程目录，避免从错误来源安装。用户配置和缓存存放在工作区的 `extension-market.json`，不写回扩展包。

开放 API 与本机界面具有相同能力：

- `GET /api/v2/extension-market?refresh=false`：来源、目录摘要、条目、安装状态和可执行动作。
- `PUT /api/v2/extension-market/source`，请求 `{ "url": "https://example.org/catalog.json" }`：切换目录。
- `POST /api/v2/extension-market/{id}/install`，请求 `{ "expected_catalog_digest": "列表中的摘要", "expected_sha256": "条目的摘要" }`：下载、校验并安装为禁用状态。

市场管理需要 admin 令牌。安装会再次核对目录摘要、包摘要及包内身份，过时的选择会被拒绝。更新同样需要用户主动选择，覆盖对应用户扩展后保持禁用；不影响该扩展独立的数据目录。此目录协议允许自建市场；项目未连接第三方公共市场。
