# 独立首页 · 2026-09-18

基于完整源码修订 26d2881。新增一级模块「首页」，不是替换画册集，也不是静态演示页。

## 页面结构

- 首屏：工作室基本介绍、原创 SVG 画册插画、「从一幕开始」与「浏览我的画册」。
- 当前画册集概览：实际画册、分镜、预设数量，以及「本地优先」的工作方式说明。没有虚构请求量、模型在线状态或云端可用性。
- 主要工作区：画册集、创作工坊、工作流与 API 配置；每张卡片包含用途、操作范围与跳转。
- 首次使用：原「初光映格，微墨生花」三渠道引导与教程入口搬到首页，保留收起／重新展开及保存的偏好。画册集不再重复显示。
- 可选模块：可选功能、AI 写故事、模板与扩展市场、运行日志。已开启的进入对应模块；未开启的跳到功能设置，不会自动打开开关。
- 工作室设置入口：外观与语言、文件与保存及功能设置的介绍。

## 行为与兼容

- 每次载入默认进入首页；侧栏第一项与 Mio 标志可回首页。首页使用独立内部路由 9，原画册集仍为 0，其他已有路由不重编号。
- `Alt+0` 回首页；`Alt+1` 画册集；`Alt+2` 创作工坊；`Alt+3` 渠道配置。修正原 Alt+3 与侧栏提示不一致的问题。编辑输入框及模态窗口内不劫持这些导航键。
- 所有首页入口只导航，不自动创建任务、不执行可执行变量、不连接／探测模型、不隐式产生付费请求。实际生成仍需在任务卡确认。
- 深浅主题、中英文均支持；英文首页链接到英文指南。用户的画册集名字不变。
- 390px / 320px 手机和 844px 横屏无页面横向溢出；导航项目过多时内部横向滚动，不缩小点击面积，当前项目会滚动至可见位置。主要按钮至少 44px。
- 首页状态属于展示层，不修改已有作品数据格式和凭据机制；上一轮密钥直填及英文补齐保留。

## 实现与测试

独立 `js/home.js` 负责首页展示与导航；通过现有构建顺序和启动安装点集成。首页读取当前画册集的资源数据，不另建状态来源。

新增 `tests/home_workspace.mjs`，通过真实 UI 检查首次载入、侧栏、标志、卡片跳转、键盘、三个渠道、引导偏好持久化、可选模块开关、英文及浅色主题、真实计数、空画册集、移动布局和不产生生成调用。运行 `npm run test:home`，已纳入 `npm run test:current`。

本轮具体测试结果及最终 ZIP 运行验收见交付目录中的验证摘要。测试使用隔离临时目录和本地协议替身，非真实付费服务验证。Windows、WebKit 和真实手机软键盘／输入法尚未实测。
