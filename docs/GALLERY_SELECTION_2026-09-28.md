# 画册集选择交互回归 · 2026-09-28

## 范围

按用户反馈，对照旧版 `legacy/js/desktop-selection.js`、`organize.js`、`context-menu.js` 和 `ui-gallery.js` 恢复画册集的选择体验。沿用当前 React 与新后端，不回滚数据模型，不把旧版全局脚本塞回页面。

本轮不改变后端、个人画册内容、生成任务或付费服务。旧版目录只读参考；画册手动排序及其他页面的差异不在本次完成范围内。

## 问题与行为

关键差异不是少了一个按键监听：旧版的 `.is-context` 是菜单的临时目标，新版却在右键时调用 `selection.contextTarget()`，把目标写成了持久选择。

| 操作 | 恢复后的行为 |
|---|---|
| 右键未选画册 | 只显示临时菜单高亮；一次 Esc 关闭菜单、移除高亮并把焦点还给画册 |
| 右键已在多选内的画册 | 保留多选并打开批量菜单；Esc 先关闭菜单，再按一次清空选择 |
| 右键选择外的画册 | 清除旧的多选，只把新画册作为本次菜单目标，不留下额外的持久选择 |
| Ctrl / ⌘ + 右键 | 把目标加入现有选择，不把已经选中的项反向取消 |
| 普通单击封面、标题或卡片空白 | 即使已有多选，仍然直接阅读；打开前清空选择 |
| Ctrl / ⌘ 点击、Shift 点击 | 加减选择、从锚点连续选择；标题区与封面共用同一套规则 |
| 单击列表空白 | 清空选择；右键列表空白则保留已有批量目标 |
| 拖动框选 | 从封面或空白起拖，超过 5px 才激活；拖动到边缘自动滚动；Ctrl / ⌘ 按开始快照加减，Shift 追加 |
| 取消拖动 | Esc 中止并清空选择；指针取消或窗口失焦恢复拖动前的快照；松手后的 click 不误开阅读器 |
| 键盘 | 列表内 Ctrl / ⌘ A 全选筛选结果；Space 切换焦点画册；Enter 阅读；Shift+F10 / 菜单键打开菜单 |
| 输入框、菜单、弹窗、阅读器 | 列表快捷键不越层响应；菜单 Esc 阻止原生 dialog 的额外关闭，方向键不穿透底层页面 |
| 删除 | 普通 Delete 仍先确认；Backspace、带修饰键的 Delete 和长按重复事件不再触发批量删除 |
| 精选展示 | 同样支持右键与键盘选择，不因为选中数量变化突然切换成网格 |
| 触屏 | 保留显式多选入口与普通点击阅读；触摸滑动不被框选截走 |

桌面不再要求进入“批量管理”模式。选择后的反馈改为轻量计数及导出、删除、更多、取消入口；星标、全选、换封面、导出工程包、删除确认和撤销等既有能力保留。

框选时只更新卡片状态，状态行 / 提示保持拖动开始时的布局，避免卡片在指针下跳动。筛选隐藏或删除的 ID 会自动退出选择。菜单聚焦不滚动页面，也不会被刚打开时排队的布局滚动立即关掉。

## 生效

本轮仅前端交互修改。生产资源构建到 `web/dist` 后，刷新画册集即可使用；不需要重启后端，既有服务和任务不自动中断。
