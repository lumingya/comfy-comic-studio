# UI 回退复刻审计（2026-10-01）

新版界面在 09-27 回退复刻为旧版界面之后，逐页对照旧版（`legacy/`，隔离数据运行在另一端口）与新版（真实数据的副本，隔离的后端与开发服务器）实测。本文件记录发现的问题、修复与仍未处理的项目；每项修复都在 [路线图](ROADMAP.md)「UI 回退复刻后审计」一节打勾。

## 用户报告的问题

| # | 现象 | 原因 | 处理 |
| - | ---- | ---- | ---- |
| 3 | 队列卡片「展开分幕进度与局部重跑」点了没反应 | 可框选列表（`useDesktopSelection`）把卡片里 `<summary>` 的点击当成「选中卡片」并 `preventDefault`，`<details>` 无法展开；`<label>` 同样受影响 | `<summary>`、`<label>` 归为控件，点击保留原生行为 |
| 2 | 版式抽屉点「导入」，在文件对话框里点「取消」，抽屉自己收起 | Chromium 在文件选择被取消时向 `<input type=file>` 派发**冒泡**的 `cancel` 事件；React 的 `onCancel` 把它交给阅读器 `<dialog>`，后者当成 Esc 关闭抽屉 | 新增 `ownCancel()`：阅读器、模板工作室、新建生成任务、帮助抽屉、命令面板只响应发给自己的 `cancel` |
| 1 | 「墨与叙事 · 漫画精装」第 1 页时「‹」亮、「›」灰，往左才是下一页 | 新版 `album/runtime.js` 把 `manga` 版式做成从右往左翻页（按钮对调），但格子仍从左往右排列 | 按旧版 `compiledBookRuntime` 重写：漫画双页不分页（奇数补「留白」衬纸），交互画册从左往右翻、文字按钮「上一跨页 / 下一跨页」，手机单幕、封面只在首页、尾声只在末页，阅读器 ← / → 转发给模板；基础样式里的按钮样式降为 `:where()` 兜底，不再覆盖模板自己的设计 |
| 5 | 新生成的图片在模板里无法实时预览 | ① 任务条目完成时只发 `complete` / `failed` 事件，前端只在任务整体状态变化时刷新分集，整批跑完前阅读器看不到新图；② 模板预览的查询键不含分集版本，还缓存 5 分钟 | 条目完成即刷新任务、分集、画册列表；模板预览与平台切片预览按分集 `revision` 重新渲染，刷新后回到原来的滚动位置与跨页（模板运行时回报 / 恢复阅读位置） |
| 6 | 模板简介直接显示 `{female_name}`…`{style}` 等变量；STARRING 为空 | 导出画册时简介原样输出；`characterName` 从未赋值 | 简介、标题按本册变量展开；读者看到的文字（简介、标题、主演、字幕 / 台词、条漫气泡、动态漫台词）里**未定义或为空的变量连同相邻的一个分隔符一起隐去**（旧版 `interpolate` 对台词就是这样处理的），例如「七海 · 标准角色设定」没有定义 `female_name` / `female_lead` / `male_name` / `male_lead`，读者不会再看到 `{female_name}`；出图提示词仍保留未定义的变量原样，方便排查。画册集书架的简介同样显示展开后的文字，并参与搜索；主演取「角色展示名」；单话画册封面用画册名，CHAPTER 行用分镜名（旧版规则）；动态漫片头同样展开 |
| 4 | 「功能开关」只有经典 / 专业二选一，远不如旧版细 | 回退复刻时把旧版逐项的功能开关换成了一个总开关，所有专业界面都绑在它上面 | 创作模式保留为两张紧凑的选择卡；按旧版「只留下你需要的功能」列出核心功能、专业模式总开关与五项专业工具，逐项开关（`useStudio(feature)`，存关闭列表，新工具默认开启）；原先绑在总开关上的界面按工具拆开 |

## 逐页对照发现的其他问题

| 位置 | 现象 | 旧版 | 处理 |
| ---- | ---- | ---- | ---- |
| 版式抽屉「导入」 | 文件对话框的类型筛选显示「*.json;*.json」；只能导入 JSON，旧版导出的 HTML 模板导不进来；导入同 id 的模板会悄悄覆盖已有模板 | `pickFile('.html,.htm,.json')`，HTML 取 `<title>` 作名称、读 `comfycomic-export-template` 元数据，每次导入都是一份独立副本 | `accept` 只写扩展名（其他文件选择框同样去掉重复的 MIME）；HTML / JSON（含旧版 `{ template }` 包装）都能导入，HTML 源码原样保留，导入总是新 id；导入后列表滚到新模板 |
| 版式抽屉模板列表 | 顺序按文件名（余光、深夜放映室、白昼美术馆…，无缝排最后）；图标框没有模板主题色 | 留白、无缝、余光、海风来信、墨与叙事、白昼美术馆、深夜放映室；图标框用模板强调色描边 | 按旧版顺序排列，自定义 / 导入的模板排在后面；图标框恢复 `--swatch` 强调色 |
| 画册集筛选与排序 | 状态筛选是「草稿 / 连载中 / 已完结」（这是装配队列的待命标记，不是画册是否画完）；排序是「最近更新 / 按标题 / 最早创建」，「最早创建」实际按最新排；没有手动排序 | 画册状态：所有画册、已完成、生成中、待补齐、星标收藏；画册排序：手动排序、最近创建（默认）、最近修改、分镜数量，排序记在本机 | 恢复旧版的状态筛选（生成中＝本册分集有排队 / 运行中的任务；待补齐＝还有分幕没有画册图）与排序；星标按钮切换「星标收藏」，旧链接 `?starred=1` 仍可用 |
| 画册卡片与精选展示 | 卡片写「草稿 · 09.30」（队列状态 + UTC 的修改日期）；精选展示多一段队列状态，缺图的画册没有「补齐 N 幕」 | 卡片「N 幕 · 已完成 / 生成中 / 待补齐 · 创建日期」；精选展示「状态 / 创建日期」，缺图时下方「补齐 N 幕」 | 按旧版显示（本地日期）；「补齐 N 幕」只重跑缺图的分幕，每幕一张、出图即入册，已完成的画面不动 |
| 画册「⋯」与右键菜单 | 「⋯」是另一套下拉（更换封面 / 导出 / 删除），右键菜单缺重命名、补齐缺失分幕、导出离线画册、调整顺序，多选时也没有批量重命名与合并导出 | 「⋯」就地打开同一个右键菜单：标题与「N 幕 · 角色 · 待补齐 / 已齐备」；翻开、星标、重命名…、补齐缺失分幕；导出与分享；整理（向前 / 向后移动、选择当前筛选结果）；删除。多选：批量星标、批量重命名…、导出离线画册…（合并为一个 HTML）、补齐缺失分幕、只翻开这本、取消选择、批量删除… | 「⋯」与右键共用旧版菜单（保留「更换封面」）；重命名 / 批量重命名对话框只改名称；单本「导出离线画册…」打开版式抽屉，多本合并导出为一个离线 HTML（选模板与合集标题）；「分享画册源文件…」导出 .mio.zip |
| 画册拖动排序 | 卡片没有 ⠿ 把手（样式还在），无法调整画册顺序 | 按住 ⠿ 拖动 8px 后提起，封面缩略图跟随指针，落点显示竖线，靠近边缘自动滚动，Esc 取消；拖完切到「手动排序」并提示「画册顺序已更新」 | 按旧版恢复，只有把手能拖（其他位置照常框选），多选或触屏批量管理时不启用；右键「向前 / 向后移动」可用键盘完成同样的调整 |
| 版式抽屉「留白」的阅读方式 | 选项是「自适应阅读 · 默认 / 单幅完整画面 / 连续滚动」，和阅读器底栏的「自适应 / 单页 / 连续」重复，没有双页阅读 | 抽屉里选整体阅读方式：自适应阅读（底栏再选自适应 / 单页 / 连续）、单幅完整画面（一屏一幅并显示缩略图条）、双页阅读（1–2、3–4… 两页一屏） | 恢复旧版三项：自适应阅读保留底栏的三种方式；单幅完整画面一屏一幅，缩略图条常驻；双页阅读不论横竖都两页一屏。选择记在本机 |
| 模板阅读的状态行 | 只在载入时显示「正在排版预览…」，看不出这本画完了多少 | 模板上方常驻「整册阅读 · 已生成 N / M 幕」 | 恢复这一行；首次载入显示「正在载入整册…」，重新排版时追加「正在更新」 |
| 设置 → 工作室 | 只有画册集名称（顶栏和画册集页都能改）和界面语言；侧栏固定显示「我的工作室」；导出的「创作者签名」每次都是空的 | 工作室名称（显示在侧栏，头像取首字）、创作者署名、「同时更新默认画册签名」、保存名称与署名；导出时签名默认取这个画册签名 | 按旧版恢复，服务端新增 `studio_name` / `creator_name` / `signature`，首次启动时从旧版数据带过来；版式抽屉和多本导出的「创作者签名」默认取画册签名，临时改动只在这次阅读有效 |
| 平台发布切片预览 | 「切片预览」几个字在深色阅读背景上几乎看不见 | — | 改用阅读器的文字颜色。首张切片显示正常，不是空白 |
| 通用偏好 | 只有画册集名称、界面语言和 AI 模型设置；侧栏「我的工作室」和工作室名称 / 署名 / 签名在一个单独 tab；缺少字体风格、界面字号、界面密度、减少动态效果、默认阅读模式 | 语言与常规、字体与界面显示（字体风格 / 字号 / 密度 / 减少动态）、阅读与翻页（默认阅读模式）；LLM 设置单独 tab | 通用偏好恢复旧版分组（语言与常规 / 字体与界面显示 / 阅读与翻页），数据写入 `<html>` dataset，CSS 即刻生效；语言选项从工作室移到通用偏好 |
