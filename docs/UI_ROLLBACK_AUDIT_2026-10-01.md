# UI 回退复刻审计（2026-10-01）

新版界面在 09-27 回退复刻为旧版界面之后，逐页对照旧版（`legacy/`，隔离数据运行在另一端口）与新版（真实数据的副本，隔离的后端与开发服务器）实测。本文件记录发现的问题、修复与仍未处理的项目；每项修复都在 [路线图](ROADMAP.md)「UI 回退复刻后审计」一节打勾。

## 用户报告的问题

| # | 现象 | 原因 | 处理 |
| - | ---- | ---- | ---- |
| 3 | 队列卡片「展开分幕进度与局部重跑」点了没反应 | 可框选列表（`useDesktopSelection`）把卡片里 `<summary>` 的点击当成「选中卡片」并 `preventDefault`，`<details>` 无法展开；`<label>` 同样受影响 | `<summary>`、`<label>` 归为控件，点击保留原生行为 |
| 2 | 版式抽屉点「导入」，在文件对话框里点「取消」，抽屉自己收起 | Chromium 在文件选择被取消时向 `<input type=file>` 派发**冒泡**的 `cancel` 事件；React 的 `onCancel` 把它交给阅读器 `<dialog>`，后者当成 Esc 关闭抽屉 | 新增 `ownCancel()`：阅读器、模板工作室、新建生成任务、帮助抽屉、命令面板只响应发给自己的 `cancel` |
| 1 | 「墨与叙事 · 漫画精装」第 1 页时「‹」亮、「›」灰，往左才是下一页 | 新版 `album/runtime.js` 把 `manga` 版式做成从右往左翻页（按钮对调），但格子仍从左往右排列 | 按旧版 `compiledBookRuntime` 重写：漫画双页不分页（奇数补「留白」衬纸），交互画册从左往右翻、文字按钮「上一跨页 / 下一跨页」，手机单幕、封面只在首页、尾声只在末页，阅读器 ← / → 转发给模板；基础样式里的按钮样式降为 `:where()` 兜底，不再覆盖模板自己的设计 |
| 5 | 新生成的图片在模板里无法实时预览 | ① 任务条目完成时只发 `complete` / `failed` 事件，前端只在任务整体状态变化时刷新分集，整批跑完前阅读器看不到新图；② 模板预览的查询键不含分集版本，还缓存 5 分钟 | 条目完成即刷新任务、分集、画册列表；模板预览与平台切片预览按分集 `revision` 重新渲染，刷新后回到原来的滚动位置与跨页（模板运行时回报 / 恢复阅读位置） |
| 6 | 模板简介直接显示 `{female_name}`…`{style}` 等变量；STARRING 为空 | 导出画册时简介原样输出；`characterName` 从未赋值 | 简介、标题按本册变量展开（与台词同规则：未定义的变量保留原样，例如「七海 · 标准角色设定」没有定义 `female_name` / `female_lead` / `male_name` / `male_lead`，它们在出图提示词里同样没有被替换）；主演取「角色展示名」；单话画册封面用画册名，CHAPTER 行用分镜名（旧版规则）；动态漫片头同样展开 |
| 4 | 「功能开关」只有经典 / 专业二选一，远不如旧版细 | 回退复刻时把旧版逐项的功能开关换成了一个总开关，所有专业界面都绑在它上面 | 创作模式保留为两张紧凑的选择卡；按旧版「只留下你需要的功能」列出核心功能、专业模式总开关与五项专业工具，逐项开关（`useStudio(feature)`，存关闭列表，新工具默认开启）；原先绑在总开关上的界面按工具拆开 |
