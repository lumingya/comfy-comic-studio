# Mio 1.0.0

## 整册阅读、外链发布与逐幕重试更新

- 默认 index 从约 1.2 MB 改为约 7 KB HTML；UI 按阅读、展示、模板、导出、编辑器、语言、助手、分镜、画廊、设置分文件。
- 自定义阅读显示整册，模板独占导航；翻页不再切换三幕窗口。结尾在最后跨页显示，手机单幕，三张样本仅限明确的导出预览。
- 默认新安装每幕自动重试 5xx 5 次；可设 1–100 次。所有 4xx 不自动重试，422 标记并跳过；手动重试无累计上限、重置自动额度。
- 失败/暂停任务自然让后续画册进入，不需要「保留此任务，继续其他画册」按钮；未知结果仍须核对及明确确认。
- 日志按本幕尝试编号显示，实际提示词/模型/参数可展开，新事件不混入旧错误。移除初始输入清单；仅保留未提交 ComfyUI 任务的可编辑工作流选择。
- 原画册、已完成图片、最新保存渠道解析、独立滑动窗口及计费保护保持不变。旧安装保留已保存失败策略。


Mio 是本地优先的分镜编排、多渠道图像生产与画册工作台。

## 动态渠道配置与队列页面整理

- 每次请求按渠道 ID 解析最新模型、地址、参数与密钥绑定；关联任务共同生效，在途请求不变。
- 缺失配置停止本任务派发，不回退旧模型；实际配置进入请求记录。
- 队列运行工具栏收紧，卡片显示下次模型；详细错误和逐幕状态折叠，刷新保留展开状态。
- 云渠道不再显示无用的工作流占位区。

## 原编辑区直接修改后续分镜

- 移除独立提示词编辑弹窗，复用分镜故事和原修改范围选择器。
- 发送前读取画册最新已保存内容；在途请求不变，已完成图不重画。
- 支持精确选择画册版本及其自身分镜列表，不随任务结束误切换。
- 记录每次实际准备输入，ComfyUI 核对保留原请求版本。
- 原有并发、恢复确认、停止隔离和日志继续有效。

## 每任务分镜池

- 并发改为每任务独立分镜滑动窗口，任意完成立即补位，无整批等待。
- 任务默认 FIFO，支持拖动待办；明确手动启动另一任务时增加独立池，两个 4 路即 8 路。
- 默认失败继续本任务其他分镜，可选只暂停本任务；未知幕永不自动重试。
- 独立记录每幕状态、尝试、上游 ID、结果、超时和取消批次；乱序完成、重试、编辑、停止和重启都保留已确认索引。
- 更新任务 API 的索引进度元数据、并行启动和让出 FIFO 操作；文档与端到端实测同步。
- 自定义 HTML/CSS 旁白自由定位已验证预览和离线导出，未扩展框架。

## 任务控制、日志与导出修正

- 立即停止并关闭已建立的本地连接，丢弃迟到结果；独立批次号避免污染继续后的任务。
- 增加可执行/暂存/失败数量诊断及明确的批量暂存释放入口；继续原任务同时提交本地待办。
- 运行日志接入持久任务事件，刷新恢复近期记录，不再只有启动消息。
- 识别包在 502 内的明确内容拒绝，不浪费自动重试；重试等待期间立即可操作。
- 云任务未完成正/负提示词可人工修订并保留历史，不重做已确认图片。
- 导出样张优先选择已生成图片，预览缩略图缓存不影响原图导出。
- 全屏后重新提升模态阅读器；关闭清理抽屉/预览并退出网页全屏。

## 原任务恢复、并发与超时

- 失败、未确认和未完成的停止任务均可在原画册继续；先读取最新游标并确认，已确认的分镜不重发。
- 超时/断线的当前幕可明确确认计费风险后重发；保留 ComfyUI 只读核对，不自动重试未知结果。
- 队列页可配置每任务 1–16 幕并发与 30–7200 秒等待超时，设置持久保存。
- 原始幕号随任务保存，部分分镜的进度/继续按钮不再用局部计数冒充原幕号。
- 修复批量提交中轮询把 held 任务改为暂存后漏启动的竞态，以及 pending/paused/running 被写成画册状态导致保存契约报错的问题。
- 同册多任务汇总运行状态；保留已确认图，提供过期确认与持久进度一致性保护。
- 去掉覆盖所有供应商调用的全局生成锁，补充本地 HTTP 实际请求顺序和并行度回归。

- 保留上游 HTTP 状态与错误正文并脱敏回显密钥，失败队列可展开查看。
- 便携工程包含当前及快照引用的图片，恢复时重新落盘；外部 API 增加有序 `images` 参数。
- 新增 30 项浏览器专项与存储/HTTP/多图协议回归。已有队列测试显式声明留空的可选文字变量，区别于真正缺失变量。

## 验证范围

[完整自动化测试日志](TEST_RESULTS.txt)。市场压力测试可运行 `node tests/market_performance.mjs`；测试使用临时目录，不读取用户数据。

压力测试条件：240 张额外资源卡、500 本画册各 32 幕、Chromium 四倍 CPU 降速、120 帧滚动及 12 次局部文字变化。同机一次前后对比，全文扫描从 12 次降为 0 次，本地化累计耗时从 452.8 ms 降为 2.8 ms，帧间隔 P95 从 58.9 ms 降为 25.7 ms。该结果是合成负载测量，不代表所有设备的实际帧率。

## English summary

Mio brings storyboards, image providers, a render queue and illustrated albums into one local-first workspace. This update adds the Chinese Windows launcher, focused product documentation and a lighter marketplace: scoped localization, offscreen card rendering and debounced result-only search. Automated tests use isolated data and provider fixtures; native Windows execution and paid generation remain separately verifiable.
