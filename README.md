# 🎨 ComfyComic Studio

> **专为 AI 连环画 / 多格漫画 / 绘本创作者打造的批量自动化工作台**  
> 告别在 ComfyUI 中一张张手动改词、反复跑图的繁琐操作。编好分镜剧本与角色表，一键批量生成整本连贯漫画。

---

## 💡 这是什么？解决了什么问题？

如果你用 ComfyUI 创作过多格漫画、绘本或连环画，通常会遇到这些麻烦：
- **重复改词太累**：同一个故事，换个角色或服装就要把几十个分镜的 Prompt 全手动改一遍；
- **排队与中断痛点**：几十幕画面连续生成，一旦中途断网、报错或显存溢出，很难搞清楚哪张画了哪张没画，重新跑又浪费算力；
- **管理浏览不便**：生成的图片分散在各个文件夹，缺乏故事视角的连贯翻页预览和单页微调能力。

**ComfyComic Studio 就是为了解决这些痛点而设计的本地工作台。**  
它将**分镜模板**、**角色矩阵**与 **ComfyUI 自动化调度**结合起来，让你像编辑表格一样轻松批量制作连续画面。

---

## ✨ 你能用它做什么？

### 1. 📝 模板化剧本分镜
把你的连环画拆解为 10 幕、20 幕或更多分镜。提示词中直接使用 `{character}`（角色）、`{outfit}`（服装）、`{style}`（画风）等占位符，一套分镜剧本可以无限复用。

### 2. 👥 角色属性矩阵，批量一键出图
在矩阵表格里配置不同的主角属性（比如：A角色是金发女武神、B角色是黑发侦探）。配置完成后，系统会自动将整本漫画的所有分镜与角色属性结合，批量排队提交给 ComfyUI 连续出图。

### 3. ⚡ 智能断点补齐（再也不怕中断）
批处理过程中如果意外中断或某几幕生成失败，进入画廊只需点击**「补齐 N 幕」**，系统会自动识别缺失和失败的分镜并单独重跑，绝不重复生成已经画好的图片。

### 4. 🧠 AI 剧情大纲与灵感扩写
卡文或提示词写不出来？内置大模型（LLM）对话与剧情助手，输入一句话主题即可自动生成整套主线大纲并填充各幕分镜提示词。

### 5. 📖 沉浸式画廊、单页精修与分享
- **全屏翻页阅读**：像看电子漫画一样预览整本成果；
- **单页重绘**：哪一幕不满意，直接在画廊修改该幕提示词单独重绘，即时替换；
- **一键导出 HTML**：把整本画册导出为一个完全独立的单文件网页，发给朋友双击就能直接看。

### 6. 🛡️ 开箱即用，100% 本地隐私
- **零安装依赖**：纯 Python 标准库驱动，无需繁琐的 `pip install` 环境安装；
- **无网也能用**：静态资源全部本地随包分发，断网离线也能正常打开；
- **内置模拟模式**：电脑还没配好 ComfyUI？打开模拟模式即可直接体验从剧本设计到画廊导出的全套流程。

## 🚀 3 步极速开始

### 第 1 步：启动服务
- **Windows 用户**：直接双击运行根目录下的 `start.bat`。
- **命令行用户**：
  ```bash
  python server.py
  ```

### 第 2 步：打开界面
在浏览器中打开：👉 **[http://127.0.0.1:8777/index.html](http://127.0.0.1:8777/index.html)**

### 第 3 步：开始创作
1. **连接 ComfyUI**：默认自动连接 `127.0.0.1:8188`（如暂未启动 ComfyUI，可在工作流页面开启「模拟模式」先体验）；
2. **挑个模板**：在「模板配置」中选择内置模板，或直接使用项目根目录自带的 [default_comic_template.json](default_comic_template.json)（12 幕全年龄奇幻冒险分镜示例）；
3. **点批量生成**：在「批量角色矩阵」选好角色，点击生成，静待整本画册出炉！

## ⌨️ 常用快捷键

- `Ctrl` / `⌘` + `K`：打开全局命令面板（搜索模板、画册、执行操作）
- `Ctrl` / `⌘` + `S`：保存当前编辑的模板（平时打字也有自动保存）
- `Alt` + `1` ～ `5`：在「模板、矩阵、剧情、画廊、工作流」之间快速切换
- `Esc`：关闭所有弹窗

---

## 💾 数据与备份

- 所有剧本、配置与生成的漫画图片都**完整保存在你的本地硬盘**（`data/` 与 `images/`），不上传任何云端。
- 顶部支持一键「**导出配置**」为单个 JSON 备份文件，换电脑时点击「**导入配置**」即可无缝还原。
