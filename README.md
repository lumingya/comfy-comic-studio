## 开始使用

需要 **Python 3.10+、Pillow 11.3–12.x** 与现代浏览器。可执行变量另需 **Node.js 20+**，Git 扩展安装另需 Git。普通阅读和生产不需要安装 npm 依赖。

解压完整源码包，在项目根目录运行：

```bash
python -m pip install -r packaging/requirements.txt
python server.py
```

打开 **http://127.0.0.1:8777**。Windows 可双击 `start.bat`；Linux/macOS 可运行 `sh start.sh`。启动器检查依赖，缺少时显示所选 Python 的安装命令，不会自动联网安装。

源码包包含可编辑的官方 `data/` 和分发清单，不包含个人密钥、开发缓存或运行任务。可用 `MIO_DATA_DIR` 指向独立数据目录；升级时保留自己的数据、扩展用户数据，不要覆盖。

## 当前创作流程

1. 在 **分镜工坊** 保存独立分镜资产：每幕名称、提示词、台词及可选负向提示词。
2. 在 **预设工坊** 保存人物、画风和图片等普通变量。负向内容也使用普通变量，例如 `{人物负向}`，在分镜负向提示词中明确引用，不会隐式叠加。
3. 在 **工作流与 API 配置** 设置 ComfyUI、NovelAI 或 OpenAI 兼容图像渠道。密钥、工作流和真实模型需自行准备。
4. 进入 **装配与生成**，用三步向导或 N:N 连线画布组合分镜与预设、选择渠道并命名输出。新任务只进入**待命**，不会立即执行脚本或调用模型。
5. 在指定任务卡点开始，或冻结“从此处顺次生成”的批次。全局暂停、取消及单幕/后续幕重跑均保留未选中的已确认结果。
6. 到画册集阅读、编辑或导出。生成画册不会反向修改独立分镜或预设。

可选功能总开关和悬浮助手默认开启，明确保存的关闭设置会被尊重。视觉审校 API 仅在其可选功能卡片配置；模板与扩展市场是可由设置关闭的独立全页工作区。

## 本次可靠性更新

- 台词按 `frame.id` 关联；重排、删除和空台词覆盖不再错位，重复分镜 ID 会被拒绝。
- 后台同步通过 DOM 差量协调更新，保留真实焦点节点、选择区与输入法会话。明确切换分幕时更换对应编辑器。
- ComfyUI 使用已记录的上游任务 ID 定向取消，并反馈回执；阻塞的本地读取也会关闭。不会盲目调用共享实例的全局中断。
- HTTP 429 尊重 `Retry-After` 和有上限的指数退避，不计入连续致命故障。已提交的 ComfyUI 任务只重试查询/下载，绝不因查询限流重新提交生成。
- 动态弹窗里的错误提示保持可见；任务卡显示白话摘要，诊断详情保留脱敏响应。
- 图片编辑支持实时拖动预览、双击原位编辑、漫画竖排、独立拖动气泡尾端，撤销保留选中图层。
- 封面、任务卡和阅读胶片条使用按需 WebP 缩略图；缓存限制为 256 MiB / 2048 文件，解码串行化。完整阅读与导出继续使用原图。
- 重启保留安全待执行的批次并全局暂停；未确认的在途请求不伪装成未提交，不自动重复付费。

## 展示、导出与备份

- **HTML**：保留模板展示能力和内联体积预算。
- **ZIP 原图资源包**：独立 `index.html` 与 `images/`，不受 HTML 的 128 MiB 内联预算影响。图片字节保持原样，未生成分幕保留缺页说明。
- **PDF 图片画册**：逐页完整图片。JPEG 尽量直接嵌入，其他位图以高质量 JPEG 嵌入；不是无损、可编辑的文字排版格式。SVG 或缺页会提示改用 ZIP。

ZIP/PDF 在服务端磁盘生成并分块发送，由浏览器下载管理器接收；不在 JavaScript 中构造整册 Base64 或整包 Blob。ZIP 需整体解压后打开阅读页，使用简洁阅读版，不复制自定义模板脚本。

HTML、ZIP 和 PDF 都不是完整工程备份。请停止服务后备份整个数据目录，包含配置、素材与运行记录。[备份说明](docs/guide/BACKUP.md)

## 安全与费用边界

- 云端生成会把提示词、参考图发送给所选供应商，可能收费；本地停止不意味着退款。
- ComfyUI 原子按任务取消依赖对应服务端接口。旧版只能安全删除本任务的排队项；不能确认运行中任务时明确提示升级或人工核对，不误停其他人的工作。取消发生在收到任务 ID 之前，也会明确标记未确认。**不承诺卸载模型或清空全部显存。**
- 结果不明必须先核对上游记录。直接重跑可能重复收费。
- 默认只监听本机。`MIO_API_TOKEN` 只保护 `/api/v1`，不是整站公网鉴权。
- 第三方扩展与可执行变量是受信任代码机制，不是恶意代码沙箱。代码和扩展用户数据分开保存。安全恢复可用 `?safe_mode=1` 或 `MIO_SAFE_MODE=1`。
