# Mio · 绘页

**把故事画出来，把作品留在自己手里。**

Mio 是一间本地优先的漫画工作室。从分镜、出图、挑图，到留白排版与分享，在同一部作品里完成。可以连接本机 ComfyUI，也可以选用云端生图服务；作品和素材保存在自己的电脑上。

先打开随包短篇《雨停以后，信会抵达》，读一读，再从自己的第一幕开始。

[开始使用](#开始使用) · [离线教程](#随时翻阅的教程) · [扩展与开放接口](#按需扩展) · [路线图](docs/ROADMAP.md)

## 创作的四件好事

### 01 · 好的分镜，可以反复开篇

在分镜工坊写故事，用 `{变量}` 留出角色、服装和画风的位置。下次换一组预设，就能沿用熟悉的分镜节奏。生成前先看展开后的提示词，按幕修改；已有画册保留自己的快照，之后修改模板也不会追改它。

### 02 · 出图方式，由你决定

连接 ComfyUI 工作流，或选择云端图像渠道。工作流里的每颗 LoRA 都可独立开关，保留各自的权重；新任务与逐幕设置分别生效。复杂节点和新渠道通过独立适配器扩展接入，已有工作流也能继续手工映射。

### 03 · 一部作品，三种收藏方式

将作品导出为可独立打开的离线 HTML 画册，送给读者，也留给未来的自己。

| 画册                            | 阅读气质                                           |
| ------------------------------- | -------------------------------------------------- |
| **典藏画集 · Monograph** · 默认 | 暖白棉纸、卡纸画框与双栏铭牌，像翻阅一本美术馆藏本 |
| **暗房放映 · Nocturne**         | 黑曜石舞台、暖象牙字幕，让画面在暗处安静展开       |
| **精装对页 · Folio**            | 棉纸双页与书脊光影，桌面舒展，手机自然转为单页     |

导出前可全屏试阅。离线阅读器提供目录、灯箱放大、单／双页、无字阅读和触屏翻页；需要其他交付方式时，同一入口也能导出 PDF、长图、平台切片、图片包与可编辑源文件。

### 04 · 日常轻一点，能力深一点

主界面围绕每天会做的创作步骤展开。AI 辅助等能力按需启用；专业处理留给独立扩展与开放接口。通用 API v2 和 Python 客户端让脚本、自动化工具与其他应用使用同一套作品流程。

## 从第一幕，到一本作品

```mermaid
flowchart LR
    A[写分镜] --> B[选预设 · 看变量]
    B --> C[连接生图 · 明确开始]
    C --> D[挑选采用]
    D --> E[排版 · 留白]
    E --> F[阅读 · 导出]
```

手工编辑始终可用。重画得到的是新候选，只有明确采用，才会替换阅读中的画面。首次启动带有示例画册、分镜与预设；真正生成新图还需要可用的 ComfyUI 或云端服务，云端调用可能计费。

## 开始使用

### 下载发布包

1. 从 [Releases](https://github.com/lumingya/comfy-comic-studio/releases) 下载 `mio-studio-<版本>.zip`，解压到自己的目录。
2. 安装 Python 3.11 或更新版本。发布包已包含界面，无需安装 Node.js。
3. Windows 双击 `start.bat`；macOS / Linux 运行 `./start.sh`。

首次启动会联网安装依赖，之后打开 [本机工作室](http://127.0.0.1:8788)。请保留启动终端；只关闭浏览器不会停止服务。若启动遇到问题，运行 `start.bat --check`（macOS / Linux：`./start.sh --check`）可先检查依赖与应用配置。

### 从源码运行

需要 Python 3.11+ 与 Node.js 20+。在仓库根目录执行：

```powershell
npm ci --prefix web
npm --prefix web run build
.\start.bat
```

macOS / Linux 将最后一行换成 `./start.sh`。开发界面时另开终端运行 `npm --prefix web run dev`；Vite 会将 API 与 WebSocket 请求代理到本机的 8788 端口。

运行数据默认保存在 `server/data/runtime/v3`，可用 `--data` 参数或 `MIO_V3_DATA` 环境变量指定其他目录。开发前请读 [AGENTS.md](AGENTS.md)，并运行 `python tools/protect_local_data.py`，避免把本机改写的示例数据提交到仓库。

### 在自己的局域网里访问

以 `start.bat --host 0.0.0.0` 启动后，可在同一可信局域网的设备上按电脑 IP 访问。若使用主机名，将它加入环境变量 `MIO_ALLOWED_HOSTS`，多个名称用逗号分隔。

本机界面的 `/api` 无需登录，请只在可信设备之间使用，**不要把 8788 端口直接暴露到公网**。给其他程序使用的 `/api/v2` 则要求带作用域的访问令牌。

## 随时翻阅的教程

启动后从「帮助 → 使用教程」进入，或打开 [本机教程中心](http://127.0.0.1:8788/manual/)。[中文教程](server/mio_server/manual/index.html)与[英文教程](server/mio_server/manual/en.html)连同插画、搜索和独立章节一起随包提供，断网也能阅读。

阅读与分享的步骤见[独立章节](server/mio_server/manual/chapters/zh/read-and-share.html)。详细操作留在教程里，创作界面留给作品。

## 把作品妥善留下

**分享作品**用画册导出；**保留可编辑内容**用源文件或创作套装；**保护整个工作区**用「设置 → 数据与备份」。工作区备份可先预检，再明确安排下次启动恢复，恢复前会保护当前内容。默认备份去除已配置的服务凭据，模型和外部服务需要另外保管。步骤与范围见[备份与恢复](docs/WORKSPACE_BACKUPS.md)。

「设置 → 关于与更新」可浏览发布版本、阅读更新日志，并选择升级或回退。更新包通过 **Ed25519 签名与 SHA-256 校验**后暂存，下次用启动脚本安装；安装失败会回滚，个人数据保留。没有可信签名时不会安装，Git 开发目录也不会被发布包覆盖。

根目录启动器与 `mio_update_bootstrap.py` 是稳定恢复宿主，原地升级或回退时保留。它们先恢复未完成的安装事务，再加载应用；`--data` 会一致传给更新器和工作室。需要更换恢复宿主时，使用完整发布包。

## 按需扩展

扩展在「扩展市场 / 已安装」中管理，支持文件夹与 ZIP 导入。启用前审阅来源和内容摘要，停用后即可回到简洁基座。独立主题在「设置 → 外观与阅读」管理；扩展代码、主题资源与私人数据分别保存。卸载扩展默认保留数据，可明确选择同时删除。
