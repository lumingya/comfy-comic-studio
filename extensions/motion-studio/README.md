# Motion Studio · 动态漫

Motion Studio is an optional episode panel for arranging camera movement and reading time, then exporting a self-contained HTML motion comic. It stays inactive until installed and trusted. Opening it does not call an image model or a paid service.

## Use

1. Import this folder or a ZIP through Extensions → Installed. Review the package and digest, then explicitly enable it.
2. Open a specific episode's extension menu and choose Motion Studio.
3. Load its shots. Choose a camera move, keep the automatic dialogue-based duration or enter 0.5–30 seconds, and choose a transition. The preview uses adopted source images and browser speech synthesis when available.
4. Save edits before export. Choose portrait or landscape, saved lettering, subtitles, and voice defaults, then export one offline HTML file. The host provides the actual download button.

The editor saves `Panel.motion` using the episode revision. If a write fails, it does not retry automatically; reload to verify the episode before saving again. A transition is saved and exported with the shot. No adopted images means there is nothing playable to export.

## API and isolation

The sandbox panel declares only these host-mediated requests in `mio-extension.json`:

| Request                                            | Permission | Purpose                                                       |
| -------------------------------------------------- | ---------- | ------------------------------------------------------------- |
| `GET /episodes/{episode_id}`                       | read       | Episode revision, panels, adopted take IDs, and dialogue      |
| `GET /episodes/{episode_id}/motion-plan`           | read       | Resolved camera move, duration, transition, and dialogue plan |
| `PATCH /episodes/{episode_id}/panels/{panel_id}`   | write      | Explicitly save the camera plan with the loaded revision      |
| `GET /episodes/{episode_id}/takes/{take_id}/image` | read       | Display an adopted image through the host media bridge        |
| `POST /export/motion`                              | write      | Prepare a self-contained offline motion-comic download        |

The panel does not use `fetch`, credentials, external assets, or a Python entry point. Its bridge checks the host session and releases image handles when changing shots or closing. The UI consumes the host's theme tokens and locale. The exported HTML is generated by the existing motion exporter and uses its own offline player.

## Checks

From the repository root:

```sh
python tools/check_extension_package.py extensions/motion-studio
node --test extensions/motion-studio/tests/*.test.cjs
```

The tests use a simulated extension host and local DOM. They do not claim to be a real browser or ComfyUI run.
