# 素纸

暖白与墨褐的浅色主题。此文件夹可以独立分享，不包含代码，也不依赖 AI 辅助或项目源码。

在 Mio 的「设置 → 扩展」选择「导入文件夹」，选中本目录并启用；随后在「外观与阅读」选择「素纸」。也可将整个文件夹压缩为 ZIP 导入。随软件附带时默认停用。

修改 `theme.json` 中的颜色、控件尺寸、圆角或阴影即可定制。保存后重新启用扩展；分享时保留 `mio-extension.json`、`theme.json` 与本说明。停用或卸载后，主题会从可选列表移除。

主题文件使用 Mio 公共主题令牌，未填写的令牌沿用浅色基础值。JSON 只接受安全的颜色、有限尺寸与阴影值，不加载远程资源或任意 CSS。
