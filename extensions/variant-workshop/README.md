# 批量变体矩阵

独立的可选沙箱面板，将角色、服装、场景与画风四个独立轴组合为原生 `VariantSet`，预览实际组合与任务数量，选择部分组合和分幕生成候选，固定其他三轴横向比较，再分别采用和导出。启用前需在扩展管理中检查并信任当前内容摘要；停用后，作品中已保存的版本、候选与导出不会删除。

## 使用

将此目录作为扩展导入，在扩展管理中确认来源与文件摘要后启用。在分镜工坊具体话的「扩展」菜单打开面板。

1. 点击「读取作品」。面板只在用户点击后读取当前话、作品和已有预设；打开不会读取或生成。当前话就是本次使用的分镜。
2. 普通分镜默认使用「分镜预设变量」来源：四轴分别绑定 `character` / `outfit` / `scene` / `style`，也可改为分镜实际使用的自定义变量。每个选项展示其预设条目的真实值和使用幕数，只提取该条目，不带入预设里的其他变量或节点绑定。当前话已有的预设快照优先于同 ID 的工坊预设；新组合也保存为值快照。
3. 结构化分幕可改用「结构化设定集」：角色外观不再复制服装字典；服装轴将源服装标签单独覆盖目标角色实际使用的一个服装槽；场景轴覆盖被引用的目标场景，保留目标 ID；画风轴选择已有画风。缺失目标或没有实际引用的目标会阻止保存。
4. 四轴按笛卡尔积预览，最多一次 24 个组合；重复选项及实际内容相同的组合合并。逐行勾选要保存的子集，未选择的轴沿用，空字符串或空标签明确清空。保存不会开始生成。
5. 勾选要生成的版本、分幕和每幕候选数。提交前可看到具体版本数 × 分幕数、分幕任务数与候选图片总数。最多 16 张候选/幕，生成不会自动采用。逐幕 `$变量` 高于版本值，版本值高于作品冻结值，后者高于设定集内建变量。
6. 选定基准版本与角色/服装/场景/画风维度后，固定其他三轴比较；选择「全部版本」则按其余轴分组。自定义变量需保持上方映射键与创建时一致。最多读取两张原图并排比较，采用仅影响同一话、分幕和版本。
7. 选择单个版本后导出 HTML 或 PDF；只有已采用的图像进入成品。下载由宿主提供的按钮触发。

重复提交相同渲染意图会复用幂等键；改变勾选、候选数或刷新版本后才会创建新的生成意图。失败、断网或请求超时会显示错误，不会静默重试或自动采纳。

## API 与权限

面板只通过 `mio-extension.json` 声明的请求调用当前真实 API：

| 能力 | API | 权限 |
| --- | --- | --- |
| 读取作品、分镜和预设 | `GET /series/{series_id}`、`GET /episodes/{episode_id}`、`GET /workshop/presets` | read |
| 原子追加版本 | `POST /series/{series_id}/variants` | write |
| 选择版本/分幕并生成候选 | `POST /episodes/{episode_id}/render` | render |
| 读取进度与候选原图 | `GET /jobs/{job_id}`、`GET /episodes/{episode_id}/takes/{take_id}/image` | read |
| 明确采用 | `POST /episodes/{episode_id}/takes/{take_id}/adopt` | write |
| 按变体下载成品 | `POST /export/album`、`POST /export/portable` | write |

没有自建后端、私有数据模型、额外依赖或凭据读取。图片通过宿主的限额媒体通道传输，切换候选/话或关闭面板时释放。主题颜色、明暗和语言跟随宿主实时更新。

`VariantSet.variables` 复用既有提示词变量展开；`outfits` 使用 `角色 ID → 服装槽 → 标签列表`，`locations` 使用 `场景 ID → Location 字段补丁`。省略与明确清空分别保留；不新增平行的预设、任务或图片存储。
